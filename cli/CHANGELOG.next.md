- **上下文圆环**：CLI Web 与 Studio 用 Core 的标准 `display` 协议渲染圆环，Core Agent 展示上下文用量。
- **文件传输命令**：新增 `workspace file-upload/file-download/file-delete`，单文件上限 50 MiB。

### 破坏性变更

- **API 路径**：项目接口从 `/api/workflows` 改为 `/api/projects`，项目字段 `workflowId` / `workflowName` 改为 `projectId` / `projectName`。
- **上传约定**：忽略文件从 `.workflowignore` 改为 `.steamharnessignore`，上传包名请求头改为 `X-SteamHarness-Package-Name`。
- **项目模板**：模板内的运行时全局 `workflow` 改为 `steamharness`，入口改用 `steamharness.defineProject`。
- Conversation 移除输入开关与自定义主字段，附件能力改为 `conversation.attachments`。
  迁移：附件声明改用 `conversation.attachments`，参数通过 Auxiliary / Quick / Mode / Slash 声明。

### 新增

- 新增 独立项目模板模块，提供三个最小项目和四个无需模型或登录的本地示例。
- 新增 Studio 开始页可创建项目，模板统一双语清单、UUID、精确依赖与目录冲突校验。
- 新增 Conversation 输入 `/` 时在输入框上方弹出可筛选的参数菜单，支持单选与 boolean。
- 新增 CLI Web 与 Studio 使用 Core 标准 `display` 协议渲染圆环并固定到输入栏右侧。
- 新增 Core Agent 用该圆环展示上下文用量，悬停或键盘聚焦时查看详情。
- 新增 CLI Web 正文、报错与日志支持快捷键或右键菜单复制，嵌入 Studio 时使用宿主剪贴板。
- 新增 Studio 本地分析的只读 Kanban 接口和轻量运行活动记录，合并真实历史。
- 新增 Studio 运行时接入已导入的关联项目，校验 UUID 与双向授权。
- 新增 Web 运行页、小助手和看板界面支持中文与英文，嵌入 VS Code 时跟随宿主语言。
- 新增 `workspace file-upload/file-download/file-delete`，独立上传和核验项目图片与文件。

- 变更 Web 对话页新对话入口移到右上角，左侧新增项目信息入口。
