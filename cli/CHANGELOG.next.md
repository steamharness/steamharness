# Unreleased

### 新特性

- **Bot 项目记忆**：项目配置提供默认开启的记忆开关，关闭后保留已存记忆
- **项目发行运行**：按入口构建、验证和运行压缩发行包，并生成独立启动快照
- **Kanban 原生会话**：看板可嵌入本地原生会话，复用流式回复、草稿、队列和审批

### 破坏性变更

- 最终封包的 `structure.json` 改用 v2 压缩编码，明文保留项目与入口摘要。
- 项目声明、配置及额外 JSON 资源压缩为单行，保留字符串内容与数值精度。
- 运行快照和上传下载沿用统一解码与完整性校验，旧发行结果需重新构建。
  迁移：从源码重新构建旧发行包；消费最终封包结构时使用 v2 解码器。
- 项目类型、结构报告、新建模板和 Web 宿主统一使用 Bot。
- 保留会话协议，按稳定请求身份关联首轮、恢复与后续消息。
  迁移：将项目类型及模板改用 Bot；嵌入会话继续使用稳定请求身份关联消息。
- 项目身份、名称、版本和声明改用独立的 `steamharness.json`；不再读取或写回 `package.json.id` 与 `steamHarness`。
- 聚合项目须显式登记子入口，由子目录配置提供图标、声明与计划。
- 未登记配置不生效，上传下载保留父子结构。
  迁移：把旧 package.json 项目字段移至 steamharness.json，并显式登记聚合子入口。
- 检查、运行、Web 与 MCP 支持入口选择。Web 窗口切换保留各入口草稿和后台任务。
- 移除关联项目、依赖锁和组合发布命令。
  迁移：使用聚合 entries/defaultEntry 与逐入口命令，替换关联项目、依赖锁及组合发布流程。

- 变更 CLI Web 的 Workflow 运行记录列表与 Bot 对话列表统一为单行展示，标题、状态和时间同行。

- 变更 SteamHarness 项目产物的统一目录为 dist/steamharness/。
