# Unreleased

### Pi Durable

- 【改进】将持久 Agent 任务面板完整迁入 Studio Trace；CLI Web 移除任务侧栏、入口和宽度状态，保留正文、队列与分叉。宿主桥传递去重任务快照、计划审批边界及显式会话控制，按 owner 校验操作并回传错误。

- 【修复】任务侧栏 Plan 页展示最新计划原文及待确认、提交中、待修改和已批准状态，不再依赖模型调用 `update_plan` 才有内容；修改、执行及重开后按审批位置保留正确计划，执行步骤仍独立保存并支持勾选。

- 【修复】等待计划审批或回答问题时隐藏当前回答底部操作栏；保留计划原文、修改版本、审批记录和执行结果，避免恢复报告或持久快照覆盖先前正文。重新打开持久历史时从已保存快照恢复完整计划，无需再次执行模型或工具。

- 【修复】持久回答顶部按本轮显示用量及调用、输入、输出和缓存明细，避免其他 fork 的消耗累计到原回答；输入栏圆环使用当前打开会话的最新标准输出，跟随后续输入、fork、压缩和重置更新，非零小占用显示不足 1%。

- 【改进】Conversation 点击发送后立即展示消息、附件和发送状态，忙碌时立即展示队列项；会话保存和参数解析在后台完成。输入框可继续编辑，确认回执不会清空新草稿；发送失败保留原消息并支持按原请求身份重试，避免重复执行。

- 【修复】持久 Agent 运行报告失败时保留失败状态和原始原因，不再被已完成的主回答覆盖为成功；同步流式内容块与异常终态修复，避免正文失败而任务仍显示运行、重开又继续执行。

- 【改进】任务视图的对话/活动任务和已结束任务各占一半高度并独立滚动，标记当前打开的对话。历史列表展示全部已加载任务，点击任务在原位展开参数、结果和错误详情，并可打开所属会话。
- 【改进】任务侧栏左边缘支持拖动和键盘调整宽度、双击复位并保存宽度；保留正文最小阅读空间，窄屏继续全宽展示。已完成或已停止任务优先显示终态，避免历史残留取消标记导致一直显示停止中。
- 【改进】任务标题栏使用向右收起按钮，将整理、重置和停止操作收进带文字的更多菜单；仅在对应工作活动时显示停止当前回答/全部任务，不把独立分叉误作所属任务。
- 【改进】移除输入框的本轮/下一轮切换，忙碌时默认排队、空闲时直接执行；持久队列项增加立即发送图标。分叉会话先显示确认弹窗，确认后打开新会话，并修复状态帧延迟导致无法切换的问题。

- 【修复】任务侧栏补齐活动及已完成工具的提交参数详情，包括 Code Mode 嵌套调用；更新 Core 依赖，防止不同轮次复用调用 ID 时遗漏或错配工具展示，或在普通 Agent 模式下复用前一次批准。
- 【修复】更新持久 Agent Core 特性依赖，固定提交时的命令快照，拒绝预声明工具目录恢复时的定义漂移，并保护 SQLite 备份的源与目标 owner；沿用现有会话与任务侧栏展示。
- 【新增】持久任务详情展示定义版本、检查点、唤醒时间和 Code Mode 脚本；记录视图展示扩展、工具目录、执行目标与存储状态，沿用 Studio / VS Code 风格和现有四视图布局。
- 【修复】持久 Agent 空闲时可继续导出与总结；工具初始化较慢时保留恢复命令，重开自动恢复排队输入，分叉确认丢失后仍能找回历史和来源。命令确认按 owner 与目标会话隔离，去重不受 JSON 字段顺序影响，完整快照不再重复写入 Trace 历史。
- 【新增】持久 Agent 任务侧栏，提供任务、计划、记录和用量四个视图，沿用 Studio / VS Code 主题与图标，窄面板可返回对话；支持队列撤回、运行中引导、消息分叉、上下文重置和分范围停止。
- 【改进】通过双向 worker 命令、稳定请求身份、未确认命令恢复和完整快照同步常驻 Agent；前台/后台/连接状态分开，多页面独立选择会话，慢连接只保留最新快照，正文保持平铺且不重复。
- 修复 Conversation 保存结束状态失败时任务记录无法释放的问题；保存停止意图失败时仍停止并等待 worker、清理审批等待任务，避免执行继续或关闭卡住。
- CLI Web / Studio 支持启用 recovery 的 Conversation 恢复原 worker 运行，沿用原消息、参数和审批；状态行显示“恢复中”，意外退出最多自动恢复 3 次，重试继续原运行。关闭宿主保留检查点，显式停止持久取消，删除会话清理 Agent 存储。

### 变更

- Workspace 移除远程执行与发行目标；上传使用静态项目类型，下载不限制平台。

### 新特性

- **项目模板模块**：提供 Workflow、Conversation、Kanban 三个最小项目和四个本地示例，供 Studio 开始页创建项目。
- **标准主输入框**：Conversation 统一使用标准输入框，附件能力改为 `conversation.attachments`。
- **上下文圆环**：CLI Web 与 Studio 用 Core 的标准 `display` 协议渲染圆环，Core Agent 展示上下文用量。
- **文件传输命令**：新增 `workspace file-upload/file-download/file-delete`，单文件上限 50 MiB。

### 破坏性变更

- **API 路径**：项目接口从 `/api/workflows` 改为 `/api/projects`，项目字段 `workflowId` / `workflowName` 改为 `projectId` / `projectName`。
- **上传约定**：忽略文件从 `.workflowignore` 改为 `.steamharnessignore`，上传包名请求头改为 `X-SteamHarness-Package-Name`。
- **项目模板**：模板内的运行时全局 `workflow` 改为 `steamharness`，入口改用 `steamharness.defineProject`。
- Conversation 移除输入开关与自定义主字段，附件能力改为 `conversation.attachments`。
  迁移：附件声明改用 `conversation.attachments`，参数通过 Auxiliary / Quick / Mode / Slash 声明。

### 新增

- 新增 独立项目模板模块，提供三个最小项目和四个无需模型或登录的本地示例。

- 新增 Conversation 输入 `/` 时在输入框上方弹出可筛选的参数菜单，支持单选与 boolean。

- 新增 Studio 本地分析的只读 Kanban 接口和轻量运行活动记录，合并真实历史。

- 新增 `workspace file-upload/file-download/file-delete`，独立上传和核验项目图片与文件。
