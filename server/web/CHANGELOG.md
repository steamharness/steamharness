# Changelog

本发布单元的所有重要公开变更均记录于此。

## 0.1.1 - 2026-07-29

### 新特性

- **版本更新提示**：检测到新的 Server 版本时展示一次更新摘要，并提供完整 Docs 记录入口。

## 0.1.2 - 2026-07-29

### 修复

- 修复 正式发布在严格 TypeScript 校验阶段中断，导致无法完成构建与部署。

## 0.1.3 - 2026-07-30

### 新特性

- **Kanban 预览与命名配置**：项目列表和公开 Embed 支持 Kanban 预览、命名配置、静态资源及受限 Bridge。
- **本地发布**：Server Web 可在部署主机本地完成发布，不再要求通过 SSH 回连同一主机。

### 新增

- 新增 项目列表和公开 Embed 支持 Kanban 预览、命名配置、静态资源及受限 KV 与知识库 Bridge。

### 变更

- 变更 Server Web 可在部署主机本地完成发布，不再要求通过 SSH 回连同一主机。

## 0.1.4 - 2026-08-07

### 新特性

- **界面语言跟随系统**：管理端和公开 Embed 提供三档语言设置，更新摘要与日志链接跟随当前语言。
- **Workflow 多入口折叠列表**：Webhook 设置加载并校验目标版本入口，运行结果、历史和回放显示实际入口。
- **项目定时任务工作区**：管理精确版本和入口计划、预览触发、立即运行并查看 fire 历史。

### 新增

- 新增 管理端和公开 Embed 提供「跟随系统 / 简体中文 / English」设置，更新摘要与日志链接跟随语言。
- 新增 管理端和公开 Embed 以可折叠列表展示 Workflow 入口，Webhook 设置加载并校验目标版本入口。
- 新增 Kanban Bridge 按静态 alias 读取授权 Workflow KV 数据源并订阅 revision，不暴露来源标识与写能力。
- 新增 Workflow 项目定时任务工作区：精确版本与入口计划、预览触发、立即运行、fire 历史与来源筛选。
- 新增 项目详情提供依赖与权限工作区，支持数据授权编辑、短期源码申请、使用方搜索与审批撤销。

### 变更

- 变更 项目工作台按更新时间从新到旧排列，最近更新的项目优先显示。
- 变更 执行回放与公开 Embed 重整推理、工具、任务、文件、重试和错误的展示与流式跟随。
- 变更 Workflow 多入口使用紧凑标题栏和对齐表单，Embed 更新与参数联动期间保留当前输入状态。

### 修复

- 修复 手动折叠的默认入口重新展开、宿主重渲染重置输入、旧目标的迟到错误显示到当前目标。
- 修复 Kanban 初始快照后重复刷新、入口结构不可用时隐藏全部计划、定时任务操作被重复提交。

## 0.1.8 - 2026-08-26

### 新特性

- **只访问服务器数据**：`server` 与 `both` 项目保持可运行，`local` 或未声明项目统一显示阻断状态。
- **独立 Alpha 入口**：随 Server Alpha 部署，账号与业务数据继续与正式版共用，代码与静态资源隔离。
- **运行状态可读**：项目列表、详情和版本页展示当前语言名称、手工声明、展示平台与可运行状态。

### 破坏性变更

- Server Web 只访问服务器数据，`local` 或未声明存储的项目在设置页之外统一阻断。
  迁移：把项目改为 `server` 或 `both`，并从其它位置清理对服务器数据的访问。
- 运行、概览和版本来源统一使用 Desktop 身份与 `desktop` 筛选值。
  迁移：把调用方的来源标识改为 `desktop`。

### 新增

- 新增 账号邀请链接提供独立的初始密码设置页面，接受后直接建立登录会话。
- 新增 项目设置页只读展示存储声明、允许位置、服务器访问状态和阻断原因。
- 新增 被阻断项目不再显示可写运行队列、访问策略或数据入口。
- 新增 项目列表、详情和版本页展示当前语言名称、手工声明、展示平台与可运行状态。
- 新增 运行、Embed、Webhook、计划任务和版本选择器只提供 Server 可运行版本。
- 新增 Server Web 随 Server Alpha 部署到独立 Alpha 入口，代码与静态资源版本隔离。

### 变更

- 变更 执行回放与详细日志默认展开 stdout、stderr、runner diagnostics 与 `report.json` 并占满宽度。
- 变更 长日志内容使用独立滚动区，手动折叠后不再残留空白占位。
- 变更 运行、账号、计划、用量、审计和发布记录统一使用 `YYYY-MM-DD HH:mm:ss` 时间格式。

### 修复

- 修复 项目类型名称随界面语言展示，中文界面统一使用「工作流」「对话」「看板」。

## 0.1.9 - 2026-09-01

### 新特性

- **关联项目工作区**：项目详情可创建、编辑和移除双方关系，分别设置读写授权并区分确认状态。
- **MCP 连接页**：可选择 draft、latest 或精确版本，复制 Streamable HTTP URL 与客户端 JSON。
- **主回答固定在正文**：finish reason、token usage 与 Provider metadata 不再把正文误判为详情块。

### 破坏性变更

- 全局 KV 导航与页面已移除，KV 检查器只显示当前项目的 KV 域。
  迁移：改用 `project` 与 `conversation` 作用域，不再访问全局 KV。

### 新增

- 新增 项目详情通用「关联项目」工作区，可设置双方读写规则并区分已确认与待确认。
- 新增 Workflow 项目 MCP 连接页，可选择版本目标并复制 URL、Bearer 模板和客户端 JSON。

### 变更

- 变更 仅注册、尚未首次发布的项目不再展示 Embed 入口，直接访问管理地址回到项目概览。
- 变更 公开 Embed 的快捷参数合并为单一摘要入口，优先展示「模型 · Effort」。
- 变更 窄屏下快捷项改为钻取导航，并支持一键恢复默认值。
- 变更 Kanban 与项目组依赖界面统一使用已确认关联项目。

### 修复

- 修复 Conversation 的 assistant 主回答始终显示在对话正文，工具调用与 reasoning 仍走详情块。
- 修复 公开 Embed 历史栏与诊断面板调整宽度时卡住、脱离鼠标或残留拖拽状态。

## 0.1.10 - 2026-09-05

### 新特性

- **运行记录可重命名与删除**：项目管理员或运行发起者可操作，运行中的记录仍可改名但不能删除。
- **KV 条目可删除**：数据页详情弹窗确认后调用 `DELETE /api/workflows/:name/kv/entry` 删除单条 KV。

### 破坏性变更

- Server Web 不再承载公开 Embed，项目详情入口、列表状态、`/embed/**` 页面与域名全部移除。
  迁移：浏览器中的运行改由 Desktop 首页的 Web 构建承担，管理端只负责管理云端项目。
- Server Web 不再有 `/web` 入口页，登录页也不再接受 `next=web` 回跳。
  迁移：直接把用户送到登录页，登录后进入项目列表。

### 新增

- 新增 公开 Embed 按 Workflow 入口分组折叠展示，展开状态按站点稳定 Workflow ID 隔离。
- 新增 管理中心 Runner 页面，可查看节点在线状态、协议架构、容量与心跳并支持排空恢复。
- 新增 项目设置提供 Runner 池、CPU、内存和超时配置，版本页展示 Core 与镜像摘要。
- 新增 执行日志的运行行支持重命名与删除，仅项目管理员或运行发起者可操作。
- 新增 删除运行前弹确认并写明目标，成功后该行从列表消失。
- 新增 KV 数据页详情弹窗的「删除条目」，确认后调用删除接口并刷新当前页。
- 新增 删除失败时弹窗保持打开并在原位显示原因，无权限的会话不显示该入口。
- 新增 原始 JSON 覆盖入口应用前校验键名与类型，解析失败时原位报错。

### 变更

- 变更 公开 Embed 支持预览视频附件并保留媒体类型。
- 变更 运行相关页面只展示远程 Server 可运行版本，任务状态来自持久化 Runner 控制面。
- 变更 执行日志、调度、MCP 与 Webhook 页签改用 Server Web 自维护的精简回放与参数表单。
- 变更 项目详情「知识库」页签文档列表改为翻页，滚动到底不再自动续载。

### 修复

- 修复 匿名访问 `/web` 先跳登录并在登录后回跳，`?next=` 只接受路由名。
