# Unreleased

- 【修复】维护者只能列出访客、开发者邀请，阻止从项目或组邀请列表获取高角色令牌并提权。
- 【修复】管理员密钥审批保留系统管理员身份；访客申请使用独立成员申请表，避免废弃源码授权表约束阻断提交，不迁移旧授权。
- 【修复】已发布版本的个人配置读取、保存和导出不再依赖草稿，草稿发布校验信息仅在选择草稿时返回。

- 【修复】启动时为已有账号表和项目表补齐管理员标记与组归属列，避免登录和项目查询因缺列失败；重复初始化保留账号、项目及成员数据。
- 【变更】业务权限改为项目与多级组的访客、开发者、维护者、所有者四种固定角色；支持继承来源、成员邀请、访客申请、归属转移及最后所有者保护。账号仅保留普通用户与系统管理员；接口和数据库采用全新结构，不迁移旧角色数据。

- 【修复】配置发布过滤隐藏的 JSON 父路径后，子路径仍继承原有编辑与携带值规则，阻止通过整对象替换或导入修改锁定值。

- 【新增】项目配置发布草稿与不可变版本模板，统一过滤字段、值、默认值和附件，校验维护者权限、源码摘要及草稿版本；个人附件与配置按账号隔离，锁定变更及导入整批拒绝。

- 【修复】项目配置支持文件字段，直接选择并上传到服务器后保存文件引用；支持类型限制、替换和清除，上传失败保留原值。

- 【修复】读取或编辑旧源码版本的配置时保留新版本字段值和被声明隐藏的自定义定义，避免本地与 PostgreSQL 存储丢失配置。

- 【新增】通用项目配置 API 与按项目、账号隔离的新存储，替换 Kanban 专属配置接口；支持版本检查、原子导入导出和自定义字段，静态预览读取同一配置。旧配置数据不迁移。

### 项目头像

- 新建项目未提供头像时，自动保存项目类型图标和对比度至少为 4.5:1 的随机图标色与背景色；重新绑定已有项目保留原头像。

### 破坏性变更

- 项目 API 从 `/api/workflows` 改为 `/api/projects`，字段改为 `projectId` / `projectName`，请求头 `X-Workflow-Locale` 改为 `X-SteamHarness-Locale`。
- 数据库表 `workflows` / `workflow_*` 改为 `projects` / `project_*`，账户表去掉 `workflow_` 前缀；发布前执行 `docker-internal/deploy/migrate-project-tables.sql`。
- 审计事件类型 `workflow.*` 改为 `project.*`；对象存储前缀与磁盘数据目录改为 `projects/`。

### 变更

- 变更 发布 API 支持版本和源码哈希校验，阻止发布被其他操作替换的草稿。
- Server 改为项目与数据存储服务：移除全部项目执行及 Runner，保留安全上传、不可变源码版本、知识库、KV 和文件；数据写入与源码下载统一按固定角色授权。
- 清理旧执行错误与权限说明，数据访问错误仅描述服务器存储授权。

### 新特性

- **Kanban 页面方法注入**：注入接口支持方法注册与注销、方法目录、JSON 返回和取消协议。
- **Kanban 展示模式桥接**：Bridge 提供 `getPresentation()` 与模式变化事件，覆盖全屏、手机、平板和对话小卡片。

### 新增

- 新增 Kanban 注入接口的方法注册与注销、方法目录、JSON 返回和取消协议。
- 新增 Kanban 页面 Bridge 的 `getPresentation()` 与展示模式变化事件，覆盖全屏、手机、平板和对话小卡片。
- 新增 Kanban Bridge 项目固定作用域的文件创建、读取与删除，最大 50 MiB，拒绝跨项目和会话附件访问。

### 修复

- 修复直接访问或刷新 Server Web `/projects` 页面时，被已移除 API 的路由拦截并返回 JSON 404 的问题。
