# Studio 分析

内置 Kanban 项目，通过 Studio 的只读连接汇总真实本地项目与运行记录，不连接 Server。

在 Studio 命令面板中执行 `Workflow: Open Studio Analysis`，或将本项目作为普通 Kanban 项目打开。仓库包含可运行的 `index.html` 与打包资源；修改源码后执行 `pnpm install`、`pnpm build`。

项目统计包含当前工作区与 Studio 已导入的本地项目，按真实路径去重；不扫描未导入的磁盘目录。服务器存储项目被排除。总览展示项目类型、运行状态、近 14 天趋势、正在运行与等待输入的任务。项目与运行表支持筛选、分页和 CSV 导出，每 5 秒自动刷新，可关闭自动刷新。

运行数据来自 Studio 的 CLI 本地历史与各运行服务的活动记录，按当前项目类型选择历史。成功、失败、取消、超时、中断分别展示；心跳过期但进程未确认退出、或旧 CLI 尚未提供活动记录时，无法确认的运行显示为未知。多窗口数据合并时去重排队输入，不恢复已删除的终态记录。读取失败的项目显示为不可用，不使用演示数据。独立浏览器或普通 CLI 没有 Studio 连接时显示连接不可用。

`pnpm test` 验证汇总与导出；`pnpm test:ui` 使用无头浏览器验证双语、主题与响应式界面。
