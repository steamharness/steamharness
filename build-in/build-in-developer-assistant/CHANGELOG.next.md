- 【改进】同步工具调用诊断规范：任务详情保留提交参数，跨轮复用调用 ID 时保持独立展示，审批以持久任务区分独立调用；Studio 内置副本同步启用完整持久会话能力。
- 【修复】生成规范明确持久命令排队前固定快照、任务输入严格 JSON 校验、预声明目录持久定义核对和 SQLite 源/目标独占备份约束。
- 【新增】小助手在授权目录内发现工具，Studio Control 首次搜索时才连接；可通过宿主环境变量显式开启 QuickJS Code Mode，默认关闭。同步持久扩展、任务、远端执行和存储生成规范，并验证脚本嵌套工具与后台计时任务跨进程恢复。
- 【新增】小助手启用持久会话控制与任务计划，支持后台受限子 Agent（最多 4 个，仅 read/grep/find/ls，不递归）、结果单次回传和分叉计划继承；Studio / CLI Web 任务侧栏显示任务、计划、记录及父子用量。
- 【改进】生成规范同步会话 lease、控制/快照协议、子工具权限声明、配置切换和后台压缩边界；离线真实工作流覆盖后台工具强杀恢复及结果去重。
- 同步 Agent 恢复规范：内存审批保留原任务，初始上下文不覆盖持久历史，流式中断从已提交片段继续；补充真实小助手强杀续写、正文与用量重放验证。
- 小助手启用 Pi Durable 跨进程恢复，保留已提交工具结果、问答和计划审批；重复恢复不重复正文、写文件或用量。工具契约及生成规范同步 Pi 1.2.0、SQLite、稳定请求身份与持久取消接口。

### 变更

- 生成规范声明静态项目类型，发布仅交付源码与关联项目锁，不生成服务器执行目标。
- 清理生成器中的服务器环境变量、参数表单与关联执行说明；关联入口在本地执行，可显式访问服务器数据。上传与发布改用现有 CLI 命令。

### 新特性

- **Studio VS Code 宿主**：默认宿主改为 Studio VS Code，使用独立工作目录，并接入 Studio Control 标准 MCP。
- **计划中提问**：plan 模式下小助手可用 Core 的 `ask_user` 工具一次问一个或多个问题。

### 破坏性变更

- Conversation 在等待回答与计划确认期间默认隐藏主输入区，批准计划后自动关闭 `/plan` 与底部 Plan 提示。
  迁移：需要保留输入区的项目在通用 `userInput` 配置中显式声明。
- Conversation 移除输入开关与自定义主字段，附件声明改到 `conversation.attachments`，旧配置在结构校验时报错。
  迁移：附件改用 `conversation.attachments`，参数只保留 Auxiliary / Quick / Mode / Slash。

- 变更 模式改由单个 `/plan` 开关控制，默认 Build，Plan 开启时在输入框外下方显示提示。
- 变更 生成规范同步通用 Slash 参数、执行命令与输入框外下方的条件文字协议。

- 变更 生成规范支持 Core 标准输出的圆环展示并固定在输入栏右侧，不再为 `context` 添加宿主逻辑。
- 变更 AI 与权限入口改用图标加当前选择展示，窄宽度下优先收起右侧入口文字。
- 变更 默认 Auto approve 允许访问工作区外的文件夹。
- 变更 提示词与 Studio Control 跟随本轮权限，Workspace 与 Read only 保留目录范围限制。
- 变更 默认宿主改为 Studio VS Code 并使用独立工作目录，保留 Core 编码工具、Skills、长期记忆与资源卡。
- 变更 生成规范同步方法注册、注销、取消与超时后的状态查询要求。

- 变更 Kanban skill 用展示模式 API 区分小卡片与设备尺寸，只读卡片只呈现内容并保留编辑状态。
- 变更 Kanban 生成 skill 适配全屏、手机、平板与对话小预览，按 iframe 宽高重排并保留草稿与上传状态。

- 变更 `dependency-config` 先校验 `release.dependencies` 的 `included` / `external` 取值与 alias 匹配。
- 变更 声明关联项目依赖的项目通过 CLI 项目组流程固化版本与 source hash。

- 变更 环境不满足时保留真实错误，不换 registry、不手工塞包、不改源码绕开缺失依赖。
