# Unreleased

- 【改进】配置工具说明集合和配置级能力、固定模式及联网角色校验，面板关闭时仍遵循相同权限。

- 【新增】配置工具支持发布草稿、接收者预览和字段权限查询，保留项目范围、版本检查及只读模式约束。

- 【新增】提供配置查询、管理、导入导出和打开面板工具，显式指定项目、存储位置、配置 ID 与版本；只读模式拒绝修改，配置操作不依赖面板。

### 变更

- 项目清单声明静态 Workflow 类型，支持服务器静态源码校验。

### 新特性

- **作为普通 Workflow 运行**：Studio Control 可在 Studio 中作为普通 Workflow 项目运行全部入口并自动连接宿主。
- **VS Code 标准 MCP 控制面**：提供工作区状态、文件定位、诊断、主题、终端和视图控制，并向小助手暴露标准 MCP。
- **关联项目查询**：`get_related_projects` 返回关联声明、名称、UUID、Studio 导入状态及目录。

### 新增

- 新增 `get_related_projects` 在每次调用时重新验证导入项目身份。
- 新增 支持工作区子目录，并以项目目录作为默认路径。
- 新增 关闭运行页面后撤销宿主连接。

### 变更

- 变更 目录访问跟随本轮 Permission，`auto` 可操作工作区外的本地目录，状态查询返回实际权限与访问范围。
- 变更 控制遵循工作区信任与工具权限，编辑器操作保留 Build/Plan 审批，会话关闭后撤销回环能力。

### 修复

- 修复 显式选主题时未使用手动模式且未更新已有工作区覆盖，出现返回成功但主题不变。
- 修复 主题颜色类型变化未在真实宿主上验证。
- 修复 MCP 省略关联项目目录时未回退到工作目录。
- 修复 MCP 非法可选路径被静默忽略。
- 修复 Studio 小助手丢失控制工具或模板权限默认值。
- 修复 诊断查询无法识别符号链接路径。
- 修复 异步打开文件后未重新校验宿主状态。
