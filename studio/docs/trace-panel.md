# 执行轨迹

底部的 **轨迹** 标签用于 Workflow 和 Conversation 项目。Kanban 继续使用 KV、知识库和终端。对话回复下方只保留一个轨迹入口，点击会选中对应对话和回复；Workflow 运行标题栏的轨迹入口选中对应运行。

面板包含项目、对话和运行选择，以及时长、轮次、调用三种视图。横向时间线使用执行事件记录的时间，区分输入、模型、工具、节点和输出；没有时间记录的内容仍保留在列表中。普通输出不会被计为模型调用。执行列表支持搜索原始参数、结果、错误和日志，点击记录展开详情，点击时间线定位记录。下拉框、搜索、模式切换和记录标签采用 VS Code 主题变量和 4px 圆角，适配浅色、深色、高对比度和窄面板。

数据直接来自项目 CLI 保存的运行事件和报告。运行期间同步更新，等待输入、失败和停止状态会保留。Workflow 历史轨迹使用独立只读请求，查看时不改变编辑区当前选中的运行。关闭项目后保留已加载的轨迹；重新打开时读取原有运行历史。小助手的轨迹在显式点击回复入口后显示，不影响普通文件夹默认只有终端的布局。

项目必须安装支持 `traceProtocolVersion: 1` 的 `@steamharness/cli`。旧版 CLI 在底部显示兼容提示，原有浏览器详情入口仍然可用。

`npm run test:trace-ui` 运行真实 Electron 回归验证，覆盖入口跳转、实时工具、停止、历史切换、重载、主题、窄布局和项目类型隔离。截图与结果保存到 `.studio/trace-panel/`。
