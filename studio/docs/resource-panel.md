# 数据库与资源管理

Studio 的数据库工具列出当前 Server 账号可访问的关系数据库与知识库。资源按类型与 UUID 合并，展示项目入口的别名引用。目录分页读取，账号切换取消旧请求并清空旧账号内容；迟到结果不能覆盖当前账号。

关系库由 `steamharness.database.ts` 与 `steamharness.schema` 定义。先生成描述符、申请资源并迁移，再在 Server 为账号、projectId、entryId、alias 绑定资源。知识库使用独立的 knowledgeBases 声明和 config.json 映射。绑定不授予资源权限，重绑、撤权和模型不匹配会使旧连接失败。

管理链接打开 Server Web，管理关系模型、数据行、知识文档、附件与账号授权；URL 不含账号 token。Studio 不再提供 KV 编辑器、本地数据库目录或 local/server KV 切换。底部保留终端与执行轨迹，持久数据由 Server PostgreSQL 管理；本机开发可以同时运行本地 Server 和 Docker PostgreSQL。

## 对话资源卡片

知识库、项目、文件和看板工具可返回资源卡片。卡片支持对话内预览、独立窗口与目标项目导航；原始调用详情可展开。看板预览保留配置与临时参数，关系查询走生成的 Browser 描述符和宿主代理，只读预览拒绝写入。

本地项目来源表示源码目录位置；资源内容仍从 Server 读取。账号切换、退出、项目位置变化或资源撤权后，旧内容与未完成读取失效。失败显示明确错误，并保留可恢复的草稿，不自动切换资源或本地后端。

## 验证

日常执行 `npm run check` 与 `npm run build:extension`，覆盖目录分页、身份变更、绑定竞态、卡片定位与代理授权。显式 UI 脚本使用隔离测试账号和本地 HTTP 测试 host；不得在日常检查中启动桌面窗口。静态检查和模拟响应不代表真实页面验收。
