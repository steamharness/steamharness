# 项目资源面板

Studio 底部默认保留 Terminal，隐藏 Problems、Output、Debug Console 和 Ports。识别到 `workflow`、`conversation` 或 `kanban` 项目后，显示 **KV** 和 **知识库** 标签；移除这些项目后，两个标签自动隐藏。独立的小助手不会触发项目资源面板。

两个面板共用项目选择。打开不同项目的编辑器时，资源面板跟随当前项目；也可在面板中主动切换。项目名称过长时截断显示，搜索框与工具按钮随宽度换行。宽面板采用左侧列表、右侧详情；窄面板在列表和详情之间切换，详情提供返回按钮。

## KV

可按项目或会话作用域筛选，搜索 Key 和值，每页显示 30 条。详情展示 JSON 值及更新时间，支持原生剪贴板复制。本地数据支持新增、编辑和删除；新增时拒绝覆盖已有 Key。会话作用域需要指定会话 ID。

服务器 KV 使用现有管理接口，支持查看、搜索、分页和删除。服务器数据由项目运行时写入，因此面板不显示服务器 KV 的编辑入口，新增按钮处于禁用状态。

## 知识库

支持文档列表、全文搜索、Markdown 预览，以及新建、修改和删除。搜索结果显示匹配行号，点击后展示完整文档。本地和服务器文档使用同一套界面；删除通过 VS Code 原生确认对话框确认，切换或关闭编辑状态前提示未保存的修改。

## 对话资源卡片

成功的 KV、知识库和项目工具调用直接显示为占满消息列的卡片，长标题换行；调用参数和原始结果可通过详情按钮展开。点击资源名称定位到相应面板或编辑器，卡片操作支持对话内预览、独立窗口预览和打开目标项目。看板预览保留引用的配置和临时参数，不覆盖保存的配置。

有访问权限的其他项目资源也能预览。本地项目需要先打开或导入，服务器资源使用当前登录账号校验访问；拒绝访问、资源删除或目标不可用时显示具体错误。跨项目 KV 和知识库面板以只读方式打开，支持查看和搜索，即使目标项目已经在当前工作区打开。切换到目标项目的编辑器或从该项目自己的卡片进入时，恢复其正常资源操作。

退出、切换账号或导入项目目录变更时，已打开的卡片预览会清除旧内容并提示重新打开；尚未完成的读取结果也会丢弃。重新验证同一账号不会使远程看板资源失效。

## 数据来源

当前入口的 `databases` 声明决定可用别名，每个别名明确指定 local 或 server 宿主。面板仅访问已审批且有效的绑定；未绑定时先通过数据库管理申请并绑定，不自动创建或回退数据库。服务器请求使用 Studio 当前登录凭据，退出或切换账号时取消未完成的请求并刷新面板。

本地面板调用项目已安装的 `steamharness` 公共存储 API，与项目 CLI 使用同一目录：

```text
<Studio globalStorage>/workflow/web/<projectKey>/kv/
<Studio globalStorage>/workflow/web/<projectKey>/values/
```

`projectKey` 是项目真实路径的 SHA-256 前 24 位；`values` 中保存 Core 的知识库 PersistentValue 数据。不同项目路径和项目 ID 的数据保持隔离。项目需要安装依赖，面板不借用工作站或其他项目的 Core。

资源操作由短生命周期的 Node Worker 执行。切换项目、退出账号或关闭工作区时取消旧请求；迟到的返回值不会更新新项目。Worker 支持 Studio 内置扩展的软链接启动路径。

## 样式与验证

控件使用 VS Code 主题色、Codicons、统一的 4px 控件圆角和聚焦边框，适配浅色、深色及高对比度主题；选中列表项、详情工具栏与窄面板保持相同的控件尺寸。

`npm run check` 包含资源宿主、真实 Core 存储和服务器接口契约测试。安装 `examples/conversation` 的依赖后可执行真实本地存储测试；未安装时这些集成测试会明确跳过。

`npm run test:resources-ui` 使用独立 Electron 窗口，验证普通文件夹仅显示终端、三种项目识别、KV 编辑与分页、知识库预览与全文搜索及创建、主题和窄布局、跨面板项目同步，以及移除项目后的标签隐藏。截图和检查记录输出到 `.studio/resources-panel/`，测试结束后清理临时工作区。服务器接口契约测试使用模拟响应，不代表真实服务器验收。

`npm run test:resource-cards-ui` 在中英文 Electron 窗口中检查卡片直接展示、整行宽度、窄布局、主题同步、资源定位、独立窗口和真实看板产物。跨项目服务器资源和权限拒绝使用本地模拟服务器验证。截图和检查记录位于 `.studio/resource-cards/`。

设置 `STUDIO_CARD_PROJECT_DIR=/absolute/path/to/conversation-project` 可验证实际项目的清单与已安装 CLI。测试在临时工作区中复制源码并生成测试会话，不调用模型；知识库列表和文档卡片覆盖工具未提供显式 `cardId` 的情况。检查记录会包含实际 CLI 版本、项目 ID 和关联数据库 ID，以便确认依赖更新已经生效。
