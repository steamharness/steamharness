- 【改进】统一项目 Node 运行时选择、版本校验和环境传递，支持可选的宿主工具链与本地路径；运行时切换对新会话生效，既有服务恢复保留原环境。开源版不下载或携带 Node。

- 【改进】CLI Web 导出对话、单条消息或工作流记录时使用原生保存窗口；文件写入成功后在右下角显示保存路径，取消保存保持安静，保存失败显示错误通知。
