# Unreleased

- 【改进】Steam 右侧工具区首次打开默认占窗口三分之一，拖动后的宽度按工作区保存，隐藏重开、模式往返和重载均恢复；窗口临时缩窄不会覆盖用户偏好。

- 【新增】Studio Control 可查询配置权限、预览与管理作者发布草稿，沿用只读策略；本地配置 RPC 使用当前登录连接，发布同步检查配置草稿版本。

- 【修复】Steam 项目配置、字段编辑、重命名及项目信息等弹窗避让顶部窗口按钮和模式切换控件；适配菜单和工具区显隐、窄屏及矮窗口，保留关闭和配置保存操作。

- 【修复】小助手输入区适配较矮窗口和长文本，默认工具与新建标签均保留完整的底部操作栏，避免输入框及发送按钮被工具区底边遮挡。

- 【新增】Steam 工具区增加原生编辑器，项目文件统一放入下层标签；资源管理器、搜索和源代码管理等入口在编辑器右侧展示，支持拖动调整宽度、新建文件、保存和未保存关闭确认，工具切换与返回 IDE 保留文件状态。

- 【改进】Steam 工具栏移除重复的「打开工具」，左侧提供新建入口，右侧只保留工具区显隐按钮；项目与工具顶部导航栏的空白区域支持拖动应用窗口，按钮、标签和可复制文字正常操作。

- 【新增】Steam 工具区采用圆角标签，支持名称缩略、新增和关闭；标题栏最右侧保留工具区显隐按钮。工具扩充为十项，终端、浏览器和其它项目均在右侧打开，隐藏工具区及模式往返保留会话，重载后恢复原先选中的工具编辑器和左侧运行项目。

- 【新增】Steam 右侧工具工作区支持动态标签、关闭和「＋」打开工具；账号、文件、设置、Diff 和其他编辑器统一在右侧打开，保留左侧项目运行页面与结果。切回 IDE 时保留未保存文档，并支持重载恢复工具编辑器。

- 【修复】启动准备按锁定的上游提交识别已有补丁，避免工作区本地修改导致重叠补丁被误报冲突，并保留暂存和未暂存的修改。

- 【修复】IDE / Steam 切换固定操作主窗口，恢复最大化面板和编辑器分组；保留工具位置偏好，忽略过期的启动失败，并避免动画被跳过时出现未处理错误。

- 【新增】三类项目复用通用配置面板，与独立 CLI 共享本地存储；Studio Control 支持关闭面板时查询、完整管理和导入导出本地或 Server 配置，沿用项目范围与只读权限校验。

### 打开项目

- 最近项目、File 菜单、Ctrl+R、打开文件夹/工作区、关联项目、资源卡片、下载/导入及安装重试统一选择在新窗口或当前窗口打开；取消选择不会切换窗口或开始安装。

### 项目头像

- 开始页、最近项目、项目列表、关联项目、项目信息、运行标签和项目选择器统一显示项目的图标与配色；新建项目自动保存清晰可辨的随机头像。
- 修复模板使用依赖版本范围导致新建项目失败的问题，改为捆绑精确兼容版本。

### Pi Durable

- Trace 完整接管持久 Agent 的任务、计划、记录和用量，保留原时间线、搜索与历史；支持任务详情、子对话/分叉来源、计划版本更新、压缩/重置及分范围停止。默认跟随当前对话，历史选择与正文独立，保留滚动/展开/焦点并禁用离线操作；适配双语、深浅主题和窄面板。

- 内置小助手同步持久 Agent 版本，启用进程恢复、Trace 任务视图、排队与引导、受限子 Agent、计划和父子用量；Studio Control 延迟连接，Code Mode 仍须宿主显式开启，界面沿用 VS Code 风格。

### 新特性

- **原生开始工作台**：空编辑器组和可恢复的开始标签页共用同一入口，提供新建项目、离线示例与系统状态。
- **内置 Studio 分析看板**：汇总已导入本地项目、实时运行状态与历史记录，提供统计图、趋势、筛选明细和 CSV 导出。
- **小助手斜杠命令**：`/plan` 切换计划模式，`/export` 导出全部会话记录，`/compact` 立即总结上下文。
- **项目创建先开窗口**：新建项目和示例先在新 Studio 窗口打开，依赖安装在该窗口内完成。

### 破坏性变更

  迁移：删除项目清单中的输入开关与自定义主字段声明，并把附件能力声明为 `conversation.attachments`。

- 新增 分析看板汇总已导入本地项目、实时运行状态和历史记录。

### 变更

- 变更 新建项目模板显式声明静态项目类型，内置小助手与 Studio Control 同步项目存储契约；上传到服务器时只保存源码与数据。
- 变更 Untitled 恢复原生空白文本编辑行为；双击编辑器背景或标签栏空白处不再自动新建文件，命令与快捷键仍可新建。
- 变更 最近项目、Ctrl+R 打开最近、工作区和关联项目列表按类型显示统一图标。
- 变更 项目与模板选择器复用同一套类型图标，普通目录和工作区保留原图标。
- 变更 新建项目和示例合并为一个创建弹窗，可选类型、模板、名称和目录。
- 变更 默认存放目录为用户主目录下的 `Documents/steamharness-projects`。
- 变更 创建前可选择在新窗口或当前窗口打开，取消选择不会生成文件。
- 变更 依赖改为在目标项目窗口打开后安装，进度和日志不再占用创建窗口。
- 变更 当前项目改为卡片，展示名称、类型、路径和运行按钮。
- 变更 取消安装或安装失败后重新加载项目，不再自动重装依赖。
- 变更 开始工作台的图标、文字、操作按钮与状态行对齐。
- 变更 最近项目的移除按钮仅在悬停或键盘聚焦时显示，并保留占位避免布局跳动。
- 变更 手动上下文总结覆盖全部已有上下文，失败、截断或取消时保留原始记录。
- 变更 上下文总结请求上报本次总结使用的模型用量。
- 变更 小助手权限入口单击展开 Read only、Workspace 和 Auto approve，选择后关闭菜单。
- 变更 Quick 入口显示图标与当前选择，窄宽度下从右到左收起文字并保留悬停提示。
- 变更 小助手默认使用 Build，通过单个 `/plan` 开关切换并在输入框外展示 Plan 模式。
- 变更 Conversation 附件能力改为 `conversation.attachments`，内置小助手与生成器协议同步。
