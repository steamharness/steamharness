# Local packaging and versions

To create a project archive, run this command in the project directory:

```sh
pnpm exec steamharness workspace pack <project-id> --path . --output project.tgz
```

An aggregate project has one version. Its archive includes every registered entry. Packing checks the UUID, version, and files declared in `steamharness.json`. It does not require a platform account or upload the archive.

To share the archive, send it to a collaborator, who can extract it and open the project folder in Studio. To preview a release locally, choose **Run (Release Mode)** from the Studio Command Palette. To manage remote versions, use the [online Workspace CLI](/en/cli/server-workspace) or enhanced Studio.
