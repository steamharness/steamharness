# Fresh aggregate declarations

The current model requires fresh declarations and data. It does not provide legacy reads, automatic migration or data import.

```json
{
  "id": "00000000-0000-4000-8000-000000000001",
  "name": "workspace-example",
  "version": "1.0.0",
  "private": true,
  "type": "module",
  "steamHarness": {
    "defaultEntry": "agent",
    "entries": [
      {
        "entryId": "agent",
        "type": "conversation",
        "name": "Assistant",
        "root": "agent",
        "entry": "index.ts",
        "databases": []
      },
      {
        "entryId": "database",
        "type": "workflow",
        "name": "Database operations",
        "root": "database",
        "entry": "index.ts",
        "configuration": "configuration.json",
        "databases": [
          {
            "alias": "data",
            "host": "server",
            "permissions": {
              "kv": {
                "read": {
                  "mode": "all"
                },
                "write": {
                  "mode": "all"
                }
              },
              "knowledge": {
                "read": {
                  "mode": "all"
                },
                "write": {
                  "mode": "all"
                }
              }
            }
          }
        ]
      },
      {
        "entryId": "map",
        "type": "kanban",
        "name": "Map",
        "root": "map",
        "entry": "dist/index.html",
        "databases": []
      }
    ]
  }
}
```

Keep business code directories and register them in root entries. Remove child SteamHarness identities. Executor `projectType` still describes the entry runtime contract; the root package has no single type.

Use `context.entries.get(entryId)` for Workflow calls and `context.databases.get(alias)` for approved spaces. Request each entry's new space separately, and request existing-space access for sharing.

When cleaning old identities, limit deletion to their old-model records. Do not clear unrelated host business data. The new project does not read old data. See [Workflow model](/en/concepts/workflow-model) and [Database spaces](/en/concepts/data-storage).
