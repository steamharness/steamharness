## npm packages

The public packages are [`steamharness`](https://www.npmjs.com/package/steamharness) and [`@steamharness/cli`](https://www.npmjs.com/package/@steamharness/cli). Check installed versions in the project directory:

```sh
pnpm list steamharness @steamharness/cli --depth 0
```

Projects pin exact versions. Check [compatibility](/en/guides/releases/compatibility) before upgrading.

## Current deployment

Read the target Server's `/health` and inspect product version, `deploymentId`, and `commitSha`. A product version can be deployed more than once. The response also provides full release notes and a localized documentation link.

## Public entry points

Use the service addresses configured by your Server and Studio. See [environments and updates](https://docs.steamharness.yuhe.space/en/enhanced/management/deployment) for the enhanced edition or [deployment](/en/guides/server/deployment) for self-hosting.

## Stable artifacts

Use the package registry's release information for npm packages. Built-in projects use their release indexes: `builtin-projects/<project>/index.json` for production and the neighboring `alpha/index.json` for alpha. Check channel, version, and integrity before downloading.

Version detail pages preserve their historical release facts. See the [complete index](/en/guides/releases/changelog).
