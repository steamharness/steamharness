# Core v0.2.8

2026-11-26

#### Added

- In supported local hosts, Agent Bots can use saved credentials by alias for restricted HTTPS or SSH queries. Secret values do not enter the conversation. {/* note: protected-bot-credential-queries */}
- In Workspace permission mode, a query approval can be reused in the same conversation for the same credential and parameters. Changing credentials, switching conversations, or restarting Studio requires approval again. {/* note: scoped-bot-credential-approvals */}
