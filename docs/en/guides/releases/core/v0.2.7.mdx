# Core v0.2.7

2026-11-26

#### Added

- Bots can ask to save a structured credential with multiple fields. In supported hosts, they can also request read-only Alibaba Cloud DNS queries by credential alias without receiving the secret values. {/* note: structured-bot-credentials */}

#### Changed

- Bots treat remembered deployment locations, configuration, and runtime status as historical information and recheck the current state before acting on it. {/* note: bot-memory-current-state */}
