# Server unreleased

#### New Features

- **Kanban page method injection**: injection supports method registration and disposal, catalogs, JSON results, and cancellation. {/* note: draft-57 */}
- **Kanban presentation bridge**: the bridge exposes `getPresentation()` and presentation change events for full screen, phone, tablet, and conversation cards. {/* note: draft-58 */}

#### Breaking Changes

- Breaking: registered entry types are workflow, bot and kanban; old conversation declarations are rejected, and uploads and distribution use the new static contract. {/* note: draft-11 */}
  Migration: Update the affected project declarations or clients to the contract described above before upgrading.
- Breaking: project identity, name, version and declarations now use independent `steamharness.json` files. Removed reads and writes of `package.json.id` and `steamHarness`. Aggregates explicitly register child entries whose configuration defines icons, declarations and schedules. Unregistered configurations stay inactive, and transfers preserve the parent and child structure. {/* note: draft-28 */}
  Migration: Update the affected project declarations or clients to the contract described above before upgrading.
- Breaking: project and version APIs return aggregate entries with separate configurations. Related-project APIs are removed; Server remains a static source host. {/* note: draft-30 */}
  Migration: Update the affected project declarations or clients to the contract described above before upgrading.
- Project endpoints moved from `/api/workflows` to `/api/projects`; `workflowId` / `workflowName` are now `projectId` / `projectName`, and `X-Workflow-Locale` is now `X-SteamHarness-Locale`. {/* note: draft-52 */}
  Migration: Update the affected project declarations or clients to the contract described above before upgrading.
- Audit event types `workflow.*` are now `project.*`; the object-storage prefix and on-disk data directory are `projects/`. {/* note: draft-53 */}
  Migration: Update the affected project declarations or clients to the contract described above before upgrading.

#### Added

- Added method registration and disposal, catalogs, JSON results, and cancellation to the Kanban injection API. {/* note: draft-59 */}
- Added `getPresentation()` and presentation change events to server Kanban pages, covering full screen, phone, tablet, and conversation cards. {/* note: draft-60 */}
- Added project-bound file create, read, and delete on the Kanban bridge, up to 50 MiB, rejecting other projects and conversation attachments. {/* note: draft-61 */}
