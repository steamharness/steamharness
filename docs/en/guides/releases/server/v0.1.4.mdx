# Server 0.1.4

2026-08-07 · Tag `server/v0.1.4` · 当前设备

<span id="server-0-1-4" className="release-version-anchor"></span>
<span id="server.0.1.4" className="release-version-anchor"></span>

#### New Features

- **Request-scoped runtime language**: first-party APIs read `X-SteamHarness-Locale` and inject the run language into the console, Embed, Webhooks, and parameter parsing. {/* note: entry-1 */}
- **Version-scoped read-only KV sources**: Kanban Studio and Embed refresh over authenticated revision SSE and drop the source as soon as access is revoked. {/* note: entry-2 */}
- **Workflow schedules**: fixed-version, fixed-entrypoint plans, common time rules, run-now, and fire history. {/* note: entry-3 */}

#### Added

- Added first-party API errors, health summaries, and a standalone Server release log in the requested language. {/* note: entry-4 */}
- Added entrypoint selection and stored entrypoint snapshots for the console, Embed, External, streaming, parameter, and Webhook APIs. {/* note: entry-5 */}
- Added rejection of invalid entrypoints before enqueueing or sending streaming response headers. {/* note: entry-6 */}
- Added read-only Workflow KV sources authorized by exact version and key prefix for Kanban Studio and Embed. {/* note: entry-7 */}
- Added exact dependency locks, resumable deployment, partial source download, source requests, and prefix-scoped data grants for Kanban project groups. {/* note: entry-8 */}
- Added refusal to transfer KV, plans, run history, environment variables, or client credentials to project groups. {/* note: entry-9 */}

#### Changed

- Changed the scheduler to prevent duplicate multi-instance runs through unique fires, leases, permission rechecks, and graceful shutdown. {/* note: entry-10 */}
- Changed plans to reject edits and deletion while a fire is active. {/* note: entry-11 */}
- Changed the Kanban revision stream to merge bursts, keep PostgreSQL reconnect order, and close cleanly when the source is unavailable. {/* note: entry-12 */}
- Changed Server to exit normally after the revision stream signals completion. {/* note: entry-13 */}

#### Fixed

- Fixed cloud Kanban subresources returning 401 or 500, which blanked the screen; short-lived capabilities now scope to project and expiry. {/* note: entry-14 */}
- Fixed remote run streams occasionally corrupting Chinese and other multi-byte characters at segment boundaries. {/* note: entry-15 */}
- Fixed `source` mode Kanban being reported missing in public Embeds. {/* note: entry-16 */}
- Fixed default config initialization failing the first time a PostgreSQL user opened an Embed. {/* note: entry-17 */}
- Fixed Workflow runtimes writing dev tooling and pnpm symlinks into archives, which made published versions unloadable from object storage. {/* note: entry-18 */}
