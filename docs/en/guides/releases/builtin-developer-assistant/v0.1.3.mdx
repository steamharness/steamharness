# 开发者小助手 0.1.3

2026-08-24 · Tag `builtin-developer-assistant/v0.1.3` · 内置项目更新

<span id="builtin-developer-assistant-0-1-3" className="release-version-anchor"></span>
<span id="builtin-developer-assistant.0.1.3" className="release-version-anchor"></span>

#### New Features

- **V2 workspace manifest**: Workflow projects and ordinary folders can both be the primary target, with linked folders authorized through typed roots. {/* note: entry-1 */}
- **Multi-project coordinated edits**: changes span the primary project and recursively linked projects, while unavailable branches only warn. {/* note: entry-2 */}

#### Added

- Added the V2 workspace manifest with Workflow projects or ordinary folders as primary targets and typed linked roots. {/* note: entry-3 */}
- Added reading of Desktop-validated multi-project manifests to coordinate edits across primary and linked projects. {/* note: entry-4 */}
- Added continued reading of legacy V1 project manifests. {/* note: entry-5 */}

#### Changed

- Changed multi-workspace authorization to require OpenCode 0.1.8 or later, which installing the assistant now enforces. {/* note: entry-6 */}
