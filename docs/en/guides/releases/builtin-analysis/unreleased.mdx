# Analysis unreleased

#### New Features

- **Local analytics dashboard**: charts, run trends, activity lists, and filterable exportable detail tables built from real project and run data. {/* note: draft-5 */}

#### Breaking Changes

- Breaking: project identity, name, version and declarations now use independent `steamharness.json` files. Removed reads and writes of `package.json.id` and `steamHarness`. Aggregates explicitly register child entries whose configuration defines icons, declarations and schedules. Unregistered configurations stay inactive, and transfers preserve the parent and child structure. {/* note: draft-2 */}
  Migration: Update the affected project declarations or clients to the contract described above before upgrading.

#### Added

- Added a local Studio analytics dashboard aggregating real project and run data. {/* note: draft-6 */}
- Added charts and run trends to the analytics dashboard. {/* note: draft-7 */}
- Added activity lists to the analytics dashboard. {/* note: draft-8 */}
- Added detail tables exportable to CSV by filter. {/* note: draft-9 */}

- Declare analysis dashboard fields in `configuration.json` and manage actual values through project configurations. {/* note: draft-4 */}
