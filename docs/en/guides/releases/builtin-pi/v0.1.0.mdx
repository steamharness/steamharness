# Pi release notes v0.1.0

#### Changed

- The original notes for the first version described it before publication. {/* note: first-version-preview */}

#### New Features

- **Built-in Pi project**: a coding agent driven by the pi agent SDK; you assign tasks in the conversation and the process and result stay in the transcript. {/* note: entry-1 */}
- **`--agent` plan then build**: plan only researches and proposes, and once you approve it the same session switches to build. {/* note: entry-2 */}
- **`--effort` reasoning effort**: seven levels from off to max, defaulting to high, with unsupported levels converging automatically. {/* note: entry-3 */}

#### Added

- Added the built-in Pi project, a coding agent driven by the pi agent SDK. {/* note: entry-4 */}
- Added task assignment in the conversation: the agent reads and writes files in the working directory, runs commands, and leaves both process and result in the transcript. {/* note: entry-5 */}
- Added a reasoning-effort parameter (`--effort`) accepting off / minimal / low / medium / high / xhigh / max, defaulting to high. {/* note: entry-6 */}
- Added an unsupported `--effort` level converging to the nearest level the model supports, instead of failing. {/* note: entry-7 */}
- Added a permission-policy parameter (`--permission-policy`) accepting read-only / workspace / auto. {/* note: entry-8 */}
- Added read-only hiding the write tools, workspace (the default) asking for approval on every write, and auto running without asking. {/* note: entry-9 */}
- Added an agent-mode parameter (`--agent`) accepting build and plan. {/* note: entry-10 */}
- Added plan researching and proposing only, then asking you to approve the plan before the same session switches to build or keeps the plan unchanged. {/* note: entry-11 */}
- Added sending `/compact` or `/summarize` — or clicking the context usage in the conversation — to compact the current turn. {/* note: entry-12 */}
- Added replacing the older conversation with a model-written summary instead of prompting the model with it, and saying so when there is nothing to compact. {/* note: entry-13 */}
- Added tool calls, reasoning, context compaction and failures as collapsible detail rows, while the answer itself stays flat in the conversation body. {/* note: entry-14 */}
