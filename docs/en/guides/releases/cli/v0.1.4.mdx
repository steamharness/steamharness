# CLI 0.1.4

2026-08-24 · Tag `@steamharness/cli/v0.1.4` · npm

<span id="@steamharness/cli-0-1-4" className="release-version-anchor"></span>
<span id="@steamharness/cli.0.1.4" className="release-version-anchor"></span>

#### New Features

- **Platform-aware downloads**: `workspace download` sends the current platform and resolves `latest` to that system's newest compatible version. {/* note: entry-1 */}
- **Per-version release targets**: `workspace upload/publish` select a Server runtime and Desktop download target per immutable version. {/* note: entry-2 */}

#### Breaking Changes

- The Desktop local runtime event variable is now `STEAMHARNESS_DESKTOP_RUNTIME_EVENTS`. {/* note: entry-3 */}
  Migration: the former `STEAMHARNESS_APP_RUNTIME_EVENTS` variable is no longer accepted.
