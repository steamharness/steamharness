# Server Web unreleased

#### Breaking Changes

- Breaking: project management displays registered entries, the default entry and separate configurations. {/* note: draft-13 */}
  Migration: Update the affected project declarations or clients to the contract described above before upgrading.

#### Changed

- Keep the account security title and card placeholders visible while loading. Show retry or sign-in actions after a load failure or an expired session. {/* note: draft-1 */}
- Submit account security changes directly without a current-password or current-email verification step. Email binding, verification, and changes still require the target email code. Password and username settings remain available when mail is unavailable. {/* note: draft-2 */}
- Default account avatars use colors suited to light and dark backgrounds, keeping the same pattern and colors when switching themes. {/* note: draft-3 */}
- Separate account security actions for binding, verifying, changing, and unbinding email, passwords, and usernames. Submit changes directly; cancellation clears sensitive forms, with explicit code purposes and unbinding requirements. {/* note: draft-4 */}
- Fixed account security navigation, manual device authorization, and account switching. Registration and recovery confirm passwords, failed requests can be retried, and security changes explain when to sign in again. {/* note: draft-5 */}
- Added registration, recovery and account security pages. Device approval shows the current account and app channel, with a return link for Studio or CLI Web. Profiles have generated geometric avatars. {/* note: draft-6 */}
- Project type labels now use Bot. {/* note: draft-7 */}
- Removed global and account memory, including tools, skills, authorization, service integration and settings controls. {/* note: draft-8 */}
- Added: Project configuration selects one subagent model from existing AI models, with inheritance, permission restrictions and unavailable-selection feedback. {/* note: draft-9 */}
- Fixed sign-in depending on project and release data. Project load failures preserve authenticated sessions and show a workspace error with refresh recovery. {/* note: draft-10 */}
- Project model creation offers only System AI and Third-party AI; removed references to Settings models. {/* note: draft-11 */}
- Improvement: Aggregate entry lists display each entry’s declared icon and foreground/background colors. Entries do not own independent versions. {/* note: draft-12 */}
- Improved avatar previews in user management and profile dialogs: click to view a larger image that fits the viewport, then return keyboard focus to the avatar on close. Existing upload, profile, menu and project navigation actions are preserved. {/* note: draft-14 */}
- Fixed avatar crop previews to fit the dialog proportionally, keeping small images usable and portrait images within the preview height. Show a loading placeholder while reading images. {/* note: draft-15 */}
- Added fixed 1:1 avatar cropping in profile settings and user management, with movable, resizable, resettable selections and automatic compression before upload, without restricting source file size. Account menus, user lists, memberships, audit entries and profile details use consistent rounded square avatars, centering existing images without stretching. {/* note: draft-16 */}
- New projects use the ID assigned by the Server; the browser no longer generates or submits a client-selected ID. {/* note: draft-17 */}
- Fixed: Standalone Web proxies follow the service channel and use localhost:7126 in dev instead of the PostgreSQL port. {/* note: draft-18 */}
- Fixed: deployments include localized Server and Web notes with source identity; health links use the current environment. {/* note: draft-19 */}
- Added mode capability and minimum-role labels to configuration lists. Guests see accessible base profiles, with collection and field management hidden and fixed modes read-only. {/* note: draft-20 */}
- Highlight the configuration in use with a clear badge and provide Use this configuration buttons for other profiles. Keep list and detail usage in sync, preserve selection on failure, and retain drafts during external switches. {/* note: draft-21 */}
- AI configuration honors source-declared allowThirdParty restrictions, hides source switching for system-only projects, and marks existing third-party entries unavailable for cleanup. {/* note: draft-22 */}
- Improved model editing with a separate dialog and segmented source selection. System AI only needs Provider and model selections and generates names automatically. Fields and model lists have clearer borders, and the lone Configuration values tab is hidden without publication management. {/* note: draft-23 */}
- Added system and third-party model management in configuration details, with exclusive source forms, on-demand subscription catalogues, model CRUD, default ordering, draft protection and read-only permissions. {/* note: draft-24 */}
- Added group and subgroup navigation, ownership selection and direct/inherited member management. Effective capabilities control upload, publication, configurations, data and settings. Removed global role editing and added guest requests from private share links. {/* note: draft-25 */}
- Improved: project configurations open with a profile list and separate detail views for values and publication rules. Browsing preserves execution selection, and back navigation protects unsaved drafts. {/* note: draft-26 */}
- Improved: project configurations use responsive columns and inline boolean controls without stretched checkboxes. Publication permissions use aligned table columns, a compact profile/action toolbar, and expandable JSON paths. {/* note: draft-27 */}
- Added a publication and permissions tab with profile/default selection, recipient previews, JSON child editors and lock reasons; conflicts preserve edited drafts. {/* note: draft-28 */}
- Edit project configuration fields directly without a Set value checkbox. Reset icons restore defaults or clear overrides; boolean and multiple-choice controls retain their checkboxes. {/* note: draft-29 */}
- Fixed: project configuration file fields choose and upload files to Server storage, then save references. Type restrictions, replacement and clearing preserve the previous value when uploads fail. {/* note: draft-30 */}
- Separate configuration management, fields and saving. Group secondary actions in icon menus, show export details with those actions, and use labeled icons for custom field editing and draft refresh. {/* note: draft-31 */}
- Ignore save responses from a previous project visit to preserve current drafts, and allow repairing previous non-array values after a field changes to multiple options. {/* note: draft-32 */}
- Add project configurations to all project detail pages, with field/value editing, profile management, import/export and recovery for conflicts, failed saves and empty states. {/* note: draft-33 */}
- Project list avatars open their projects; standalone avatars support previews. User avatars open the displayed profile, and personal profile avatars select an upload, with keyboard focus restored on close. {/* note: draft-34 */}
- Project lists, detail headers, overviews, and settings consistently display avatars from the projectCard icon and colors. {/* note: draft-35 */}
- Changed Settings and Admin Center to expand submenus in the main sidebar, retaining Project Workbench and other entries while switching pages and filtering admin entries by permission; project details keep dedicated navigation. {/* note: draft-36 */}
- Changed the console to shadcn Blocks and New York components, unifying navigation, tables, forms, dialogs and themes while removing private styling and notifications. {/* note: draft-37 */}
- Removed the invitations block from the project members page; invitations are created, listed and revoked from the dedicated Invitations section. {/* note: draft-38 */}
- Changed the console to remove execution statistics, logs, schedules, environment variables, Webhook and Runner pages while retaining project and data management. {/* note: draft-39 */}
- Changed role descriptions to project and data permissions, removed obsolete execution types and copy, and added bilingual data write descriptions. {/* note: draft-40 */}
- Changed the project information card on the project overview and Settings pages to label the project creator instead of the uploader. {/* note: draft-41 */}
- Removed the Back to project workbench entry from the top of the sidebar; the brand entry returns to the project list instead. {/* note: draft-42 */}

#### Fixed

- Fixed Admin Center navigation for accounts limited to role or audit viewing permissions. {/* note: draft-43 */}
- Fixed version and member summaries loading when opening project details or switching tabs, while ignoring stale responses after navigation. {/* note: draft-44 */}
