# Server Web 0.1.4

2026-08-07 · Tag `server-web/v0.1.4` · 当前设备

<span id="server-web-0-1-4" className="release-version-anchor"></span>
<span id="server-web.0.1.4" className="release-version-anchor"></span>

#### New Features

- **Interface language follows the system**: the console and public Embed offer three language settings, and summaries and log links follow the active one. {/* note: entry-1 */}
- **Collapsible entrypoint lists**: Webhook settings load and validate the target catalog, and results, history, and replay show the actual entrypoint. {/* note: entry-2 */}
- **Schedule workspace**: manage exact-version and entrypoint plans, preview triggers, run now, and inspect fire history. {/* note: entry-3 */}

#### Added

- Added Follow system, Simplified Chinese, and English settings to the console and public Embed, with summaries and log links following the active language. {/* note: entry-4 */}
- Added collapsible Workflow entrypoint lists to the console and public Embed, with Webhook settings loading and validating the target catalog. {/* note: entry-5 */}
- Added the Kanban Bridge reading authorized Workflow KV sources by static alias and subscribing to revisions, without exposing source identifiers or write access. {/* note: entry-6 */}
- Added a Workflow schedule workspace for exact-version and entrypoint plans, trigger previews, run now, fire history, and scheduled-source filtering. {/* note: entry-7 */}
- Added dependency and permission workspaces with data-grant editing, short-lived source requests, consumer search, and approval or revocation. {/* note: entry-8 */}

#### Changed

- Changed the project workspace to sort by update time with the most recently updated projects first. {/* note: entry-9 */}
- Changed run replay and public Embed to redesign reasoning, tools, tasks, files, retries, and errors, following streams reliably at the bottom. {/* note: entry-10 */}
- Changed multi-entrypoint views to use compact headers and aligned forms, retaining Form or Raw mode and current input during updates. {/* note: entry-11 */}

#### Fixed

- Fixed manually collapsed default entrypoints reopening, host rerenders resetting input, and late errors from an old target appearing on the current one. {/* note: entry-12 */}
- Fixed Kanban refreshing twice after the initial snapshot, entrypoint failures hiding every schedule, and schedule actions accepting rapid duplicates. {/* note: entry-13 */}
