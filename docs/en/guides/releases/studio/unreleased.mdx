# Studio unreleased

#### New Features

- Open **Project Details → Bot Management** to view and edit memories for the main Bot or an instance, or find previously delivered files in the artifact library. Check the selected Bot and memory directory before editing. {/* note: bot-management-local-library */}
- Local Studio can manage a separate credential vault for each Bot. Credentials are entered in a native window and are excluded from project and conversation exports. Secure input is unavailable in paired Web, IM, and background runs. {/* note: native-bot-credential-vault */}
- Save Workflow form drafts and create schedules on supported local hosts. {/* note: studio-local-workflow-drafts-and-schedules */}
- Hosted Web applications can connect to a service based on the selected project configuration. Switching configurations closes old connections and updates the sign-in action. This requires a compatible CLI and service provider. {/* note: web-app-selected-configuration */}
- **Native Start workbench**: empty editor groups and a restorable Start tab share one entry offering new projects, offline examples, and system status. {/* note: draft-85 */}
- **Built-in Studio Analysis**: summarizes imported local projects, live run states, and histories with charts, trends, filtered tables, and CSV export. {/* note: draft-86 */}
- **Assistant slash commands**: `/plan` switches to plan mode, `/export` exports every session record, and `/compact` summarizes context immediately. {/* note: draft-87 */}
- **Projects open a window first**: new projects and examples open in a new Studio window where dependencies are installed. {/* note: draft-88 */}
- LLM Bot model nodes show **Input**, **Model request**, **Output**, and **Execution information** in that order, all collapsed by default. Expand **Model request** to inspect each request in the turn, including its system prompt, messages, and model parameters. Conversation exports omit these details. {/* note: llm-bot-model-request-trace */}

#### Breaking Changes

- Breaking: project creation, discovery and type labels now use Bot, with templates built directly on Core Agent and native conversation, Workflow and Kanban views. {/* note: draft-17 */}
  Migration: Update the affected project declarations or clients to the contract described above before upgrading.
- Breaking: project identity, name, version and declarations now use independent `steamharness.json` files. Removed reads and writes of `package.json.id` and `steamHarness`. Aggregates explicitly register child entries whose configuration defines icons, declarations and schedules. Unregistered configurations stay inactive, and transfers preserve the parent and child structure. {/* note: draft-40 */}
  Migration: Update the affected project declarations or clients to the contract described above before upgrading.
- Breaking: the project tree exposes aggregate entries in separate native tabs sharing one host. The host is released after its last tab closes. Transfers include the complete aggregate. {/* note: draft-51 */}
  Migration: Update the affected project declarations or clients to the contract described above before upgrading.
- Conversation always renders the standard message input and no longer accepts an enable setting or custom main fields, with attachments moved to `conversation.attachments`. {/* note: draft-89 */}
  Migration: drop the enable setting and custom main fields from the project manifest and declare attachments as `conversation.attachments`.
