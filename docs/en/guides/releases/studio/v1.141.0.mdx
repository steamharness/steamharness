# Studio v1.141.0

2026-11-24

#### Added

- The browser workbench can open projects on the host. A second device needs HTTPS and a one-time pairing code. Only pair devices you trust with access to the host's files and terminal. {/* note: paired-browser-workbench */}
- The project library distinguishes local projects, repositories, and built-in projects. It shows local usage and can open separate Bot workspaces for the same project. {/* note: studio-project-library */}
- New Bots offer Core Agent and Core LLM templates. Workflow Agent guides users through model selection on the first run. {/* note: studio-bot-templates */}

#### Fixed

- A local preview opened from the project library loads inside the current browser workbench. {/* note: local-web-preview */}
