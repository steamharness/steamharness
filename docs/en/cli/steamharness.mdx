# CLI and aggregate entries

Invoke the installed CLI from the aggregate root. Use Node.js 24 and install dependencies with the declared package manager. The root manifest and registered entries must be valid. Child directories do not own independent SteamHarness project identities.

```sh
pnpm exec steamharness check .
pnpm exec steamharness check . --entry database
pnpm exec steamharness structure . --entry database
pnpm exec steamharness run . --entry database --entrypoint search -- --query example
pnpm exec steamharness json . --entry database --entrypoint search -- --query example
pnpm exec steamharness web . --entry agent
pnpm exec steamharness mcp . --entry database
```

## Entry selection

`--entry` selects the window entry. `run`, `json`, `structure`, `mcp` and `web` default to `defaultEntry`. `check` inspects all entries unless `--entry` selects one. `--entrypoint` selects an operation inside a Workflow. Keep the two identifiers distinct.

Arguments after `--` pass unchanged to the Workflow. `--locale zh-CN|en` selects host text without altering business parameters.

## CLI Web

One root directory starts one aggregate host. The window selector beside the project name displays entry names, types and states. Each entry has an `/entries/<entryId>/` URL and independent controller. Switching preserves drafts, history and background runs.

Database management supports requests, approval, shared access, binding, narrowing, revocation, rotation and data management. Pending requests do not create spaces. See [Database spaces](/en/concepts/data-storage).

## Validation and output

`check` and `structure` statically inspect registered entries without executing user modules. Unsafe paths, duplicate IDs, invalid defaults, mismatched types and legacy declarations fail. `json` returns a run report with project and entry identity. Failed runs return a nonzero exit code. Cancellation propagates to the current execution and calls to other entries.

Use [workspace commands](/en/cli/server-workspace) for remote static project management. Server never executes project code.
