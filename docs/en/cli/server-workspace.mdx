# Server Workspace CLI

`steamharness workspace` manages project source and immutable Server versions. Dependencies, builds, and execution remain local; Server processes static archives.

## From sign-in to download

```sh
pnpm exec steamharness workspace login --server <server-url>
pnpm exec steamharness workspace status
pnpm exec steamharness workspace pack <project-id> --path . --output project.tgz
pnpm exec steamharness workspace upload <project-id> --path .
pnpm exec steamharness workspace publish <project-id> --release-log "Update entries"
pnpm exec steamharness workspace versions <project-id>
pnpm exec steamharness workspace download <project-id> --target latest --path ./downloaded
```

One archive contains every registered entry, dependency declaration, and Kanban artifact. It excludes Git, `node_modules`, runtime data, and credentials. After download, install dependencies and check resource grants and entry bindings.

## Registration and ownership

Client creation requests a Server identity. The CLI can explicitly create a project and replace the local aggregate identity with `upload --create`; `--group-id` selects its group. Confirm the intended identity and ownership first.

Project membership and group inheritance use fixed roles. Database and knowledge grants are managed separately and are not obtained through source downloads.

## Transfers and configuration

| Operation | Purpose |
| --- | --- |
| `upload --file` | Upload an existing archive |
| `upload --no-wait`, `preparation` | Submit preparation, then inspect its result |
| `file-upload`, `file-download`, `file-delete` | Manage business files |
| `--server`, `--token` | Override connection settings explicitly |

Configuration templates, schemes, snapshots, and attachments are scoped to entries. Server maintains relational bindings by account, project, entry, and alias; archives carry no account bindings. Knowledge access follows declarations and grants. Keep credentials in host configuration.

See [workspace help](/en/cli/workspace/help) for the complete command list.
