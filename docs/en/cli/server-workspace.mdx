# Workspace static project management

`steamharness workspace` manages aggregate source and immutable versions on Server. Server does not install project dependencies, build or execute projects.

```sh
pnpm exec steamharness workspace login --server <server-url>
pnpm exec steamharness workspace status
pnpm exec steamharness workspace pack <project-id> --path . --output project.tgz
pnpm exec steamharness workspace upload <project-id> --path .
pnpm exec steamharness workspace publish <project-id> --release-log "Update entries"
pnpm exec steamharness workspace versions <project-id>
pnpm exec steamharness workspace download <project-id> --target latest --path ./downloaded
```

The aggregate is one upload, version and download unit. Archives contain every registered entry's code, dependency manifests and Kanban artifacts, excluding Git, node_modules, runtime data and credentials. Database alias-to-ID references remain; hosts maintain grants and credentials.

## Identity and ownership

Use the client creation flow to request a Server identity. `upload --create` explicitly creates and replaces the local aggregate identity; `--group-id` selects its permission group. Membership, inherited roles and source-access requests remain separate from database requests.

## Transfer and configuration

`upload --file` accepts an archive. `--no-wait` returns a preparation job; `preparation` reads its static preparation result. `file-upload/file-download/file-delete` manage business files. `--server` and `--token` override saved authentication. Never put credentials in the manifest.

CLI Web shows Project information → Global memory according to actual Core capabilities. Switch between personal global and current project/directory memory, search pages, view details, edit or forget records. The viewport-constrained dialog keeps a fixed size; temporary outages retain the entry with an error state, while disconnected or disabled memory is hidden. Account memory requires a fresh login for an independent credential; it does not use a project API key or business database.

Configuration templates, profiles, snapshots and attachments are entry-scoped. Use CLI Web, Studio or Server Web to request independent database spaces and bind them. Downloads require fresh approval.
