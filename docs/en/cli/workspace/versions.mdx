# workspace versions

Use `workspace versions` to inspect a project's `latest`, `nextVersion`, and historical releases.

## Command

```sh
pnpm exec steamharness workspace versions <project-id>
```

The command reads `GET /api/projects/{projectId}/versions`. Failed requests print error JSON and exit with code `1`.

## Returned information

Each version includes its number, publisher, publication time, notes, source SHA-256, dependency lock, `latest` marker, and `downloadCount`.

Counts increase when Server successfully sends a source response. Repeat downloads by the same user count again; a `latest` download is attributed to the resolved version.

Version records have no execution state or online/offline operation. Use [download](/en/cli/workspace/download) to retrieve a snapshot and [publish](/en/cli/workspace/publish) to create another version.
