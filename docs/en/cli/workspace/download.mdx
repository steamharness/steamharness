# Download an aggregate

```sh
pnpm exec steamharness workspace download <project-id> --target latest --path ./downloaded
```

One operation covers every registered entry of one projectId, including code, dependency manifests, configuration definitions and Kanban artifacts. Install dependencies and build static entries locally, then run `steamharness check .`.

Archives exclude credentials, host runtime data, Git and node_modules. Database alias-to-ID references remain. References do not grant access: request host access for another project identity or replace the database ID for another host.

`--target` accepts `draft`, `latest` or an exact version. Download into one aggregate directory while preserving registered subdirectories. Source access still requires membership or approved access.
