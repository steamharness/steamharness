# workspace download

Use `workspace download` to retrieve the complete aggregate while preserving entry-relative directories. The account must have the required source access.

## Command

```sh
pnpm exec steamharness workspace download <project-id> --target latest --path ./downloaded
```

| `--target` | Download |
| --- | --- |
| `draft` | Current draft |
| `latest` | Latest published version |
| Exact version | The corresponding historical snapshot |

## Validation and installation

The target project directory is created only after entry files, database inventories, and hashes pass validation. Missing files, damaged inventories, runtime data, or unregistered `dist/` files fail the download and trigger temporary-file cleanup.

Install dependencies in the downloaded directory. Rebuild modified static entries, then run `steamharness check .`.

## Resource access

Archives contain neither credentials nor host runtime data. Server keeps account-specific relational bindings. Resource declarations and knowledge references grant no access. Check grants and bindings again after changing accounts or Servers before running data operations.
