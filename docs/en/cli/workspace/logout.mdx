# workspace logout

Use `workspace logout` to clear the Server address, API key, and account details saved by the local CLI. It removes the sign-in configuration without contacting Server or deleting project files.

## Command Format

```bash
pnpm exec steamharness workspace logout
pnpm exec steamharness workspace logout --ai --server https://server.example.com
```

## Parameter

|Parameter|Description|
| --- | --- |
| `--ai` | Clear the saved System AI sign-in without changing project sign-in. |
| `--server <URL>` | Clear credentials for this address only. Omit to clear the current address. |

## Behavior

|Steps|Description|
| --- | --- |
|Locate Configuration Directory|Use `STEAMHARNESS_CLI_AUTH_DIR` or the system default directory.|
| Clear credentials | Remove credentials for the selected purpose and address. If they were the active sign-in, leave a marker to prevent legacy credentials from being restored. |
|Output status|Output `{ loggedIn: false }`.|

## Output

|Situation|Output|
| --- | --- |
|Success| `{ errCode: 0, errMessage: "", data: { loggedIn: false } }` |
|File write failed|Output error message with exit code `1`.|

## Example

```bash
pnpm exec steamharness workspace logout
pnpm exec steamharness workspace status
```

## Precautions

|Scene|Description|
| --- | --- |
|`STEAMHARNESS_SERVER_ADMIN_KEY` set|The environment variables are still read by subsequent commands.|
|Need to switch accounts completely|Clean up the shell environment variables and the CLI login state at the same time.|
