# workspace status

Use `workspace status` to inspect saved sign-in details and the Server the current invocation would actually use. It reads local configuration without contacting Server, so it cannot establish that an API key remains valid.

Connection settings resolve in this order:

1. `--server` and `--token`.
2. `STEAMHARNESS_SERVER_URL` and `STEAMHARNESS_SERVER_ADMIN_KEY`.
3. Saved CLI sign-in details.
4. Channel defaults.

Use `effective.serverUrl` for the current target; `serverUrl` is only the saved value. Studio injects its current session into project execution and built-in terminals, which can differ from an independent terminal's saved login.

## Command Format

```bash
pnpm exec steamharness workspace status
```

## Parameter

|Parameter|Description|
| --- | --- |
|None|The command does not read positional parameters.|

## Output field

|Field|Description|
| --- | --- |
| `loggedIn` |CLI When both a non-empty server URL and API Key are present in the login state, it is `true`.|
| `serverUrl` |CLI The server URL saved in the login state.|
| `user` |The user summary obtained from the most recent device flow login.|
| `expiresAt` |API Key expiration time.|
| `expiringSoon` |It is `true` when less than 3 days remain until expiration.|
| `source` |Login source, currently `device_flow` or `manual`.|
| `effective.serverUrl` |The server URL this call would use.|
| `effective.serverSource` |Where that server URL came from: `env`, `flag`, `file`, or `default`.|
| `effective.tokenSource` |Where the token for this call came from: `env`, `flag`, `file`, or `none`.|

## Example output

```json
{
  "errCode": 0,
  "errMessage": "",
  "data": {
    "loggedIn": true,
    "serverUrl": "http://localhost:7126",
    "user": {
      "userId": "user-1",
      "email": "user@example.com",
      "displayName": "Normal User"
    },
    "expiresAt": "2026-07-01T00:00:00.000Z",
    "expiringSoon": false,
    "source": "device_flow",
    "effective": {
      "serverUrl": "https://server-alpha.example.com",
      "serverSource": "env",
      "tokenSource": "env"
    }
  }
}
```

## Example

```bash
pnpm exec steamharness workspace status
```

## Precautions

|Scene|Description|
| --- | --- |
|Server availability needs to be verified.|Use [`health`](/en/cli/workspace/health).|
|Need to verify that the token is available|Use [`login`](/en/cli/workspace/login) to re-authenticate, or execute a command that requires authentication.|
|Need to know which server a command would use|Read `effective`; `serverUrl` only describes the saved login, which an environment variable or a command-line flag may already override.|
