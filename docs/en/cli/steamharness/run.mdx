# Run the selected entry

Execute a registered Workflow or Conversation; use `web` to present static Kanban entries.

```sh
pnpm exec steamharness run . --entry database --entrypoint search -- --query example
```

`entryId` selects an aggregate entry; `entrypointId` selects an internal Workflow operation. Entries have independent configurations, database requirements and conversation state. Selection defaults to `defaultEntry`; unknown entries fail.

Pass business arguments after `--`. Configuration is fixed at execution start; edits apply to the next execution. Cross-entry calls use the target configuration and inherit caller permissions. See [CLI](/en/cli/steamharness).
