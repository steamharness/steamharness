# steamharness run

Run the project's default entry or select a registered Workflow or Bot with `--entry`. Use `web` to display a static Kanban entry.

## Command

```sh
pnpm exec steamharness run .
pnpm exec steamharness run . --entry database --entrypoint search -- --query example
```

The second command requires a `database` entry with a `search` operation. Arguments after `--` belong to the business workflow rather than the CLI.

## Entry selection

| Option | Meaning |
| --- | --- |
| `--entry` | Aggregate `entryId`; defaults to `defaultEntry` |
| `--entrypoint` | Operation within the selected Workflow; not accepted by Bot |

Unknown IDs fail. Each entry has separate configuration, database requirements, and conversation state. A run keeps its startup configuration snapshot; edits apply to the next run.

## Results and next steps

The command executes the selected workflow and displays its result. Use [json](/en/cli/steamharness/json) for a structured report or [structure](/en/cli/steamharness/structure) to inspect declarations first. Cross-entry calls load the target configuration and inherit current permissions.
