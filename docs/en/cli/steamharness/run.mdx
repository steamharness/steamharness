# steamharness run

Run the project's default entry or select a registered Workflow or Bot with `--entry`. Use `web` to display a static Kanban entry.

## Command

```sh
pnpm exec steamharness run .
pnpm exec steamharness run . --entry workflow --entrypoint summarize -- --text example
```

The second command requires a `workflow` entry with a `summarize` operation. Arguments after `--` belong to the business workflow rather than the CLI.

## Entry selection

| Option | Meaning |
| --- | --- |
| `--entry` | Aggregate `entryId`; defaults to `defaultEntry` |
| `--entrypoint` | Operation within the selected Workflow; not accepted by Bot |

Unknown IDs fail. Each entry has separate configuration and conversation state. A run keeps its startup configuration snapshot; edits apply to the next run.

## Results and next steps

The command executes the selected workflow and displays its result. Use [json](/en/cli/steamharness/json) for a structured report or [structure](/en/cli/steamharness/structure) to inspect declarations first. Cross-entry calls load the target configuration and inherit current permissions.

## Opt into platform features

Platform credentials are not read by default. Use `--online project` for protected project configuration, or `--online ai` for System AI. Each option requires a Server connection and its own login. Repeat the flag to enable both.
