# JSON run reports

Execute the selected entry and output its JSON run report.

```sh
pnpm exec steamharness json . --entry database --entrypoint search -- --query example
```

`entryId` selects an aggregate entry; `entrypointId` selects an internal Workflow operation. Entries have independent configurations, database requirements and conversation state. Selection defaults to `defaultEntry`; unknown entries fail.

Reports contain run status, output and errors. `--conversation-id` and `--run-id` select explicit identities; the host still isolates them by project and entry. Cancellation aborts the current execution.
