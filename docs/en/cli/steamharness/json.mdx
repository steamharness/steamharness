# steamharness json

Use `json` when a script needs run status, output, or errors. It executes the project rather than converting a previously saved result.

## Command

```sh
pnpm exec steamharness json .
pnpm exec steamharness json . --entry database --entrypoint search -- --query example
```

The second example selects a declared `database` entry and `search` operation. Omitting `--entry` uses `defaultEntry`; unknown IDs fail. Put business arguments after `--`.

## Read the report

Reports include status, output, and errors. Explicit `--conversation-id` and `--run-id` values remain scoped to the project and entry; reusing an ID grants no access to another entry.

Entries retain independent configuration, resource requirements, and conversation state. Cancellation stops execution and reports an aborted state. Inspect permission and resource errors rather than treating the presence of JSON as success.
