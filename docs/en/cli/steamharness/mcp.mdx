# Entry MCP server

Expose the selected Workflow operations, parameters and results through stdio MCP.

```sh
pnpm exec steamharness mcp . --entry database
```

`entryId` selects an aggregate entry; `entrypointId` selects an internal Workflow operation. Entries have independent configurations, database requirements and conversation state. Selection defaults to `defaultEntry`; unknown entries fail.

MCP requests and recovery handles bind to both project and entry. Tool permissions, actor, configuration snapshot and cancellation follow the call chain. Resuming in a different entry fails. Request and approve databases in the host first; MCP cannot create spaces implicitly.
