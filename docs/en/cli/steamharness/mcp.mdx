# steamharness mcp

Use `mcp` to expose a registered Workflow's operations, parameters, and results. The process communicates through standard input and output.

## Command

```sh
pnpm exec steamharness mcp . --entry database
```

The project must declare the `database` entry. Without `--entry`, it uses `defaultEntry`. A client's `entrypointId` selects an operation within that Workflow and does not replace the aggregate `entryId`.

## Permissions and recovery

Every request and resume handle is bound to a project and entry. User identity, tool permissions, configuration snapshots, and cancellation propagate through calls. Resuming into another entry is rejected.

Entries retain their own configuration, resource requirements, and conversation state. MCP does not allocate databases: create or obtain access to resources and bind the entry first. Unknown entries fail explicitly.
