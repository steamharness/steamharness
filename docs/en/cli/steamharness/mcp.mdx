# steamharness mcp

Use `mcp` to expose a registered Workflow's operations, parameters, and results. The process communicates through standard input and output.

## Command

```sh
pnpm exec steamharness mcp . --entry workflow
```

The project must declare the `workflow` entry. Without `--entry`, it uses `defaultEntry`. A client's `entrypointId` selects an operation within that Workflow and does not replace the aggregate `entryId`.

## Permissions and recovery

Every request and resume handle is bound to a project and entry. User identity, tool permissions, configuration snapshots, and cancellation propagate through calls. Resuming into another entry is rejected.

Entries retain their own configuration and conversation state. Unknown entries fail explicitly.

## Opt into platform features

Platform credentials are not read by default. Use `--online project` for protected project configuration, or `--online ai` for System AI. Each option requires a Server connection and its own login. Repeat the flag to enable both.
