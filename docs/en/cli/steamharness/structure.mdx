# Entry structure

Statically inspect the selected entry, using the default when omitted. `check` validates the whole aggregate.

```sh
pnpm exec steamharness structure . --entry database
```

`entryId` selects an aggregate entry; `entrypointId` selects an internal Workflow operation. Entries have independent configurations, database requirements and conversation state. Selection defaults to `defaultEntry`; unknown entries fail.

Analysis is scoped to the registered code root and entry file. Different executor types and repeated types are checked independently. Static HTML entries validate built artifacts. Legacy root type and storage declarations are rejected.
