# steamharness structure

Use `structure` to inspect declarations and execution structure within registered source roots and entry files. Use `check` to validate the whole aggregate project.

## Commands

```sh
pnpm exec steamharness structure .
pnpm exec steamharness structure . --entry database
pnpm exec steamharness check .
```

`--entry` is the manifest entry ID and defaults to `defaultEntry`. Entries of the same type are still checked separately. Unknown IDs fail.

## What is checked

- Workflow: executor, operation catalog, nodes, and static parameters.
- Conversation: executor and conversation parameter declarations.
- Kanban: the HTML entry and built static resources.

Legacy root types and removed data declarations are rejected. Static validation does not establish runtime behavior or resource authorization. Continue with [run](/en/cli/steamharness/run) to verify results.
