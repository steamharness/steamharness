# Runtime platform

```ts
workflow.getRuntimePlatform(): "cli" | "desktop"
workflow.isCli(): boolean
workflow.isDesktop(): boolean
```

Platforms describe where code executes. Terminal and CLI Web use `cli`; an absent marker defaults to `cli`. Unknown nonempty markers throw. Server does not execute projects and provides no server execution marker or `isWeb()`.

```ts
const platform = workflow.getRuntimePlatform();
const local = workflow.isCli();
```

Runtime platform does not choose the data host. Entries resolve aliases and database IDs from root config.json; the host determines the data location. Access approved spaces with `context.databases.get(alias)`. Local execution can use server spaces.
