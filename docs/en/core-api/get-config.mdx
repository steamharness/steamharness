# getConfig

Use `steamharness.getConfig()` to read the current run's configuration snapshot. Values retain their native string, number, boolean, array, object, or `null` types.

## Example

```ts
const enabled = steamharness.getConfig<boolean>("enabled") ?? false;
const token = steamharness.getConfig<string>("API_KEY");
```

## Signature

```ts
steamharness.getConfig<T extends ConfigurationValue = ConfigurationValue>(key: string): T | undefined
```

## Return rules

| Situation | Result |
| --- | --- |
| Field exists | Native value, without string conversion or whitespace trimming |
| Missing field or run scope | `undefined` |
| Array or object | Nested values are frozen |
| Prototype name such as `toString` | Read only when explicitly configured as an own field; required-field validation still applies |

The caller supplies the generic type; declarations and save validation determine the actual value type. Executors, parameter resolvers, and node `context.config` share the same snapshot.

This API replaces business `getEnv` and reads neither process variables nor project env files. See [project configuration](/en/concepts/project-configuration) for declarations, storage, import, and export.
