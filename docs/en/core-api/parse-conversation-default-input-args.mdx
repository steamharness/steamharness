# parseConversationDefaultInputArgs

This low-level helper reads message and attachment flags from CLI-style arguments without accessing `RunContext`. Hosts and Workflow adapters can use it when they construct their own inputs. Bot projects use [defineBot](/en/core-api/define-bot): Core parses their input automatically before `prepareInput`.

## Signature

```ts
steamharness.parseConversationDefaultInputArgs(
  args: string[],
): {
  message: string;
  images: FileReference[];
  videos: FileReference[];
  files: FileReference[];
}
```

## parsing rules

|Parameter|Behavior|
| --- | --- |
| `--message <text>` |Reads the last occurrence of the value and executes `trim()`; returns an empty string if not passed.|
| `--images <value>` |Each occurrence is parsed into one or more `FileReference` s and eventually merged into an array.|
| `--videos <value>` | Each occurrence is parsed into one or more references and merged into the videos array. |
| `--files <value>` |Each occurrence is parsed into one or more `FileReference` s and eventually merged into an array.|
|Missing value|The flag is ignored.|
|Other parameters|Reserved for business code to parse, this helper does not process.|

`--images`, `--videos`, and `--files` accept file reference JSON or local path strings using `parseProjectFileReferences()`, just like the file input node. Only projects with `attachments.videos: true` use `--videos`; existing projects with only `files: true` continue to serialize videos under `--files`.

## Example

```ts
const input = steamharness.parseConversationDefaultInputArgs(["--message", "Hello"]);
console.log(input.message); // Hello
```

## with file input node

The helper only resolves the parameter to `FileReference[]`. If you need to read the contents of the file, pass the reference to `steamharness.createFileInputNode()`:

```ts
const imageInputNode = steamharness.createFileInputNode({
  name: "images",
  accept: ["image/png", "image/jpeg", "image/webp"],
  multiple: true,
});

const images = await steamharness.runNode(imageInputNode, input.images, context);
const imageParts = await Promise.all(images.map((file) => file.toLLMImagePart()));
```

## Precautions

|Scene|Description|
| --- | --- |
|Multiple `--message`|Returns the last value suitable for the host to overwrite the previous draft with the next input.|
|Multiple attachments|`--images`, `--videos`, and `--files` each merge all occurrences.|
| Bot standard input | Core parses it automatically; business customization uses `prepareInput`. |
|CLI Manual debugging|Pass `--message`, `--images`, `--videos`, and `--files` to simulate the default input box.|
