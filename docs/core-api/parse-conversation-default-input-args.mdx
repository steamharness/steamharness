# parseConversationDefaultInputArgs

`workflow.parseConversationDefaultInputArgs(args)` 解析 conversation 默认输入框写入的固定参数。它只读取 `--message`、`--images`、`--videos` 和 `--files`，不会自动读取 `RunContext`，也不会替代 executor 的 `createInput`。

Bot 始终使用标准主输入框。Core 自动解析文本与图片；业务输入钩子需要额外处理文件或视频时，可调用本 helper 读取宿主附件引用。

## 签名

```ts
workflow.parseConversationDefaultInputArgs(
  args: string[],
): {
  message: string;
  images: FileReference[];
  videos: FileReference[];
  files: FileReference[];
}
```

## 解析规则

| 参数 | 行为 |
| --- | --- |
| `--message <text>` | 读取最后一次出现的值，并执行 `trim()`；未传时返回空字符串。 |
| `--images <value>` | 每次出现都会解析为一个或多个 `FileReference`，最终合并为数组。 |
| `--videos <value>` | 每次出现都会解析为一个或多个 `FileReference`，最终合并为数组。 |
| `--files <value>` | 每次出现都会解析为一个或多个 `FileReference`，最终合并为数组。 |
| 缺少值 | 该 flag 会被忽略。 |
| 其它参数 | 保留给业务代码自行解析，本 helper 不处理。 |

`--images`、`--videos` 和 `--files` 复用文件引用协议，参数值可以是文件引用 JSON 或本地路径字符串。解析逻辑与文件输入节点相同，底层使用 `parseProjectFileReferences()`。只有显式启用 `attachments.videos: true` 的项目使用 `--videos`；旧项目仅启用 `files: true` 时，视频继续使用 `--files`。

## executor 配置

```ts
export const executor = steamharness.defineBot({
  conversation: { attachments: { images: true, files: true } },
  async prepareInput(input, context) {
    const attachments = steamharness.parseConversationDefaultInputArgs(context.args);
    return { ...input, businessFiles: attachments.files };
  },
});
```

## 与文件输入节点配合

helper 只把参数解析成 `FileReference[]`。如果需要读取文件内容，再把引用传给 `workflow.createFileInputNode()`：

```ts
const imageInputNode = workflow.createFileInputNode({
  name: "images",
  accept: ["image/png", "image/jpeg", "image/webp"],
  multiple: true,
});

const images = await workflow.runNode(imageInputNode, input.images, context);
const imageParts = await Promise.all(images.map((file) => file.toLLMImagePart()));
```

## 注意事项

| 场景 | 说明 |
| --- | --- |
| 多次传 `--message` | 返回最后一个值，适合宿主用后一次输入覆盖前一次草稿。 |
| 多次传附件 | `--images` / `--videos` / `--files` 各自合并所有出现次数。 |
| 标准主输入框 | 由 Core 自动解析；额外业务附件可在 `prepareInput` 中读取。 |
| CLI 手动调试 | 可以直接传 `--message`、`--images`、`--videos`、`--files` 模拟默认输入框。 |
