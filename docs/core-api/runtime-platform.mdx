# Runtime platform

```ts
workflow.getRuntimePlatform(): "cli" | "desktop"
workflow.isCli(): boolean
workflow.isDesktop(): boolean
```

平台表示代码实际执行的宿主。终端与 CLI Web 使用 `cli`；没有宿主标记时默认 `cli`。非空未知标记会抛错。Server 不执行项目，因此没有服务器执行标记或 `isWeb()`。

```ts
const platform = workflow.getRuntimePlatform();
const local = workflow.isCli();
```

运行平台不决定存储后端。导入生成的数据库描述符并调用 `context.databases.connect(descriptor)`，Server 根据账号和入口绑定选择独立授权的 PostgreSQL 资源。知识库使用 `context.knowledgeBases.get(alias)`。本地开发可在同一台机器运行 Server 与 Docker PostgreSQL。

## 宿主资源管理

Studio 和 CLI Web 列出 Server 资源，打开经过鉴权的 Server Web 页面管理模型、数据表、附件及账号权限；链接不含账号 token。宿主持有 SQL 凭据、连接与绑定身份，项目 RPC 和 Browser 页面只接收授权的模型操作。不提供本地数据库目录或 KV 管理上下文。
