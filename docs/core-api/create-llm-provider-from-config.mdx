# createLLMProviderFromConfig

用 `steamharness.createLLMProviderFromConfig()` 从本次运行的配置创建 Provider。SDK 同名导出也可接收显式配置对象，两种方式都不回退读取环境变量。

## 示例

```ts
const provider = steamharness.createLLMProviderRef("default", () =>
  steamharness.createLLMProviderFromConfig());
```

## 签名

```ts
steamharness.createLLMProviderFromConfig(): LLMProvider
createLLMProviderFromConfig(config?: ConfigurationValues): LLMProvider
```

## 配置字段

先在 `configuration.json` 声明字符串字段，再在项目配置中填写值。把 API Key 标记为敏感字段。

| Key | 别名 | 取值 |
| --- | --- | --- |
| `LLM_TYPE` | `TYPE` | `openai-completion`、`openai-responses`、`anthropic` |
| `LLM_API_KEY` | `API_KEY`、`APIKEY` | 必填 |
| `LLM_BASE_URL` | `BASE_URL` | 可选地址 |
| `LLM_MODEL` | `MODEL` | 可选模型 ID |

未配置模型时，OpenAI 默认 `gpt-4.1-mini`，Anthropic 默认 `claude-3-haiku-20240307`。缺少必填键或 Provider 类型无效会抛出 `input_validation`。

配置保存和快照规则见[项目配置](/concepts/project-configuration)。
