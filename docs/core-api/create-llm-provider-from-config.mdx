# createLLMProviderFromConfig

```ts
steamharness.createLLMProviderFromConfig(): LLMProvider
createLLMProviderFromConfig(config?: ConfigurationValues): LLMProvider
```

运行时工厂读取当前运行快照；SDK 同名导出也支持显式配置对象。两者均不回退读取环境变量。

| Key | Aliases | 说明 |
| --- | --- | --- |
| `LLM_TYPE` | `TYPE` | `openai-completion`, `openai-responses`, `anthropic` |
| `LLM_API_KEY` | `API_KEY`, `APIKEY` | 必填 API key |
| `LLM_BASE_URL` | `BASE_URL` | 可选接口地址 |
| `LLM_MODEL` | `MODEL` | 可选模型 |

在 `configuration.json` 声明这些字符串字段，在项目配置面板填写值；API key 标记为敏感字段。缺少必填键或 provider 类型无效时抛出 `input_validation`。OpenAI 默认模型为 `gpt-4.1-mini`，Anthropic 为 `claude-3-haiku-20240307`。

```ts
const provider = steamharness.createLLMProviderRef("default", () =>
  steamharness.createLLMProviderFromConfig());
```

参见[项目配置](/concepts/project-configuration)。
