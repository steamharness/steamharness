# 账号记忆 API

从 `steamharness/agent` 导入 `AgentMemoryProvider`、`AgentMemoryBinding`、`withAgentMemory()`、`getAgentMemoryCapabilities()` 和 `createServerAgentMemoryProvider()`。Core 本身不加载 SQLite、jieba 或 embedding。

```ts
import { createAgent, createServerAgentMemoryProvider, withAgentMemory } from 'steamharness/agent';

// 由可信宿主取得或刷新，只包含短期 shmu_ 授权；不返回账号管理凭据。
declare function getScopedGrant(): Promise<{ token: string; scope: string }>;
const provider = createServerAgentMemoryProvider({
  serverUrl: 'https://your-server.example',
  getGrant: getScopedGrant,
});
const agent = await withAgentMemory({ provider, outboxDirectory: './.data/memory-outbox' }, () =>
  createAgent({ memory: true, databasePath: './.data/agent.sqlite' }),
);
try {
  for await (const event of agent.run({ prompt: '请记住这个项目使用 PostgreSQL。' })) {
    // 按宿主的输出协议处理 event。
  }
} finally {
  await agent.close();
}
```

`AgentRuntimeOptions.memory` 默认关闭。设为 `true` 时使用当前宿主绑定，也可显式传入 `AgentMemoryBinding`；`false` 始终关闭。静态识别的 Core Agent 入口在「项目配置」中展示“项目记忆”开关，使用保留布尔字段 `STEAMHARNESS_AGENT_MEMORY`，默认 `false`；源码显式声明 `memory: true` 时提供开启默认值，内置小助手已这样声明。保存的项目值从下一次执行覆盖默认值，关闭时同时禁用工具、召回、自动提交和记忆分页，不删除已有记忆。账号总开关仍然生效，项目不能绕过账号关闭状态，也不能凭空创建宿主绑定。

绑定可设 `readOnly` 和 `onError`。宿主必须按账号和当前范围隔离 `outboxDirectory`，该目录只保存待提交回合，不保存凭据。

宿主从 `steamharness` 导入 `getLocalProjectMemoryCapabilities({ projectDir, entryId?, entrypointId? })`，按执行所用的配置快照查询当前入口声明与宿主绑定合并后的有效能力；未进入执行上下文时读取当前已保存配置。包装 Conversation 通过 `coreAgent` 关联；默认关闭的项目、显式 `memory: false` 或非 Core Agent 入口返回未接入，不请求记忆授权。检查只加载入口声明，不运行任务或工具工厂。`getAgentMemoryCapabilities()` 则直接查询指定或当前异步上下文中的绑定。

Provider 实现能力查询、`recall`、`submitTurn`、`list`、`get`、`remember`、`update` 和 `forget`。公开工具作用域只有 `global` 和 `current`，由适配器映射到宿主授权的范围，模型不能指定用户或任意项目。写操作使用稳定 `operationId`；编辑携带 `version`，冲突返回 409。

每个用户回合首次调用模型前按相关性召回最多 8 条、最多 2,000 估算 tokens，2 秒超时。同一活会话的后续输入也会重新检索；记录仅作为本轮请求中带范围与来源的参考，不写入会话历史，当前用户指令优先。

持久 Agent 每个成功回合保存完成后，只提交用户文字与最终回答，不等待宿主会话租约或进程结束。推理、工具原始输出、召回参考和子 Agent 报告不作为提炼来源。回合及消息 ID 从持久会话身份生成，提交回执持久保存；配置 `outboxDirectory` 时，断网回合进入宿主 outbox，恢复与重试不会重复保存。首次接入记忆不会自动导入此前已完成的会话历史。

规划、只读运行和子 Agent 只能读取。原生工具支持 `list/get/search/remember/update/forget`；内置 `steamharness-memory` 技能说明归类和遗忘规则。旧数据库记忆 API 保持独立，不自动回退或迁移。部署、账号面板和恢复流程见 [账号记忆](/guides/server/account-memory)。
