# getConfig

用 `steamharness.getConfig()` 读取当前运行的配置快照。返回原生值，支持字符串、数字、布尔、数组、对象和 `null`。

## 示例

```ts
const enabled = steamharness.getConfig<boolean>("enabled") ?? false;
const token = steamharness.getConfig<string>("API_KEY");
```

## 签名

```ts
steamharness.getConfig<T extends ConfigurationValue = ConfigurationValue>(key: string): T | undefined
```

## 返回规则

| 情况 | 结果 |
| --- | --- |
| 字段存在 | 返回配置中的原生值，不转换字符串或裁剪空白 |
| 字段不存在或无运行作用域 | `undefined` |
| 数组或对象 | 嵌套值已冻结 |
| 原型名称，如 `toString` | 只有显式配置为自身字段后才可读取，仍需满足必填校验 |

泛型由调用方声明，实际类型由字段定义和保存校验决定。执行器、参数解析器与节点的 `context.config` 使用同一快照。

此接口替代业务 `getEnv`，不读取进程变量或项目 env 文件。声明、存储和导入导出见[项目配置](/concepts/project-configuration)。
