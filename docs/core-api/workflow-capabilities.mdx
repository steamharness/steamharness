# 工作流能力工具

工作流能力工具把宿主配置、Kanban 页面方法和 Bot 资源卡片提供给项目。每项能力共用 JSON Schema 和执行函数，可作为 Agent 原生工具或 MCP 服务。项目在 executor 的 `tools` 中声明要使用的工具 ID。

| 能力 | 工具 ID |
| --- | --- |
| Kanban 页面方法 | `steamharness-kanban_kanban_methods` |
| Bot 资源卡片 | `workflow-ui_present_card` |

## 创建与调用

```ts
const tools = await steamharness.createProjectCapabilityTools({
  context,
  approve: (toolId, args) => approval.approve({ name: toolId, arguments: args }, context),
});

const ids = steamharness.listProjectCapabilityToolIds();
const result = await steamharness.runProjectCapabilityAction(ids[0], context, args);
```

`createProjectCapabilityServer(toolId, { context, approve })` 将单项能力包装成 MCP 服务端。工具 ID 未知时会抛错；`isProjectCapabilityAvailable(toolId)` 可在展示工具前检查当前宿主是否提供该能力。

工具审批由 executor 的 `tools` 声明控制。暂停后用获批的工具 ID 调用 `runProjectCapabilityAction` 恢复，避免继续使用已经结束的 Agent 轮次中的闭包。

## 资源卡片

`workflow-ui_present_card` 使用稳定的 `cardId`。传 `action: "upsert"` 创建或更新卡片，传 `action: "remove"` 移除卡片。支持 `project`、`kanban`、`browser` 和 `file`；文件路径相对项目，浏览器 URL 使用 HTTP(S)。

```json
{
  "action": "upsert",
  "cardId": "roadmap-board",
  "kind": "kanban",
  "target": { "source": "current", "entryId": "map" },
  "pinned": true,
  "preview": true
}
```

`preview` 适用于 Kanban、项目与浏览器卡片。配置预览可在 `target.configurationId` 中指定现有配置；临时覆盖使用 `kanban: { mode: "preview", values }`。卡片不会保存配置值，保存时使用 Studio Control 的 `manage_configurations`。
