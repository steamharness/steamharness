# CLI 总览

安装 `@steamharness/cli` 后，通过 `steamharness` 操作项目。在项目目录推荐使用 `pnpm exec steamharness`，确保调用项目安装的版本。

## 选择命令组

| 任务 | 命令组 |
| --- | --- |
| 本地运行、结构检查、JSON 报告、MCP | [本地 CLI](/cli/steamharness) |
| 登录 Server、打包、上传、发布、下载 | [Workspace CLI](/cli/server-workspace) |

## 典型工作流

先在本地检查和运行，确认结果后再上传：

```sh
pnpm exec steamharness check .
pnpm exec steamharness structure .
pnpm exec steamharness run .
pnpm exec steamharness json .
```

连接 Server 时明确选择地址。下面的 `<project-id>` 应替换为已注册项目 ID：

```sh
pnpm exec steamharness workspace health --server http://localhost:7126
pnpm exec steamharness workspace login --server http://localhost:7126
pnpm exec steamharness workspace upload <project-id> --path .
pnpm exec steamharness workspace publish <project-id> --release-log "初始发布"
```

## 数据库与入口

本地命令从聚合根读取 `entries`；`--entry` 选择入口，`check` 默认检查全部入口。关系库先创建资源、授权、迁移并绑定，知识库使用独立声明与绑定。

CLI Web 与 Studio 共用用户级项目登记。各类数据的存放与权限见[数据存储](/concepts/data-storage)。
