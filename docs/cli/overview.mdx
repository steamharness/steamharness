# CLI 总览

`@steamharness/cli` 只暴露一个 `steamharness` 命令，并按用途分为两个命令组：

| 命令组 | 用途 |
| --- | --- |
| [`steamharness`](/cli/steamharness) | 在本地 workflow 目录运行、输出 JSON 报告、检查结构，或启动 stdio MCP Server。 |
| [`steamharness workspace` / `pnpm exec steamharness workspace`](/cli/server-workspace) | 连接 SteamHarness Server，完成登录、打包、上传、发布、下载和版本查询。 |

## 典型工作流

本地开发时，先用 `steamharness` 在 workflow 目录验证运行结果和结构，再用 workspace CLI 上传到 server。

以下命令中的 `./my-project` 指你已创建并注册入口的本地项目目录。

```bash
steamharness run ./my-project -- --message "hello"
steamharness json ./my-project -- --message "hello"
steamharness structure ./my-project
steamharness mcp ./my-project
```

发布到 server 时，先检查服务状态，再登录、上传、发布和下载。

```bash
pnpm exec steamharness workspace health --server http://localhost:7126
pnpm exec steamharness workspace login --server http://localhost:7126
pnpm exec steamharness workspace upload hello
pnpm exec steamharness workspace publish hello --release-log "初始发布"
```

开发环境可以使用本地 server 地址；部署环境建议显式使用正式域名或你的生产端口。

## 数据库与入口

所有本地命令从聚合根读取 entries。使用 `--entry` 选择入口；`check` 默认检查全部入口。业务关系库通过生成的描述符访问，先在 Server 创建资源、授权、迁移并绑定入口；知识库使用独立的 knowledgeBases 声明和绑定。CLI Web、Studio 共用用户级本地注册表。详见 [CLI](/cli/steamharness) 和 [项目数据存储](/concepts/data-storage)。
