# 使用 CLI Web

在浏览器中打开本地项目、切换入口并使用项目信息。

```sh
pnpm exec steamharness web .
```

## CLI Web

Bot 主对话框中输入 `@`，选择 **技能**、**文件** 或 **项目入口**，也可继续输入名称直接搜索。技能读取当前入口实际配置的目录；文件从项目根目录（小助手使用绑定的工作目录）搜索，Git 项目遵循忽略规则，并排除依赖、构建产物、运行数据与 `.env` 配置。使用 ↑/↓ 选择，Enter 或 Tab 插入，Esc 关闭；Shift+Enter 继续换行。插入的 `@skill:…`、`@file:…`、`@entry:…` 在输入框中高亮；

文件仅显示文件名，悬停时展示完整路径，含空格的文件名自动加引号。保存和发送仍保留完整路径，引用作为消息文本保存，可随草稿恢复、编辑队列消息或重新发送。选择入口仅引用入口标识，不切换窗口或运行入口。原有 `/` 命令继续可用。

Core Agent 默认或 `modelSource: "user-settings"` 在 Studio 使用设置的内置／自定义模型，不展示项目“AI 模型”。独立 `steamharness web` 没有模型设置能力时自动改用项目模型，点击“配置模型”可添加系统 AI／第三方 AI。Studio 设置列表为空时仍进入设置管理；显式 `modelSource: "project"` 始终使用项目模型。

Core Agent 的执行 worker 在活动宿主中意外退出时，最多自动恢复 3 次，沿用原任务、子会话和检查点。 本地执行锁随旧进程退出自动释放；显式使用 Server 关系存储时，最多等待 35 秒让旧租约到期。等待响应停止操作，不接管仍有效的其他执行身份，也不重放已提交写入。

宿主自身强退重开时，普通会话按原运行身份恢复，含未完成业务任务的会话等待明确输入。宿主退出会关闭运行 worker；不响应清理的 worker 最迟在 5 秒后退出并释放会话锁。失败、停止或超时后，待发队列保留并暂停；只有一轮成功完成后才自动发送下一条。可显式继续队列或发送新输入，新输入成功后再顺序发送保留的队列。

重新打开会话或同步其它窗口的历史时，已持久化的 Agent 回合终态会校正旧的“回复中”和恢复标记。已经完成、失败或停止的回答不会继续计时，也不会因旧标记再次执行；尚未完成的回合继续按恢复规则处理。每轮回答结束后保留最终耗时，刷新或重开历史仍可查看；后续追问从该轮开始执行时独立计时。

子 Agent 首次打开及恢复历史时使用持久记录中的实际执行起止时间，包含打开前已经执行的时间；排队时间不计入该轮。旧历史缺少可靠计时记录时不按当前时间补算。

Agent 调用 `sleep` 时，活动行显示预计结束时间，展开可查看等待结果；完成后显示实际结束时间。时间按浏览器本地时区显示，重开历史仍可查看，恢复等待沿用原截止时间。

在 Studio 中，Agent 回复与计划中的本地文件链接、行内代码路径和正文绝对路径可点击，在编辑区打开对应文件。支持相对路径、`file://` 链接及 `src/main.ts:12:3`、`src/main.ts#L12C3` 形式的行列定位；相对路径从聚合项目根目录或小助手绑定的工作目录解析。普通网页链接继续在浏览器中打开。独立浏览器中的 CLI Web 无法打开本机编辑器，点击本地文件路径时会提示使用 Studio。

在 Studio 中导出对话、单条消息或工作流记录时，会打开原生保存窗口，默认位置为用户主目录下的 Downloads（下载）目录，也可手动选择其他位置。确认位置并成功写入文件后，右下角通知显示保存路径；取消保存不提示成功，保存失败显示错误。独立浏览器中的 CLI Web 使用浏览器下载。

一个根目录启动一个聚合宿主，默认只展示 `defaultEntry`。点击顶部操作区的 **项目窗口** 图标，面板以紧凑卡片显示各入口的图标、名称、类型、默认／当前标记和运行状态。点击入口右侧的打开图标，在独立 CLI Web 中打开新浏览器页面，在 Studio 中打开新的原生标签。每次点击都会新开一个标签，包括当前入口；各标签独立保留页面状态和草稿，共享聚合运行宿主。关闭一个标签不影响其他标签；关闭最后一个 Studio 标签后释放宿主。

每个入口使用 `/entries/<entryId>/` URL 和独立控制器。入口的可选 `projectCard` 配置 `icon`、`iconColor` 与 `iconBackgroundColor`，颜色使用 `#RRGGBB`；未配置的字段采用入口类型的默认值。根 `steamharness.json.projectCard` 用于聚合项目卡片，入口图标相互独立。版本只在根 `steamharness.json.version` 声明，入口不接受独立版本。

点击右上角的 **项目信息** 图标，统一查看概览、项目配置、工具、技能与数据库。面板使用固定宽高，宽屏采用左侧导航，窄屏改用可横向滚动的顶部标签，内容区独立滚动；切换分栏不会改变面板大小，也不会丢弃配置草稿或工具搜索。工具清单与权限随项目状态更新。工具与技能供支持它们的入口使用。

技能页读取当前入口的真实技能目录，展示技能数量并区分项目技能与 Core 内置技能，支持搜索。点击技能可在固定面板内预览完整 `SKILL.md` 或查看 Markdown 源码；预览的返回栏固定，正文在独立区域内滚动，返回列表保留搜索与滚动位置。技能仅作只读展示，没有启用或自动批准开关，预览不执行技能指令。

原有的配置模型快捷入口会直接打开面板中的项目配置。

CLI Web 的“项目信息 → 数据库”展示关系库和独立知识库引用、状态及共享入口。关联操作使用各自绑定规则，浏览操作打开 Server Web 对应资源，URL 不含账号 token；资源创建、授权和数据编辑在 Server Web 或 CLI 管理命令中完成。

入口在 `steamharness.json` 中分别声明 `databases` 与 `knowledgeBases` 别名。关系库资源由 Server 按账号、项目、入口和别名绑定；根 `config.json.knowledgeBases` 记录知识库别名到 UUID 的映射，支持 `STEAMHARNESS_PROJECT_CONFIG` 覆盖。一个入口可关联多个资源，绑定不授予权限。详见 [项目数据存储](/concepts/data-storage)。

## 服务器连接失败时

页面会按失败原因显示修复操作，项目登记和数据库检查列在单独的“连接检查”区域。知识库资源会标为“知识库（数据库）”，关系表资源标为“关系数据库”。

- **项目未找到或无权访问**：先确认它是否应当已经存在。如果需要新建，点击高亮的“创建云端项目”，会在当前账号下创建私有项目并自动打开。新项目使用 Server 分配的新 ID；原有数据和授权不会转移，源码也不会因此上传。
- **需要登录或数据库授权**：分别点击“登录”或“配置数据库”，完成后点击“重新检查”。
- **服务器返回 HTTP 500 等错误**：点击“打开云端项目”检查登记。如果管理页面也失败，把“连接详情”中的服务器、项目 ID 和入口交给管理员处理。页面会自动重新检查，不会为服务器错误新建项目。

连接故障阻断运行时，Bot 输入框、Workflow 执行表单和 Kanban 操作区暂时隐藏；历史和草稿保留，已有任务仍可停止。连接恢复后操作区自动显示。复查期间保持已有提示和布局。

Studio 通过宿主打开云端项目，并沿用当前登录状态。独立 CLI Web 打开经过认证的新标签页；如果浏览器阻止弹出页面，请允许后重试。打开失败的原因显示在按钮下方。

## 本地资源预览

知识卡片可提供 `reader: { entrypointId, args? }`，调用当前本地聚合中目标 Workflow 入口的只读操作。该操作须声明 `readOnly: true`，返回 `{ errCode: 0, errMessage: "", format: "markdown" | "json", content }`。Markdown 的 content 为正文字符串，JSON 为待展示的数据。reader 不用于 Server 资源或其它项目。

声明 reader 后，知识卡片不需要 knowledgeBase 别名；原有 Server 知识卡片仍使用该别名。地图等 Kanban 卡片可通过现有 `entries.get(id).runEntrypoint(...)` 读取同一聚合中声明只读的操作。宿主拒绝预览写操作，并在卡片关闭或访问身份变化后取消读取。

自定义工具的本地知识卡片可用 `details.resourceCard.target.query` 保存搜索关键词。打开时，宿主把当前选择追加为 `--document-id <id>` 与 `--query <query>`；reader 应以这些末尾参数覆盖保存的初始参数。空 documentId 表示返回结果列表。reader 可返回 `title` 更新预览名称。文档使用真实标题，搜索和目录使用各自名称；标识仍保留在卡片详情中。

在 Studio 中，卡片的“在侧边编辑器中打开”按钮复用对话旁的编辑器分组；尚未拆分时创建一个分组。后续卡片更新同一预览页签，不再创建独立原生窗口。
