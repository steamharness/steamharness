# workspace download

```bash
steamharness workspace download <project> [--target draft|latest|version] [--path <dir>]
```

默认下载 `latest`。所有操作系统使用同一源码契约，不需要平台参数。历史版本读取不可变快照；下载不会重新应用上传忽略规则，也不安装或运行代码。

Workflow、Conversation 和 Kanban 均可下载正式版本；项目类型不会限制根项目下载。

项目声明中的待确认关联不会阻止根项目源码下载。下载只处理发布版本中已确认的关联锁，不会自动包含未获双方确认的项目。

| 目标 | 行为 |
| --- | --- |
| `draft` | 下载根项目草稿并替换目标目录，不处理依赖锁。 |
| `latest` | 解析当前 latest 的精确版本，再按其依赖锁下载。 |
| 精确版本 | 下载指定历史版本，included 依赖使用锁定版本与源码哈希。 |

## 权限和写入

已发布源码下载要求访客及以上角色。公开项目向登录用户提供隐式访客权限；私有项目通过分享链接申请后，由维护者或所有者批准加入为访客。每个依赖独立校验目标项目权限，源码不包含服务器数据。

新项目先写 staging，再移动到目标路径；校验或移动失败会移除本次新增目录。已有项目仅在 UUID 和版本均匹配时复用，保留其本地修改；不同版本不会被误报为已下载，已占用的目标目录拒绝覆盖，可通过 `--path` 选择其他目录。文本与 base64 二进制文件按原始字节恢复并校验 SHA-256。

项目组不携带 KV、PersistentValue、文件存储、环境变量、运行历史和用户配置。下载后在本地安装项目依赖；需要服务器数据时显式使用服务器存储。

## API

- 草稿：`GET /api/projects/{projectId}/files?target=draft&includeBinary=true`。
- 项目组：`GET /api/projects/{projectId}/project-group-download?target=<target>`。
- 单版本 tar.gz：`GET /api/projects/{projectId}/source-archive?target=<version>`。

```bash
steamharness workspace download hello --target 1.2.0 --path ./hello-copy
```

v2 发布配置只携带作者选定的字段、值和不可变附件副本。下载验证版本源码及附件摘要，将可信配置缓存到源码之外供离线使用。升级保留获准的个人值和自定义字段，新锁定值停止覆盖模板。下载权限不会开放原项目的其他数据。详见[项目配置](/concepts/project-configuration)。
