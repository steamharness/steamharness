# workspace download

用 `workspace download` 下载整个聚合项目，保持各入口的相对目录结构。账号需要相应的源码访问权限。

## 命令

```sh
pnpm exec steamharness workspace download <project-id> --target latest --path ./downloaded
```

| `--target` | 下载内容 |
| --- | --- |
| `draft` | 当前草稿 |
| `latest` | 最新发布版本 |
| 精确版本号 | 对应的历史快照 |

## 校验与安装

入口文件、数据库产物清单和哈希全部通过检查后，才创建目标项目目录。缺失文件、损坏清单、运行数据或未登记的 `dist/` 文件会导致失败，并清理临时文件。

下载完成后进入项目目录安装依赖。需要修改静态入口时重新构建，再运行 `steamharness check .`。

## 资源访问

归档不包含凭据或宿主运行数据。关系库的账号绑定保存在 Server，资源声明和知识库引用也不会授予权限。换账号或 Server 后，重新检查授权和绑定，再执行数据操作。
