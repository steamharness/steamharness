# 下载聚合项目

```sh
pnpm exec steamharness workspace download <project-id> --target latest --path ./downloaded
```

一次操作覆盖一个 projectId 的所有注册入口，包含入口代码、依赖清单、业务配置定义和 Kanban 产物。先在本地安装依赖并构建静态入口，再运行 `steamharness check .`。

归档过滤凭据、宿主运行数据、Git 和 node_modules，保留根 `config.json` 中的 `alias → databaseId` 映射，不导出环境变量覆盖值。引用不授予访问权；使用其他宿主或项目身份时，申请相应访问或替换数据库 ID。

`--target` 支持 `draft`、`latest` 和精确版本。下载到一个聚合目录，保持注册的子目录路径，不创建其他独立项目。源码访问仍需要成员或获批权限。

下载使用与上传相同的入口及数据库产物校验；缺失入口文件、生成清单损坏、运行数据或未登记的 `dist/` 文件会使下载失败。校验全部通过后才创建目标项目目录，失败时清理临时文件。
