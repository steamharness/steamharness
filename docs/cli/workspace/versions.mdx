# workspace versions

用 `workspace versions` 查看项目的 `latest`、`nextVersion` 和历史发布记录。

## 命令

```sh
pnpm exec steamharness workspace versions <project-id>
```

命令读取 `GET /api/projects/{projectId}/versions`。请求失败时输出错误 JSON，以退出码 `1` 结束。

## 返回内容

每个版本包含版本号、发布者、时间、说明、源码 SHA-256、依赖锁、`latest` 标记和 `downloadCount`。

下载次数按 Server 成功发送的源码响应累计，同一用户重复下载也计数；通过 `latest` 下载会计入实际版本。

版本记录没有执行状态或上下线操作。用 [download](/cli/workspace/download) 取回快照，用 [publish](/cli/workspace/publish) 创建新版本。
