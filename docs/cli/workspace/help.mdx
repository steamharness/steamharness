# workspace help

运行 `steamharness workspace help` 查看 Server 项目管理命令。使用 `--help`、`-h` 或省略子命令也会显示同一份帮助。

## 命令格式

```bash
pnpm exec steamharness workspace help
pnpm exec steamharness workspace --help
pnpm exec steamharness workspace -h
pnpm exec steamharness workspace
```

## 输出内容

| 内容 | 说明 |
| --- | --- |
| Usage | workspace CLI 基础调用格式。 |
| Commands | login、logout、status、health、pack、upload、preparation、download、publish、versions 和 file-upload/file-download/file-delete。 |
| Options | `--server` 和 `--token` 的默认来源。 |

## 行为

| 情况 | 结果 |
| --- | --- |
| 未传命令 | 输出帮助。 |
| 命令是 `help` / `--help` / `-h` | 输出帮助。 |
| 未知命令 | 输出错误信息，退出码为 `1`。 |
