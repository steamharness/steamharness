# workspace logout

用 `workspace logout` 清除本机 CLI 保存的服务器地址、API Key 和账号信息。命令只删除登录配置，不请求 Server，也不删除项目文件。

## 命令格式

```bash
pnpm exec steamharness workspace logout
```

## 参数

| 参数 | 说明 |
| --- | --- |
| 无 | 该命令不读取位置参数。 |

## 行为

| 步骤 | 说明 |
| --- | --- |
| 定位配置目录 | 使用 `STEAMHARNESS_CLI_AUTH_DIR` 或系统默认目录。 |
| 清理配置 | 删除 `workflow-auth.json`。 |
| 输出状态 | 输出 `{ loggedIn: false }`。 |

## 输出

| 情况 | 输出 |
| --- | --- |
| 成功 | `{ errCode: 0, errMessage: "", data: { loggedIn: false } }` |
| 文件写入失败 | 输出错误信息，退出码为 `1`。 |

## 示例

```bash
pnpm exec steamharness workspace logout
pnpm exec steamharness workspace status
```

## 注意事项

| 场景 | 说明 |
| --- | --- |
| 已设置 `STEAMHARNESS_SERVER_ADMIN_KEY` | 环境变量仍会被后续命令读取。 |
| 需要彻底切换账号 | 同时清理 shell 环境变量和 CLI 登录态。 |
