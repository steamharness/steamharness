# 发布不可变聚合版本

```sh
pnpm exec steamharness workspace publish <project-id> --release-log "Update entries"
```

一次操作覆盖一个 projectId 的所有注册入口，包含入口代码、依赖清单、业务配置定义和 Kanban 产物。先在本地安装依赖并构建静态入口，再运行 `steamharness check .`。

归档过滤凭据、宿主运行数据、Git 和 node_modules，保留数据库别名和模型定义；业务库绑定由 Server 按账号、项目、入口和别名管理，归档不携带连接凭据或业务数据。使用其他账号或 Server 时，重新申请资源权限并绑定入口。

发布从已准备草稿读取根 `steamharness.json.version`，创建不可变快照；同一版本不能重发。所有入口共享该版本及源码哈希。Server 只处理静态数据。

CLI 发布前读取各入口配置，并提交按 `entryId` 索引的 `expectedConfigurationRevisions`（JSON 非负安全整数，初始为 0）及源码哈希；源码或配置发生并发修改时，Server 拒绝发布。
