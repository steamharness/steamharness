# workspace publish

发布校验草稿并保存不可变源码快照、SHA-256、发布者、发布时间、发布说明和关联项目版本锁，成功后更新 `latest`。所有类型都保留完整源码；下载不受操作系统限制。

```bash
steamharness workspace publish <project> [--release-log <text>]
steamharness workspace publish --deployment <id>
```

发布版本取自已准备草稿的 `package.json.version`。Server 按项目串行发布；重复版本返回冲突，已有版本不会被覆盖。需要新版本时重新上传带新版本号的源码。发布不安装依赖、不构建或执行代码。

## 项目组

从本地发布项目组可使用 `--project-group`、`--path <dir>`、`--dependency <alias>=<path>` 和 `--create`。included 项目先发布，根 Kanban 最后更新 `latest`；根版本固化精确版本和源码哈希。

已准备项目组使用 `--deployment <id>` 重试，不能同时传本地目录或项目组创建参数。已完成且哈希一致的项目会被复用。

## API

单项目：`POST /api/workflows/{workflow}/publish`，请求体可包含 `releaseLog`。项目组：`POST /api/deployments/{deploymentId}/publish`。

使用 [versions](/cli/workspace/versions) 查看结果，再用 [download](/cli/workspace/download) 下载任意历史版本。
