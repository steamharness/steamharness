# workspace publish

用 `workspace publish` 发布 Server 上已准备完成的草稿。整个聚合项目共享版本和源码哈希。

## 命令

```sh
pnpm exec steamharness workspace publish <project-id> --release-log "Update entries"
```

先完成本地检查与 [upload](/cli/workspace/upload)。发布读取根 `steamharness.json.version`，同一版本不能再次发布。

## 并发检查

CLI 提交源码哈希和各入口的 `expectedConfigurationRevisions`。修订号为非负安全整数，初始为 `0`；准备期间源码或配置被修改时，Server 拒绝发布。

发生冲突后重新读取草稿与配置，确认差异，再重新上传或发布。不要只重复提交旧的修订号。

## 发布包含什么

版本包含全部入口代码、依赖声明、配置定义、模型和静态产物。它不携带宿主凭据、运行数据或业务数据；接收方按自己的账号申请资源权限并绑定入口。

Server 只处理静态快照。发布后用 [versions](/cli/workspace/versions) 核对版本和源码哈希。
