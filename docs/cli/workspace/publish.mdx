# 发布不可变聚合版本

```sh
pnpm exec steamharness workspace publish <project-id> --release-log "Update entries"
```

一次操作覆盖一个 projectId 的所有注册入口，包含入口代码、依赖清单、业务配置定义和 Kanban 产物。先在本地安装依赖并构建静态入口，再运行 `steamharness check .`。

归档过滤凭据、宿主运行数据、Git 和 node_modules；保留数据库需求，剥离所有 `bindingRef`。安装者必须在自己的 local 或 server 宿主重新申请绑定，不继承作者授权。

发布从已准备草稿读取根 `package.json.version`，创建不可变快照；同一版本不能重发。所有入口共享该版本及源码哈希。Server 只处理静态数据。
