# 上传聚合项目

```sh
pnpm exec steamharness workspace upload <project-id> --path .
```

一次操作覆盖一个 projectId 的所有注册入口，包含入口代码、依赖清单、业务配置定义和 Kanban 产物。先在本地安装依赖并构建静态入口，再运行 `steamharness check .`。

归档过滤凭据、宿主运行数据、Git 和 node_modules，保留 `alias → databaseId` 引用。引用不授予访问权；使用其他宿主或项目身份时，申请相应访问或替换数据库 ID。

`--file` 上传归档，`--no-wait` 返回准备任务，`preparation <project-id> <job-id>` 查询结果。只有静态校验通过才替换草稿；上传不安装依赖或执行代码。
