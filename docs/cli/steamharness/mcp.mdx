# 入口 MCP 服务

通过 stdio 暴露所选 Workflow 的操作、参数与执行结果。

```sh
pnpm exec steamharness mcp . --entry database
```

`entryId` 定位聚合入口，`entrypointId` 定位 Workflow 内部操作。同一项目的多个入口分别持有配置、数据库需求和会话状态。默认使用 `defaultEntry`，未知入口直接报错。

每个 MCP 请求和恢复句柄绑定项目与入口。工具权限、当前用户、配置快照和取消信号沿调用链传递；恢复到其他入口会拒绝。数据库仍须先在宿主申请和获批，MCP 不能自动创建空间。
