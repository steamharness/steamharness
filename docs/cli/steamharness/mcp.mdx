# steamharness mcp

用 `mcp` 把已注册 Workflow 的操作、参数和结果提供给 MCP 客户端。进程通过标准输入输出通信。

## 命令

```sh
pnpm exec steamharness mcp . --entry workflow
```

项目需声明 `workflow` 入口；不传 `--entry` 时使用 `defaultEntry`。客户端调用的 `entrypointId` 指向 Workflow 内部操作，不能替代聚合的 `entryId`。

## 权限与恢复

每个请求和恢复句柄都绑定项目与入口。当前用户、工具权限、配置快照和取消信号随调用传递，跨入口恢复会被拒绝。

入口各自保存配置和会话状态。未知入口会直接报错。

## 按需联网

默认不会读取平台登录凭据。指定 `--online project` 可使用已登录账号的受控项目配置；指定 `--online ai` 可使用已登录的系统 AI。这两个选项都需要连接服务器，可重复指定。
