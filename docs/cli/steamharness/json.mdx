# JSON 运行报告

执行所选入口并输出 JSON 运行报告。

```sh
pnpm exec steamharness json . --entry database --entrypoint search -- --query example
```

`entryId` 定位聚合入口，`entrypointId` 定位 Workflow 内部操作。同一项目的多个入口分别持有配置、数据库需求和会话状态。默认使用 `defaultEntry`，未知入口直接报错。

报告包含运行状态、输出和错误。`--conversation-id` 和 `--run-id` 供显式会话与执行标识使用；宿主仍按项目与入口隔离，不能用相同 ID 访问其他入口。取消会终止当前执行，返回中止状态。
