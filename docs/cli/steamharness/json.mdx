# steamharness json

需要在脚本中读取运行状态、输出或错误时，使用 `json`。它会实际执行项目，不只是转换已有结果。

## 命令

```sh
pnpm exec steamharness json .
pnpm exec steamharness json . --entry database --entrypoint search -- --query example
```

第二条示例选择已声明的 `database` 入口和 `search` 操作。省略 `--entry` 使用 `defaultEntry`，未知 ID 报错；业务参数放在 `--` 后。

## 阅读报告

报告包含运行状态、输出与错误。显式使用 `--conversation-id` 和 `--run-id` 时，记录仍按项目与入口隔离，不能用相同 ID 读取其他入口。

各入口有独立配置、资源需求和会话状态。取消会终止当前执行并返回中止状态；权限或资源失败需要按报告处理，不能仅凭有 JSON 输出判断成功。
