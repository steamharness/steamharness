# 运行所选入口

执行注册的 Workflow 或 Conversation；Kanban 使用 `web` 静态展示。

```sh
pnpm exec steamharness run . --entry database --entrypoint search -- --query example
```

`entryId` 定位聚合入口，`entrypointId` 定位 Workflow 内部操作。同一项目的多个入口分别持有配置、数据库需求和会话状态。默认使用 `defaultEntry`，未知入口直接报错。

`--` 后传业务参数；配置在本轮开始时固定，修改从下一轮生效。跨入口调用使用目标配置，继承当前权限。详见 [CLI](/cli/steamharness)。
