# steamharness help

`steamharness help` 输出本地 CLI 的简短帮助。未传命令、传 `help`、`--help` 或 `-h` 时都会进入帮助模式。

## 命令格式

```bash
steamharness help
steamharness --help
steamharness -h
steamharness
```

## 输出内容

| 内容 | 说明 |
| --- | --- |
| Usage | `run`、`json`、`structure` 的基础格式。 |
| Examples | 常见本地运行和结构检查示例。 |

## 行为

| 情况 | 结果 |
| --- | --- |
| 未传命令 | 输出帮助，退出码为 `0`。 |
| 第一参数是 `help` / `--help` / `-h` | 输出帮助，退出码为 `0`。 |
| 第一参数是未知命令 | 输出错误信息，退出码为 `1`。 |
