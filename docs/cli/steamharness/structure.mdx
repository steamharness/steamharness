# steamharness structure

用 `structure` 查看入口声明和执行结构。它分析已注册源码根与入口文件；检查整个聚合项目时使用 `check`。

## 命令

```sh
pnpm exec steamharness structure .
pnpm exec steamharness structure . --entry database
pnpm exec steamharness check .
```

`--entry` 是清单中的入口 ID，省略时选择 `defaultEntry`。同一类型的多个入口也分别检查，未知 ID 会报错。

## 检查范围

- Workflow：执行器、操作目录、节点和静态参数。
- Bot：执行器及对话参数声明。
- Kanban：静态 HTML 入口和已构建资源。

旧根类型与已移除的数据声明会被拒绝。静态检查不代替真实运行或资源授权验证，完成后继续用 [run](/cli/steamharness/run) 验证结果。
