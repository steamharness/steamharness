# 逐入口静态结构

静态分析所选入口，省略入口时使用默认入口。`check` 检查整个聚合。

```sh
pnpm exec steamharness structure . --entry database
```

`entryId` 定位聚合入口，`entrypointId` 定位 Workflow 内部操作。同一项目的多个入口分别持有配置、数据库需求和会话状态。默认使用 `defaultEntry`，未知入口直接报错。

分析范围是注册的代码根目录及入口文件。聚合中可存在不同类型的 executor；同类型多入口也分别检查。静态 HTML 入口验证已构建产物，旧根类型和数据声明被拒绝。
