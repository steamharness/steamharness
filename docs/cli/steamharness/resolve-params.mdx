# steamharness resolve-params

`resolve-params` 供 CLI Web 调用，也可用于本地调试参数联动。Workflow 使用 `--entrypoint <id>` 选择入口的 `resolveParams`，省略时使用默认入口；Conversation 使用 executor `resolveParams`，并拒绝非空入口参数。请求 JSON 从 stdin 读取，避免输入正文出现在命令行参数中。

```bash
printf '%s' '{"draftText":"查询文档","args":["--tone","balanced"],"inputMode":"form","trigger":{"kind":"input"}}' \
  | steamharness resolve-params ./workspace/workflow/example --entrypoint search
```

成功时 stdout 返回 `WorkflowParamResolveResult`：

```json
{"params":{"tone":{"value":"precise","resolvedOptions":[{"value":"precise","label":"精确"},{"value":"creative","label":"创意"}],"options":{"creative":{"disabled":true}}}}}
```

所选入口或 Conversation executor 没有定义 `resolveParams` 时返回 `{"params":{}}`。`resolvedOptions` 数组会替换参数当前的完整选项列表，`null` 恢复静态列表，`options` 只补充单个选项的显示或禁用状态。`--entrypoint` 必须放在 CLI 参数区；显式 `--` 后的同名参数不会被 CLI 读取。请求格式、入口或回调结果非法时退出码为 `1`，错误写入 stderr。
