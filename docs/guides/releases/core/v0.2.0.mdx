# Core v0.2.0

2026-11-18 · Tag `steamharness/v0.2.0` · npm

<span id="steamharness-0-2-0" className="release-version-anchor"></span>
<span id="steamharness.0.2.0" className="release-version-anchor"></span>

#### 新特性

- **Bot 项目记忆**：Bot 默认开启项目记忆，自动保存长期事实并在每轮按输入检索 {/* note: entry-1 */}
- **本地运行持久化**：运行历史与 Agent 检查点默认保存到本地 SQLite，回复路径不再等待远程读写 {/* note: entry-2 */}
- **可取消的等待**：内置 `sleep({ seconds })` 保存截止时间，恢复后只等待剩余时间 {/* note: entry-3 */}

#### 破坏性变更

- 发行结构采用带版本标识的 Brotli + Base64 编码，项目与入口摘要保留明文。 {/* note: entry-4 */}
  迁移：升级前按本条列出的新约定调整项目或客户端。
- SDK 统一解码后读取入口、参数与模型定义，拒绝损坏、超限或旧格式载荷。 {/* note: entry-5 */}
  迁移：重新从源码构建旧发行包；通过统一结构解码器读取入口、参数和模型。
- Conversation 项目改为 Bot，统一使用 defineBot 与 Core Agent。 {/* note: entry-6 */}
  迁移：升级前按本条列出的新约定调整项目或客户端。
- 固定输入解析、输出与持久会话，提供输入准备和可恢复的完成通知，写工具可声明始终审批。 {/* note: entry-7 */}
  迁移：将 Conversation 项目声明迁至 defineBot，并按 Bot 输入、输出和持久会话契约接入。
- 完全移除 KV、PersistentValue 与本地 KV API；对话与运行记录默认使用本地 SQLite，可显式选择 Server 仓储。 {/* note: entry-8 */}
  迁移：改用运行持久化接口；旧 KV/SQLite 数据不会自动迁移，请先评估并迁移所需记录。
- 项目身份、名称、版本和声明改用独立的 `steamharness.json`；不再读取或写回 `package.json.id` 与 `steamHarness`。 {/* note: entry-9 */}
  迁移：升级前按本条列出的新约定调整项目或客户端。
- 聚合项目须显式登记子入口，由子目录配置提供图标、声明与计划。 {/* note: entry-10 */}
  迁移：升级前按本条列出的新约定调整项目或客户端。
- 未登记配置不生效，上传下载保留父子结构。 {/* note: entry-11 */}
  迁移：把旧 package.json 项目字段移至 steamharness.json，并显式登记聚合子入口。
- 项目改用根 projectId 与 entries/defaultEntry 聚合入口，支持同类型多入口、逐入口配置和执行隔离。 {/* note: entry-12 */}
  迁移：升级前按本条列出的新约定调整项目或客户端。
- 跨入口调用继承身份与取消信号并重新校验权限。 {/* note: entry-13 */}
  迁移：在根清单声明 projectId、entries 和 defaultEntry，并按目标入口调整调用与配置。

#### 新增

- 新增 Kanban 结构报告保留显式 Web 应用声明，支持完整本地 H5 的宿主接入。 {/* note: entry-14 */}
- 新增 Bot 记忆改为静默维护：模型自动判断并记录长期事实，每轮开始按当前输入检索。 {/* note: entry-15 */}
- 新增 支持多关键词、相关性排序与有界摘要的 `memory_search`，默认最多 5 条，避免载入全部记忆。 {/* note: entry-16 */}
- 新增 默认开启的 Bot 项目记忆，可通过项目配置或 `defineBot.memory.enabled` 调整。 {/* note: entry-17 */}
- 新增 内置存、取、改、删工具及操作提示，按项目、Bot 入口、分类与独立条目保存，支持并发版本校验和跨会话检索。 {/* note: entry-18 */}
- 新增 本地运行日志按真实时间读取活动记录的接口。 {/* note: entry-19 */}
- 新增 返回有界的截图引用、活动区间及当前时刻详情，保留原有分页和历史。 {/* note: entry-20 */}
- 新增 文件参数的 `image` 裁剪开关与最小／最大宽高声明，结构报告和等待输入保留图片设置，并校验像素范围。 {/* note: entry-21 */}
- 新增 数值参数的 `control: "range"` 与 `range: { min, max, step }`，支持滑块展示，参数解析和联动检查范围。 {/* note: entry-22 */}
- 新增 项目生成规范中的结构化活动记录，用于分层展示业务事件、完整文字和宿主附件。 {/* note: entry-23 */}
- 新增 本地 Workflow 历史的增量输出日志及分页读取，最终局部快照不截断此前输出。 {/* note: entry-24 */}
- 新增 删除与备份包含完整日志。 {/* note: entry-25 */}
- 新增 Kanban 桥接补齐内层会话的剪贴板及编辑路由，保留沙箱与会话边界，并在关闭时清理复制请求。 {/* note: entry-26 */}
- 新增 Kanban 自定义引用支持 `suggest: false`：保留历史显示名称，同时从提及菜单隐藏该条目。 {/* note: entry-27 */}
- 新增 Kanban 原生会话卡片的带标签操作；回调仅传卡片 `id` 与 `requestId`，不接受 URL 或脚本。 {/* note: entry-28 */}
- 新增 Kanban Conversation UI 的有界纯文本 `messageCards`，按请求 ID 关联原生回复，不开放脚本或导航。 {/* note: entry-29 */}
- 新增 子 Agent 队列清空后以持久内部状态输入续行主 Agent，并提前结束相关 sleep。 {/* note: entry-30 */}
- 新增 保留真实结果、通知去重、取消和失败边界，普通定时等待保持原时长。 {/* note: entry-31 */}
- 新增 内置可取消的 `sleep({ seconds })`，保存截止时间并在恢复后只等待剩余时间；宿主禁用的内置及自带工具从模型列表中移除。 {/* note: entry-32 */}
- 新增 支持显式声明只读 Workflow 操作供本地知识卡片与 Kanban 预览读取。 {/* note: entry-33 */}
- 新增 宿主逐次校验操作并拒绝预览写入。 {/* note: entry-34 */}
- 新增 支持校验和运行压缩发行包，保留可读入口结构，隔离开发与发行会话及配置。 {/* note: entry-35 */}
- 新增 Kanban 原生 Conversation 嵌入接口的发送生命周期与按原身份重试。 {/* note: entry-36 */}
- 新增 业务消息区可即时展示发送状态并直接合并已授权回执。 {/* note: entry-37 */}
- 新增 Kanban Conversation 公开类型的项目自定义 @ 选项、动态 UI 更新、展示插槽及提交回执回调。 {/* note: entry-38 */}
- 新增 可复用原生输入框构建多人话题。 {/* note: entry-39 */}
- 新增 聚合 Bot 入口控制与可信调用来源，保留原用户、权限和取消信号。 {/* note: entry-40 */}
- 新增 支持持久回执、快照、审批、停止及显式恢复。 {/* note: entry-41 */}
- 新增 持久会话快照提供子 Agent 的执行耗时和用量，以及包含所属子 Agent 的会话总用量。 {/* note: entry-42 */}
- 新增 失败、停止和隐藏子会话仍保留已消耗用量，重试、重开和独立分支不会重复累计。 {/* note: entry-43 */}
- 新增 提供 `steamharness/runtime-storage` 服务端 Agent 存储。 {/* note: entry-44 */}
- 新增 该存储按账号、工作区和会话隔离 PostgreSQL 记录，支持租约接管、幂等提交和文档检查点。 {/* note: entry-45 */}
- 新增 自定义宿主也可显式接入。 {/* note: entry-46 */}
- 新增 子 Agent 总并发与角色并发支持显式 `null` 不设数量上限，保留默认 FIFO 限额。 {/* note: entry-47 */}
- 新增 已证明未发出的工具请求可按业务回执恢复重试，权限拒绝、取消与未知副作用仍阻止重放。 {/* note: entry-48 */}
- 新增 项目可为子 Agent 配置总尝试上限与退避。 {/* note: entry-49 */}
- 新增 失败后复用原任务、子会话和检查点自动继续。 {/* note: entry-50 */}
- 新增 完成回执核验、不可重试标记、持久次数与取消边界防止误报成功和无限重复。 {/* note: entry-51 */}
- 新增 子任务最终失败回传主 Agent；耗尽配置的尝试上限时，同时附带上限提示。 {/* note: entry-52 */}
- 新增 子 Agent 可通过项目配置单选统一模型，或由开发者指定默认模型。 {/* note: entry-53 */}
- 新增 复用现有模型列表，支持跟随主模型、独立连接与凭据、能力匹配及系统 AI 权限校验。 {/* note: entry-54 */}
- 新增 持久任务快照的委派项提供 `childConversationId`。 {/* note: entry-55 */}
- 新增 匿名与命名子 Agent 在运行、完成和重开历史中均可定位对应子会话，供对话与 Trace 展示执行详情。 {/* note: entry-56 */}
- 新增 命名 Agent 角色、持久 FIFO 并发队列、统一管理命令及安全检查点重试。 {/* note: entry-57 */}
- 新增 动态会话和自定义 executor 继承 durable，恢复重新校验角色权限，保留业务任务历史与进度。 {/* note: entry-58 */}
- 新增 Core Agent 的 skills.directories 技能目录声明，运行时自动组装带权限校验的技能工具。 {/* note: entry-59 */}
- 新增 宿主可列出项目及 Core 内置技能，并按目录 ID 只读预览完整 SKILL.md，无需运行工具工厂或任务。 {/* note: entry-60 */}
- 新增 Core Agent 内置小助手参数，defineExecutor 自动继承参数与模型解析。 {/* note: entry-61 */}
- 新增 支持字段定制、隐藏、禁用、固定值和分组，以及业务 workflow 的 coreAgent 引用。 {/* note: entry-62 */}
- 新增 输入 helper 支持 ExecutorContext，静态结构报告共用同一参数契约。 {/* note: entry-63 */}
- 新增 用户设置支持模型列表，Agent 节点与直接调用可免连接配置运行。 {/* note: entry-64 */}
- 新增 支持显式选择用户或旧项目来源，模型参数默认跟随且允许覆盖，始终执行系统 AI 来源及授权限制。 {/* note: entry-65 */}
- 新增 公开用户设置快照 API `getUserSettings`、`withUserSettings` 与宿主校验 `parseUserSettings`，隔离并发执行并复制冻结设置。 {/* note: entry-66 */}
- 新增 Agent 显式 `permissionPolicy: "inherit"` 继承用户权限，无宿主时回退 `auto`。 {/* note: entry-67 */}
- 新增 未配置仍默认 `workspace`，本轮输入优先，工具与路径范围使用同一有效值。 {/* note: entry-68 */}

#### 变更

- 变更 本地项目加载允许缺省或非 UUID 项目 ID，按规范目录生成稳定存储身份且不写回清单。 {/* note: entry-69 */}
- 变更 仅本地加载的 ID 规则，发行和分发仍校验源码 UUID。 {/* note: entry-70 */}
- 变更 项目生成规范同步 Kanban 后台 Workflow 控制、分页和运行图片接口。 {/* note: entry-71 */}
- 变更 项目生成规范统一使用 dist/steamharness/ 管理缓存、报告和发行产物，并同步项目产物与上传校验契约。 {/* note: entry-72 */}
- 变更 sleep 运行进度显示预计结束时间，结果保存实际结束时间。 {/* note: entry-73 */}
- 变更 实时工具进度同步到对话与持久会话快照，恢复后保留原截止时间。 {/* note: entry-74 */}
- 变更 入口编译与静态产物按源码根归入 dist/steamharness 的 build/`<entryId>`/。 {/* note: entry-75 */}
- 变更 拒绝占用其他入口的构建目录。 {/* note: entry-76 */}
- 变更 入口名称和路径禁止与受管产物目录及 Windows 设备名冲突，避免构建清理覆盖缓存或报告。 {/* note: entry-77 */}
- 变更 可重建产物统一使用聚合根 dist。独立 SDK 运行历史默认保存到用户目录 ~/.steamharness/runtime/`<projectId>`/`<entryId>`/，不再写入项目。 {/* note: entry-78 */}
- 变更 Conversation 状态、用量与默认 Agent 会话使用本地持久化；新增版本化会话快照及分叉、独立化和取消接口。 {/* note: entry-79 */}
- 变更 显式 Server 仓储仍在租约失效时中止执行，旧 KV/SQLite 不自动迁移。 {/* note: entry-80 */}
- 变更 Agent 模型改为设置／项目两种独立模式：Studio 隐藏项目 AI 配置，独立 CLI Web 自动使用项目模型。 {/* note: entry-81 */}
- 变更 空设置不回退，项目模型只保留系统 AI／第三方 AI 两种来源。 {/* note: entry-82 */}
- 变更 开发用项目生成技能统一命名为 steamharness-generator，技能副本与相关检查、生成脚本引用同步更新。 {/* note: entry-83 */}
- 变更 默认 Conversation 参数将模型与 effort 拆为两个独立 Quick 入口。 {/* note: entry-84 */}
- 变更 用户模型快照支持完整宿主内置目录，同时保留 100 个自定义模型限制及全局唯一 ID 校验。 {/* note: entry-85 */}
- 变更 参数绑定新增 `userSetting: { key: "agent.permissionPolicy", mode: "fixed" | "default" }`。 {/* note: entry-86 */}
- 变更 fixed 控件仅显示当前系统权限并打开用户设置；default 控件保留三个可选权限。 {/* note: entry-87 */}
- 变更 系统值作为默认且重置后继续跟随；继承状态与项目覆盖分开保存，现有任务保持原权限。 {/* note: entry-88 */}

- 修复 资源未声明、未登录等已知失败显示明确提示，未知宿主异常仍保留安全的通用消息。 {/* note: entry-90 */}

- 修复 压缩后重开未完成请求时复用原摘要和工具结果。 {/* note: entry-96 */}

- 修复 宿主禁用规则覆盖会话工具、原生工具和延迟目录工具。 {/* note: entry-98 */}
- 修复 跨轮替换目录会释放旧连接、更新回调并保留历史与定义校验。 {/* note: entry-99 */}
- 修复 同一运行时拒绝并发执行，避免覆盖在途状态。 {/* note: entry-100 */}
- 修复 请求前自动压缩上下文后恢复当前系统提示和工具声明，避免长任务在压缩后失去工具而提前结束。 {/* note: entry-101 */}
- 修复 保留当前授权范围和已加载的延迟工具。 {/* note: entry-102 */}
- 修复 后台报告统一按业务身份去重并合并待处理进度。 {/* note: entry-103 */}

- 修复 运行配置拒绝保留独立错误类型和重校验文案，同一输入不重置授权重试预算。 {/* note: entry-105 */}
- 修复 子 Agent 默认最多 3 个并行，多余工作持久排队并自动补位。 {/* note: entry-106 */}

- 修复 持久 Agent 的思考与正文条目保留模型请求的起止时间（含首包等待），工具条目使用持久任务跨度，重开后仍可显示轨迹耗时。 {/* note: entry-114 */}

## 历史发布线 (2026-08-26)

#### 破坏性变更

- 项目必须声明 `steamHarness.projectInfo.dataStorage.mode`，它限制 KV、PersistentValue 与知识库可访问位置。 {/* note: entry-167 */}
  迁移：补齐 `dataStorage.mode`；`server` 位置要求登录并绑定同 UUID 项目。
- 移除 `context.kv` 与 `context.persistentValue`，改用 `context.storage.<位置>.*`。 {/* note: entry-168 */}
  迁移：本地改写为 `context.storage.local.*`，服务器改写为 `context.storage.server.*`；旧属性运行时只抛出迁移错误。
- 知识库 helper 必须显式接收对应存储位置上下文，不再隐式沿用当前存储域。 {/* note: entry-169 */}
  迁移：调用知识库 helper 时显式传入 `context` 或目标存储位置。

#### 变更

- 变更 项目必须在 `devDependencies.steamharness` 写入精确 SemVer，宿主只比较 `major.minor` 兼容线。 {/* note: entry-170 */}
- 变更 同线任意 patch 或日期 Alpha 可直接运行，major 或 minor 变化在加载用户模块前要求升级宿主。 {/* note: entry-171 */}
