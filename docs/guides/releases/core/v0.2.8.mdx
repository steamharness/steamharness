# Core v0.2.8

2026-11-26

#### 新增

- 在支持的本地宿主中，Agent Bot 可以按别名使用已保存的凭据进行受限的 HTTPS 或 SSH 查询。凭据原值不会进入对话。 {/* note: protected-bot-credential-queries */}
- 工作区权限下，可以在本次对话复用同一凭据和相同参数的查询授权。更换凭据、切换对话或重启 Studio 后会重新确认。 {/* note: scoped-bot-credential-approvals */}
