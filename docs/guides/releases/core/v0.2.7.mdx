# Core v0.2.7

2026-11-26

#### 新增

- Bot 可请求保存由多个字段组成的结构化凭据。在支持的宿主中，Bot 也可按别名请求阿里云 DNS 只读查询；凭据原值不会交给 Bot。 {/* note: structured-bot-credentials */}

#### 变更

- Bot 会把记忆中的部署位置、配置和运行状态当作历史记录，在据此操作前重新核对当前状态。 {/* note: bot-memory-current-state */}
