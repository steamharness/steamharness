# Core v0.2.6

2026-11-25

#### 新增

- 支持按项目目录读写 Bot 记忆。支持目录选择的宿主可为 `memory_*` 工具指定 `projectPath`；不指定时继续使用旧库，已有记忆不会迁移。 {/* note: bot-project-memory */}
- Bot 可在支持的本地对话中提交交付文件。交付保存文件当时的内容，之后修改源文件不影响已交付的副本。 {/* note: bot-artifact-snapshots */}
- 本地 Studio 中受信任的 Bot 可以请求安全输入凭据。Bot 只收到保存、已存在或拒绝的状态，不会收到凭据原值。 {/* note: protected-bot-credential-input */}

#### 修复

- 系统 AI 凭据服务短暂不可用时，Core 会重试读取凭据。 {/* note: system-ai-credential-retry */}
