# Studio v0.1.0

2026-11-26

#### 新增

- 点击启动台左下角的版本号，打开设置中的「关于」。这里可以区分 Studio、Core、CLI 和 VS Code 的版本。 {/* note: studio-about-component-versions */}
- 在项目详情中管理 Bot 的本体或分身，不必先启动项目。启动项目时，状态栏会显示依赖检查与安装进度。 {/* note: project-bot-management-and-progress */}

#### 变更

- Studio 从 `0.1.0` 开始独立编号，不再使用 VS Code 的版本号。这是 `1.141.1` 后的新版本，不需要降级。 {/* note: independent-studio-version-series */}

#### 修复

- 重建托管项目时保留已有的项目数据，旧运行记录仍按各自项目归集。 {/* note: managed-project-data-and-usage */}
