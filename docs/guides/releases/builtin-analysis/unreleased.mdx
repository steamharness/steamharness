# 分析项目 待发布

#### 新特性

- **本地分析看板**：以真实项目与运行数据展示统计图、运行趋势、活动列表及可筛选导出的明细表。 {/* note: draft-5 */}

#### 破坏性变更

- 项目身份、名称、版本和声明统一使用独立的 `steamharness.json`，移除 `package.json.id` 和 `steamHarness` 的读取与写回。聚合项目显式登记子入口，由子目录配置提供图标、声明与计划；未登记配置不生效，上传下载保留父子结构。 {/* note: draft-2 */}
  迁移：升级前按本条列出的新约定更新受影响的项目声明或客户端。

- 新增 Studio 本地分析看板，以真实项目与运行数据汇总。 {/* note: draft-6 */}
- 新增 分析看板的统计图与运行趋势。 {/* note: draft-7 */}
- 新增 分析看板的活动列表。 {/* note: draft-8 */}
- 新增 可按筛选条件导出 CSV 的明细表。 {/* note: draft-9 */}
