# Pi v0.1.0

v0.1.0 是首个版本，尚未发布；下面记录的是该版本已具备的能力。

#### 新特性

- **内置「智能体-Pi」**：由 pi agent SDK 驱动的编码智能体，在对话里指派任务，过程和结果都留在对话中。
- **`--agent` 先 plan 后 build**：plan 只调研出方案，经确认后同一会话切到 build 执行。
- **`--effort` 思考强度**：off 到 max 共七档，默认 high，模型不支持的档位自动收敛。

#### 新增

- 新增 内置项目「智能体-Pi」：由 pi agent SDK 驱动的编码智能体。
- 新增 在对话里直接指派任务，代理读改工作目录中的文件、执行命令，并把过程和结果留在对话中。
- 新增 思考强度参数 `--effort` 支持 off / minimal / low / medium / high / xhigh / max，默认 high。
- 新增 `--effort` 在模型不支持某档位时自动收敛到该模型支持的档位，而不是直接失败。
- 新增 权限策略参数 `--permission-policy` 支持 read-only / workspace / auto。
- 新增 read-only 隐藏写工具，workspace（默认）对每次写操作请求批准，auto 直接执行。
- 新增 agent 模式参数 `--agent` 支持 build 与 plan。
- 新增 plan 只做调研和方案，一轮结束后弹出计划确认：批准后同一会话切到 build 执行，拒绝则保留计划不做改动。
- 新增 发送 `/compact` 或 `/summarize`（也可点击对话里的上下文用量）触发本轮上下文压缩。
- 新增 较早的对话被替换成模型生成的摘要，不再作为普通消息发给模型；无可压缩内容时明确提示。
- 新增 工具调用、推理、上下文压缩与失败过程以可折叠的详情行呈现，正文回答仍平铺在对话正文里。
