# Server Web v0.1.4

2026-08-07 · Tag `server-web/v0.1.4` · 当前设备

<span id="server-web-0-1-4" className="release-version-anchor"></span>
<span id="server-web.0.1.4" className="release-version-anchor"></span>

#### 新特性

- **界面语言跟随系统**：管理端和公开 Embed 提供三档语言设置，更新摘要与日志链接跟随当前语言。
- **Workflow 多入口折叠列表**：Webhook 设置加载并校验目标版本入口，运行结果、历史和回放显示实际入口。
- **项目定时任务工作区**：管理精确版本和入口计划、预览触发、立即运行并查看 fire 历史。

#### 新增

- 新增 管理端和公开 Embed 提供「跟随系统 / 简体中文 / English」设置，更新摘要与日志链接跟随语言。
- 新增 管理端和公开 Embed 以可折叠列表展示 Workflow 入口，Webhook 设置加载并校验目标版本入口。
- 新增 Kanban Bridge 按静态 alias 读取授权 Workflow KV 数据源并订阅 revision，不暴露来源标识与写能力。
- 新增 Workflow 项目定时任务工作区：精确版本与入口计划、预览触发、立即运行、fire 历史与来源筛选。
- 新增 项目详情提供依赖与权限工作区，支持数据授权编辑、短期源码申请、使用方搜索与审批撤销。

#### 变更

- 变更 项目工作台按更新时间从新到旧排列，最近更新的项目优先显示。
- 变更 执行回放与公开 Embed 重整推理、工具、任务、文件、重试和错误的展示与流式跟随。
- 变更 Workflow 多入口使用紧凑标题栏和对齐表单，Embed 更新与参数联动期间保留当前输入状态。

#### 修复

- 修复 手动折叠的默认入口重新展开、宿主重渲染重置输入、旧目标的迟到错误显示到当前目标。
- 修复 Kanban 初始快照后重复刷新、入口结构不可用时隐藏全部计划、定时任务操作被重复提交。
