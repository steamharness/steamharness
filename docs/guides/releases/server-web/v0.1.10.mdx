# Server Web v0.1.10

2026-09-05 · Tag `server-web/v0.1.10` · 当前设备

<span id="server-web-0-1-10" className="release-version-anchor"></span>
<span id="server-web.0.1.10" className="release-version-anchor"></span>

#### 新特性

- **运行记录可重命名与删除**：项目管理员或运行发起者可操作，运行中的记录仍可改名但不能删除。
- **KV 条目可删除**：数据页详情弹窗确认后调用 `DELETE /api/workflows/:name/kv/entry` 删除单条 KV。

#### 破坏性变更

- Server Web 不再承载公开 Embed，项目详情入口、列表状态、`/embed/**` 页面与域名全部移除。
  迁移：浏览器中的运行改由 Desktop 首页的 Web 构建承担，管理端只负责管理云端项目。
- Server Web 不再有 `/web` 入口页，登录页也不再接受 `next=web` 回跳。
  迁移：直接把用户送到登录页，登录后进入项目列表。

#### 新增

- 新增 公开 Embed 按 Workflow 入口分组折叠展示，展开状态按站点稳定 Workflow ID 隔离。
- 新增 管理中心 Runner 页面，可查看节点在线状态、协议架构、容量与心跳并支持排空恢复。
- 新增 项目设置提供 Runner 池、CPU、内存和超时配置，版本页展示 Core 与镜像摘要。
- 新增 执行日志的运行行支持重命名与删除，仅项目管理员或运行发起者可操作。
- 新增 删除运行前弹确认并写明目标，成功后该行从列表消失。
- 新增 KV 数据页详情弹窗的「删除条目」，确认后调用删除接口并刷新当前页。
- 新增 删除失败时弹窗保持打开并在原位显示原因，无权限的会话不显示该入口。

#### 变更

- 变更 公开 Embed 支持预览视频附件并保留媒体类型。
- 变更 运行相关页面只展示远程 Server 可运行版本，任务状态来自持久化 Runner 控制面。
- 变更 执行日志、调度、MCP 与 Webhook 页签改用 Server Web 自维护的精简回放与参数表单。
- 变更 项目详情「知识库」页签文档列表改为翻页，滚动到底不再自动续载。

#### 修复

- 修复 匿名访问 `/web` 先跳登录并在登录后回跳，`?next=` 只接受路由名。
- 修复 管理端表格在窄屏下保持列宽并在自己的滚动区域内显示长内容。
