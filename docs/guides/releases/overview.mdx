# 发布总览

按组件选择发布日志，查看具体版本的变更和迁移要求。本站收录历史记录；安装和部署时还需核对当前包版本及目标服务。

## NPM 包

公开 npm 包为 [`steamharness`](https://www.npmjs.com/package/steamharness) 与 [`@steamharness/cli`](https://www.npmjs.com/package/@steamharness/cli)。在项目目录确认实际安装版本：

```sh
pnpm list steamharness @steamharness/cli --depth 0
```

项目固定精确版本，升级前检查[版本兼容性](/guides/releases/compatibility)。

## 当前部署版本

读取目标 Server 的 `/health`，核对产品版本、`deploymentId` 和 `commitSha`。同一产品版本可以有多次部署，完整更新说明及同语言文档链接也从该响应读取。

## 公开入口

从所用 Server 和 Studio 配置的入口访问服务。增强版环境选择见[环境与更新](https://docs.steamharness.yuhe.space/enhanced/management/deployment)，自托管环境见[部署指南](/guides/server/deployment)。

## 最新稳定产物

npm 包以包仓库中的发行信息为准。内置项目使用对应发布索引，正式索引位于 `builtin-projects/<项目>/index.json`，alpha 使用同级 `alpha/index.json`。下载前核对通道、版本和完整性信息。

已收录的版本详情保持当时的发布事实，完整目录见[发布日志索引](/guides/releases/changelog)。
