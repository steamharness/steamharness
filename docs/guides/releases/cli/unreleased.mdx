# CLI 待发布

#### 变更

- 本地开发不再建立平台会话。需要受控项目配置或系统 AI 时，指定 `--online project` 或 `--online ai`。 {/* note: explicit-platform-connection */}
- CLI Web 支持 LLM Bot 的流式回答、工具审批、队列、停止和手动重试。项目更换引擎后开启新会话，保留旧会话。Bot 模板显式声明 Agent 引擎。 {/* note: draft-1 */}
- 使用 `--online project` 启动 CLI Web 后，点击「浏览器登录」，可在同一标签页授权并回到原链接和 Bot 会话。 {/* note: cli-web-one-click-sign-in */}
