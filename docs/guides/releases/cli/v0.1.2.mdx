#### 破坏性变更

- 项目打包只读取根目录 `.workflowignore`，其它忽略文件不再生效。
  迁移：在 `.workflowignore` 中显式排除凭据、依赖目录和临时文件。

#### 新增

- 新增 `workspace pack`、`upload`、`publish` 和 `download` 支持 Kanban 静态项目，无损传输二进制资源。
