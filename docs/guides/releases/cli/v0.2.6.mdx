# CLI v0.2.6

2026-11-25

#### 新增

- CLI Web 支持显示 Bot 交付的文件卡片，并在支持的本地宿主中预览或下载文件。 {/* note: web-bot-file-cards */}
- 支持保存尚未提交的 Workflow 表单草稿，可稍后打开并继续填写。 {/* note: workflow-form-drafts */}

#### 修复

- 对话的 `@` 文件候选显示相对于项目目录的路径，便于区分同名文件。 {/* note: relative-file-mentions */}
