# 使用 Server Web 管理项目与数据

Server Web 是 SteamHarness Server 的浏览器管理端。登录后可查找 Workflow、Conversation 和 Kanban 项目，管理源码版本与项目数据。项目执行由本地 CLI 或 Studio 完成。

## 项目工作台

项目列表可按项目 ID、名称、类型、上传者和版本搜索，并展示 latest、版本数量与更新时间。项目详情提供概览、设置、关联项目、版本、成员、邀请、知识库和 KV 数据。

上传包必须在 `package.json.steamHarness.projectType` 声明 `workflow`、`conversation` 或 `kanban`。名称和展示平台来自 `steamHarness.projectInfo`；展示平台不限制源码下载。

## 项目与数据

- 使用 [Workspace CLI](/cli/server-workspace) 创建、上传、发布和下载项目。
- 在 [项目管理](/guides/server/project-management) 中配置成员、源码授权和双方关联权限。
- 知识库支持文档创建、编辑、删除、检索和按行读取；KV 与 PersistentValue 保存项目或会话数据。
- `dataStorage.mode` 为 `server` 或 `both` 时可访问服务器数据；`local` 项目仍可存储与下载源码。
- Kanban 保留静态预览、配置和数据 Bridge。预览使用绑定项目、用户和版本的短期 capability，iframe 不继承账号凭据。

## 账号与设置

Server Web 支持邮箱密码登录、设备授权、成员邀请、用户角色、API Key、审计和主题设置。账号、项目和数据权限由 Server 统一校验，凭据只以脱敏形式出现在管理界面和审计记录中。

主侧栏中的「设置」和「管理中心」可展开子菜单；选择子页后仍保留项目工作台和其他入口。管理中心仅展示当前账号有权访问的菜单，直接打开子页时会自动展开对应分组并高亮当前页面。

上传失败会显示文件处理阶段和原因；失败不会替换已经保存的草稿或历史版本。Server 不安装项目依赖、不构建或加载上传的项目代码。

## 显示

管理端支持移动端、浅色、深色和系统主题。时间按浏览器时区显示，完整时间使用 `YYYY-MM-DD HH:mm:ss`。API 保留 ISO 时间。

所有管理页面仅在右上角保留一个刷新按钮，用于刷新当前页面的数据。移动端以抽屉展示页面导航，表格在自己的区域内滚动。
