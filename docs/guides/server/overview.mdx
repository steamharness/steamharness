# 使用 Server Web 管理项目与数据

Server Web 是 SteamHarness Server 的浏览器管理端。登录后可查找 Workflow、Bot 和 Kanban 项目，管理源码版本与项目数据。项目执行由本地 CLI 或 Studio 完成。

## 项目工作台

项目列表展示类型集合，筛选匹配任一入口类型；详情提供入口清单、逐入口配置、版本和成员。关系库与知识库独立管理，支持显式创建、账号读写授权、入口绑定与数据浏览。

上传包必须注册非空 `steamharness.json.entries` 和有效 `defaultEntry`。名称和展示平台来自 projectInfo。入口在 steamharness.json 中声明关系库与知识库别名；关系库资源 ID 由 Server 按账号、项目、入口和别名绑定，知识库别名到 ID 的映射记录在根 config.json 的 knowledgeBases 中。

## 项目与数据

- 使用 [Workspace CLI](/cli/server-workspace) 创建、上传、发布和下载项目。
- 项目成员与组归属在[项目管理](/guides/server/project-management)维护，数据资源在各自详情页设置账号授权。
- 关系库支持资源、账号授权、模型迁移与表数据管理；知识库支持文档、检索、版本冲突检查和私有附件；运行历史保存在平台关系表。
- Kanban 保留静态预览、配置和数据 Bridge。预览使用绑定项目、用户和版本的短期 capability，iframe 不继承账号凭据。

## 账号与设置

Server Web 支持邮箱密码登录、设备授权、成员邀请、组与项目成员角色、API Key、审计和主题设置。账号、项目和数据权限由 Server 统一校验，凭据只以脱敏形式出现在管理界面和审计记录中。

在已登录的 Studio 中点击数据库或「在 Server 中管理资源」，管理页直接使用当前 Studio 的账号和权限，无需再次输入密码。网页通过一分钟内有效、仅可使用一次的凭证建立登录态，地址不会包含长期令牌；Studio 凭据撤销或账号停用后，网页访问也随之失效。数据库侧栏的按钮、筛选和提示文字跟随 Studio 当前主题。

登录状态由账号会话独立校验。项目列表加载失败时保留已登录状态，在项目工作台显示错误并允许刷新重试，不会显示为密码或登录失败。版本公告加载失败也不影响登录；会话失效后才需要重新登录。


在「设置 → 个人资料」或用户管理中选择头像后，使用固定 1:1 的正方形选区裁剪，可以移动和缩放选区，「重置选区」恢复居中的最大正方形。原图不限制文件大小、尺寸和宽高比；预览会等比适应弹窗，小图也会放大显示以方便操作，导出不会放大原图。浏览器会在确认裁剪后自动压缩正方形头像，点击「保存资料」后上传。取消裁剪保留原头像，处理失败可以重试；GIF 会转换为静态头像。个人资料、账户菜单、用户列表、成员、审计和资料详情统一使用 1:1 圆角头像，历史图片居中覆盖显示，避免拉伸。用户管理的预览头像与用户资料弹窗中的头像支持点击查看大图，预览按视口大小显示。关闭按钮、点击遮罩或 Escape 均可关闭预览，关闭后键盘焦点返回原头像。

主侧栏中的「设置」和「管理中心」可展开子菜单；选择子页后仍保留项目工作台和其他入口。管理中心仅展示当前账号有权访问的菜单，直接打开子页时会自动展开对应分组并高亮当前页面。

上传失败会显示文件处理阶段和原因；失败不会替换已经保存的草稿或历史版本。Server 不安装项目依赖、不构建或加载上传的项目代码。

## 显示

管理端支持移动端、浅色、深色和系统主题。时间按浏览器时区显示，完整时间使用 `YYYY-MM-DD HH:mm:ss`。API 保留 ISO 时间。

所有管理页面仅在右上角保留一个刷新按钮，用于刷新当前页面的数据。移动端以抽屉展示页面导航，表格在自己的区域内滚动。
