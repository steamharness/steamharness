# 使用 Server Web 管理项目与数据

Server Web 是 SteamHarness 的浏览器管理端。用它管理项目、版本、成员和数据；项目代码在本地 Studio 或 CLI 中执行。

## 项目工作台

1. 登录 Server Web，在项目列表搜索名称或按入口类型筛选。
2. 打开项目，查看注册入口、配置、版本和成员。
3. 下载所需版本，在本地安装依赖并运行。

一个项目可包含多种入口，类型筛选匹配其中任意一种。上传归档必须包含非空 `entries` 和有效 `defaultEntry`，名称与展示信息按项目声明读取。

## 项目与数据

| 任务 | 入口 |
| --- | --- |
| 管理成员、组归属和访问申请 | [项目管理](/guides/server/project-management) |
| 上传草稿、发布或下载版本 | [Workspace CLI](/cli/server-workspace) |
| 创建关系库、授权、迁移模型与编辑表行 | 数据库目录中的关系库详情 |
| 管理知识文档、搜索、版本与附件 | 数据库目录中的知识库详情 |

关系库与知识库分别创建、授权和绑定。关系库绑定由 Server 按账号、项目、入口和别名管理；知识库还使用根配置中的别名映射。操作前检查资源授权，项目成员身份不会自动授予数据访问权。

Kanban 可在受权限限制的静态 iframe 中预览。预览使用短期能力凭据，不继承账号凭据；需要执行项目逻辑时使用本地宿主。

## 账号与设置

设置中提供个人资料、API Key 和主题；具有相应权限的账号还可管理用户、组、邀请和审计。菜单按能力显示，服务端再次检查每次操作。

从已登录 Studio 的资源管理链接进入时，可以使用同一账号，无需再次输入密码。跳转凭证仅可使用一次、有效期一分钟，不包含长期令牌；原凭据撤销或账号停用后，网页访问随之失效。

项目列表或版本公告加载失败时，可以在对应区域重试，已有登录状态保留。只有会话失效才需要重新登录。

### 修改头像

1. 在 **设置 → 个人资料** 选择图片。
2. 移动或缩放正方形选区，必要时选择 **重置选区**。
3. 确认裁剪，再点击 **保存资料** 上传。

预览按弹窗大小缩放，导出不会放大原图；客户端压缩为正方形头像，GIF 转为静态图。取消保留原头像，处理失败可重试。用户资料中的头像可放大查看，Esc、关闭按钮或遮罩可关闭并恢复焦点。

历史头像居中裁剪显示，避免拉伸。设置与管理中心的子页会保留侧栏其他入口，并展开、高亮当前分组。

## 显示

管理端支持浅色、深色、系统主题和窄屏布局。表格在自身区域滚动，移动端导航使用抽屉；右上角刷新按钮更新当前页。

界面时间按浏览器时区显示，完整格式为 `YYYY-MM-DD HH:mm:ss`，API 继续返回 ISO 时间。上传失败会报告处理阶段，保留原草稿和历史版本。
