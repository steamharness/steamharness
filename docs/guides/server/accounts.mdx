# 账号、登录与恢复

Studio 和 CLI Web 都通过 Server 网页登录。账号、邮箱验证和密码保存在 Server；应用只接收批准后签发的专用登录凭据。

## 从应用登录并返回

1. 在 Studio 的登录页或 CLI Web 的账号菜单中选择 Server，点击「浏览器登录」。
2. 在打开的 Server 网页完成登录。已有网页会话时，先核对当前账号；需要换号时点击「切换账号」。
3. 核对应用名称、通道和设备码，再批准登录。
4. 点击「打开应用并返回」。Studio 打开对应通道的应用；CLI Web 返回发起授权的本机页面。应用也会自动检查批准结果。

浏览器未自动打开时，使用应用提供的登录链接。请求过期、取消或被拒绝后，回到应用重新发起。关闭 Studio 登录页或点击取消会撤销该次请求。

| 应用通道 | Studio 返回协议 |
| --- | --- |
| `dev` | `steamharness-studio-dev://` |
| `alpha` | `steamharness-studio-alpha://` |
| `main` | `steamharness-studio://` |

三个通道使用独立安装标识和本机登录存储。自定义协议需要先安装或启动相应通道的 Studio；未注册协议时，可手动回到发起登录的应用查看结果。CLI Web 的返回地址只接受 HTTP 回环地址，不在链接中携带 API Key。

## 注册账号

注册默认关闭。管理员开启 `STEAMHARNESS_SERVER_REGISTRATION_ENABLED=true` 后，登录页才会显示注册入口；直接访问 `/register` 也受此开关控制。

| 方式 | 必填信息 | 注册后的登录方式 |
| --- | --- | --- |
| 用户名和密码 | 3–32 位用户名、至少 8 位密码 | 用户名和密码；绑定并验证邮箱后也能使用邮箱登录。 |
| 邮箱验证 | 邮箱和邮件验证码；密码可选 | 邮箱验证码；设置密码后也能使用邮箱和密码。 |

用户名仅接受英文字母、数字、下划线和连字符，须以字母或数字开头，不区分大小写，设置后不能修改。验证码为 6 位，10 分钟内有效、只能使用一次；连续输错 5 次后须重新获取，同一邮箱发送间隔至少 60 秒。

注册后，Server 创建普通账号，并生成昵称和默认几何头像。进入「设置 → 个人资料」修改昵称或上传头像；应用授权流程会保留原来的返回入口。新账号不会获得系统管理员或现有项目的访问权限。

邮件服务未配置时，只能使用用户名和密码注册。管理员可按[部署与发布](/guides/server/deployment)配置 SMTP。

## 绑定或更换邮箱

1. 打开「设置 → 账号安全」，查看用户名、邮箱验证状态和密码设置情况。
2. 输入目标邮箱，发送验证码并填写收到的 6 位数字。
3. 用当前密码，或发送到当前已验证邮箱的另一组验证码，确认操作并保存。
4. 重新登录网页和应用。

已有账号的邮箱不会自动视为已验证。邮箱验证完成前，不能通过它进行验证码登录或密码恢复。更换邮箱需要同时验证新邮箱和当前身份。

解绑邮箱前必须已有用户名和密码，避免失去全部登录方式。解绑后，该邮箱不再用于登录和恢复；重新绑定并验证邮箱后才恢复这些能力。

## 设置或找回密码

邮箱注册时可以不设密码。在「设置 → 账号安全」验证当前邮箱后，即可设置密码；也可先设置一次性的用户名。

忘记密码时，在登录页点击「找回密码」，填写已绑定且验证过的邮箱，获取验证码并设置至少 8 位的新密码。未绑定或未验证邮箱的账号无法自助找回，请联系管理员。

邮箱和密码变更会撤销已有网页会话、Studio／CLI 登录凭据和已批准的设备授权。手工创建的 API Key 保持有效，需要时在 API Key 页面单独撤销。

## 收不到验证码

检查垃圾邮件、邮箱拼写和发送倒计时。页面使用统一发送提示，避免泄露邮箱是否注册；提示发送成功也不表示该邮箱一定已有可用账号。持续收不到邮件时，请管理员检查 SMTP 配置和投递记录。
