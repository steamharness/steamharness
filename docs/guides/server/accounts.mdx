# 账号、登录与恢复

Studio 和 CLI Web 都通过 Server 网页登录。账号、邮箱验证和密码保存在 Server；应用只接收批准后签发的专用登录凭据。

## 从应用登录并返回

1. 在 Studio 的登录页或 CLI Web 的账号菜单中选择 Server，点击「浏览器登录」。
2. 在打开的 Server 网页完成登录。已有网页会话时，先核对当前账号；需要换号时点击「切换账号」。
3. 核对应用名称、通道和设备码，再批准登录。
4. 点击「打开应用并返回」。Studio 打开对应通道的应用；CLI Web 返回发起授权的本机页面。应用也会自动检查批准结果。

浏览器未自动打开时，使用应用提供的登录链接。也可直接打开 Server 的 `/login/device`，手工输入应用上的设备码。请求过期、取消或被拒绝后，回到应用重新发起。关闭 Studio 登录页或点击取消会撤销该次请求。

| 应用通道 | Studio 返回协议 |
| --- | --- |
| `dev` | `steamharness-studio-dev://` |
| `alpha` | `steamharness-studio-alpha://` |
| `main` | `steamharness-studio://` |

三个通道使用独立安装标识和本机登录存储。自定义协议需要先安装或启动相应通道的 Studio；未注册协议时，可手动回到发起登录的应用查看结果。CLI Web 的返回地址只接受 HTTP 回环地址，不在链接中携带 API Key。

## 注册账号

注册默认关闭。管理员开启 `STEAMHARNESS_SERVER_REGISTRATION_ENABLED=true` 后，登录页才会显示注册入口；直接访问 `/register` 也受此开关控制。

| 方式 | 必填信息 | 注册后的登录方式 |
| --- | --- | --- |
| 用户名和密码 | 3–32 位用户名、至少 8 位密码 | 用户名和密码；绑定并验证邮箱后也能使用邮箱登录。 |
| 邮箱验证 | 邮箱和邮件验证码；密码可选 | 邮箱验证码；设置密码后也能使用邮箱和密码。 |

用户名仅接受英文字母、数字、下划线和连字符，须以字母或数字开头，不区分大小写，设置后不能修改。验证码为 6 位，10 分钟内有效、只能使用一次；连续输错 5 次后须重新获取，同一邮箱发送间隔至少 60 秒。

注册后，Server 创建普通账号，并生成昵称和默认几何头像。进入「设置 → 个人信息」修改昵称或上传头像；应用授权流程会保留原来的返回入口。新账号不会获得系统管理员或现有项目的访问权限。

默认头像按账号固定生成，配色兼顾浅色和深色背景；切换主题不会改变图案或颜色。上传头像后优先显示上传的图片，清除后恢复默认头像。

填写注册密码时，需要再次输入相同密码。校验或提交失败后，可在原表单修改并重试。邮件服务未配置时，只能使用用户名和密码注册。管理员可按[部署与发布](/guides/server/deployment)配置 SMTP。

## 绑定或更换邮箱

1. 打开「设置 → 账号安全」，查看用户名、邮箱验证状态和密码设置情况。
2. 在邮箱区域选择「绑定邮箱」「验证邮箱」或「更换邮箱」。验证已有邮箱时，地址不可编辑；绑定或更换时，填写新邮箱。
3. 向该邮箱发送验证码，填写收到的 6 位数字。
4. 点击「绑定邮箱」「验证邮箱」或「更换邮箱」保存。
5. 重新登录网页和应用。

已有账号的邮箱不会自动视为已验证。邮箱验证完成前，不能通过它进行验证码登录或密码恢复。绑定、验证或更换邮箱只需保持登录，并填写目标邮箱的验证码。已验证的当前邮箱无需重复绑定。

解绑邮箱前必须已有用户名和密码，避免失去全部登录方式。在邮箱区域点击「解绑邮箱」，核对提示后提交，无需输入当前密码或邮箱验证码。解绑后，该邮箱不再用于登录和恢复；重新绑定并验证邮箱后才恢复这些能力。

邮箱、密码和用户名各有独立操作入口。取消会清空本次操作填写的密码和验证码；已发送邮件的倒计时仍有效。重新打开操作时，须等待倒计时结束并获取新验证码。

## 设置或找回密码

邮箱注册时可以不设密码。在「设置 → 账号安全」的密码区域点击「设置密码」或「修改密码」，两次填写至少 8 位的新密码后，点击对应按钮直接保存，无需输入当前密码或当前邮箱验证码。

用户名在同一页面的用户名区域单独设置，填写后直接保存，设置后不能修改。解绑邮箱需要用户名和密码，页面会提示尚缺的条件。邮件服务不可用时，已登录的账号仍可设置或修改密码、设置用户名，或在满足条件时解绑邮箱。

忘记密码时，在登录页点击「找回密码」，填写已绑定且验证过的邮箱，获取验证码，并两次输入至少 8 位的新密码。重置成功后，点击「返回登录」，使用新密码登录；从应用进入时会保留原授权入口。未绑定或未验证邮箱的账号无法自助找回，请联系管理员。

邮箱和密码变更会撤销已有网页会话、Studio／CLI 登录凭据和已批准的设备授权。手工创建的 API Key 保持有效，需要时在 API Key 页面单独撤销。

退出 Studio 或 CLI Web 时会清除本机账号，并尝试撤销该应用在 Server 上的凭据；离线时仍可退出本机账号。网页退出会撤销当前会话，其他已登录应用继续使用各自的凭据。

## 收不到验证码

检查垃圾邮件、邮箱拼写和发送倒计时。页面使用统一发送提示，避免泄露邮箱是否注册；提示发送成功也不表示该邮箱一定已有可用账号。持续收不到邮件时，请管理员检查 SMTP 配置和投递记录。

登录配置、个人资料、API Key 列表或设备信息加载失败时，使用页面上的「重试」。发送邮箱验证码或提交期间，请等待当前请求结束；失败后会显示原因，并恢复可操作状态。账号安全操作提示重新获取验证码时，须发送新验证码后再提交。
