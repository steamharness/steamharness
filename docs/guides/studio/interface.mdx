# 使用工作台与 Steam 模式

IDE 模式提供源码编辑器。识别到 Workflow、Conversation 或 Kanban 项目后，可以切换到 Steam 模式，把运行页面和工具并排放置。

## 切换布局

1. 使用标题栏的 **IDE / Steam** 切换按钮。
2. Steam 模式左侧固定项目，右侧打开工具与文件。
3. 用右上角按钮隐藏或恢复工具区，拖动分隔线调整宽度。

工具区首次占窗口宽度的三分之一；宽度按工作区保存，重开、切换模式和重载后恢复。窄窗口临时限制宽度，变宽后恢复保存值。切回 IDE 会恢复原布局和可见区域。

Steam 模式隐藏顶部导航栏和底部状态栏。macOS 窗口按钮位于项目菜单顶部，菜单收起或窗口较窄时移到标题行左侧。拖动项目或工具导航栏的空白处可移动窗口。

## 工具与编辑器

| 操作 | 结果 |
| --- | --- |
| 上层标签 | 切换终端、浏览器、数据库、项目信息、小助手、版本或轨迹工具 |
| 下层 **+** | 新建当前工具的实例 |
| 关闭终端实例 | 结束对应会话 |
| 关闭终端工具标签 | 隐藏工具，现有会话仍可恢复或在 IDE 使用 |
| 选择 **编辑器** | 在下层标签打开工作区文件，**+** 新建空白文件 |

终端配置、分屏和重命名在下层菜单。其他项目以独立项目标签保留。资源管理器、搜索和源代码管理位于编辑器右侧，可以调整宽度。

切换或隐藏工具区会保留未保存修改。关闭文件或编辑器工具时仍有保存确认；返回 IDE 后可以继续编辑。较矮窗口中的弹窗正文独立滚动，标题、关闭和保存操作保持可见。

## 快捷键与文件链接

项目页面优先处理按键，未处理的继续使用 Studio 自定义快捷键与连续组合键。输入框的编辑、复制粘贴和中文输入留在项目页面。Kanban 自定义快捷键调用 `event.preventDefault()` 可避免同时触发宿主快捷键。

Agent 回复中的本地路径可以点击，支持中文、空格、Windows 路径、`file://`，以及 `:行:列`、`#L行C列` 定位。项目相对路径从聚合根目录解析，小助手从绑定工作目录解析。

网页链接在浏览器打开，文档文件使用文档预览；不存在的文件显示错误。文件标签可复制路径或在系统文件管理器中定位。

## 开始工作台

无文件编辑区显示开始工作台；命令 **Studio: 打开开始页** 打开独立标签。`studio.startPage.enabled` 可关闭背景入口。Untitled 仍是普通空白文本，双击背景不会新建文件。

多个编辑器分组均有关闭按钮，关闭前保护未保存文件；只剩一个分组时隐藏关闭按钮。开始页支持中英文、深浅主题和窄分栏，首次显示加载占位，后续刷新保留已有内容。

当前项目与入口的图标来自 `steamharness.json` 的 `projectCard`：项目用根字段，入口用 `entries[].projectCard`。可分别声明图标、图标色和背景色，缺省采用类型默认值。读取图标无需运行项目或安装依赖。

系统状态显示 Studio、VS Code、实际 Node、Core/CLI、账号、连接和本地任务数。可见时每 5 秒刷新，局部读取错误不影响其他计数，整体读取失败保留旧结果并提示；详细统计见[本地分析](/guides/studio/analysis)。
