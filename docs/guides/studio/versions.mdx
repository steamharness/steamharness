# 本地打包与版本

要把项目打成归档，在项目目录运行：

```sh
pnpm exec steamharness workspace pack <project-id> --path . --output project.tgz
```

一个聚合项目只有一个版本。归档包含清单中登记的全部入口。打包会检查 `steamharness.json` 中的项目 UUID、版本和文件，不需要平台账号，也不会上传归档。

将归档交给同事后，可解压并在 Studio 打开项目目录。要在本机预览发行效果，在 Studio 的命令面板选择 **运行（发行模式）**。需要管理远端版本时，使用[在线 Workspace CLI](/cli/server-workspace)或增强版 Studio。
