# 安装与启动 Studio

当前文档使用 Studio 的源码启动方式。先准备 Node 和原生构建工具，再安装并构建工作站。

## 环境要求

| 工具 | 要求 |
| --- | --- |
| Node.js | 24.18.0 或更新的 24.x |
| npm | 11 或 12 |
| Git、curl | 用于源码、子模块和下载 |
| 原生编译工具 | macOS 使用 Xcode Command Line Tools；其他平台按 VS Code 源码构建要求准备 |

## 启动桌面工作站

在开源仓的 `studio` 目录中执行：

```sh
npm ci
npm run setup
npm run build
npm run dev
```

`setup` 安装所需依赖并准备扩展。首次桌面启动会下载所需 Electron。也可通过 `npm run dev -- <项目目录>` 打开已有项目。

源码环境需要访问包仓库与下载源。发生安装或构建错误时，先修复终端报告的问题，再重新运行对应步骤。

## 浏览器工作站

```sh
npm run dev:web
```

在运行 Studio 的机器上，打开终端打印的 `localhost` 或 `127.0.0.1` 地址，无需配对。也可以在源码版桌面打开 **设置 → 远程访问 → 启动 Studio Web**。默认从 `3030` 到 `3040` 选择本机端口，可以用 `npm run dev:web -- --port 3050 --default-folder <项目目录>` 指定端口和项目。

浏览器和桌面操作宿主机上的同一套项目文件与运行历史。浏览器独立保存账号、编辑器设置和扩展，不会镜像桌面窗口。项目无法嵌入时，按 Studio 的提示更新该项目的 SteamHarness CLI。

浏览器需要能访问 `*.vscode-cdn.net`，才能加载设置和项目面板等 Webview 界面。

### 配对另一台设备

1. 按下表配置 HTTPS，重启源码版 Studio。为工作台和预览分别配置不同的主机名。
2. 在宿主机的 **设置 → 远程访问** 启动服务，选择远程地址，再点击 **生成配对码**。
3. 在另一台设备上打开远程工作台，输入配对码并确认。扫码或打开配对链接会预填配对码，仍需手动确认。

配对码只能使用一次，五分钟后过期；生成新码会使旧码失效。浏览器会话有效期为 30 天，服务重启后仍有效。在宿主机撤销设备，或在远程浏览器退出此设备，会立即断开该设备的工作台和预览连接。停止服务会断开所有设备，但不会撤销它们。

只配对可信设备。配对设备可以打开宿主机的文件和终端。桌面托盘与系统通知不会转发到浏览器。

| 方式 | 启动环境变量（以 `STEAMHARNESS_STUDIO_WEB_` 开头） | 网络设置 |
| --- | --- | --- |
| HTTPS 反代 | `PROXY_ORIGIN`、`PROXY_PREVIEW_ORIGIN`、`PROXY_PORT`（默认 `3041`） | 在反代终止 TLS，将两个 HTTPS 来源转发到 `127.0.0.1:3041`（或指定端口）。保留原始 `Host`、WebSocket Upgrade 和流式响应。不要转发到本机免配对端口。 |
| 局域网 HTTPS | `LAN_HOST`、`LAN_ORIGIN`、`LAN_PREVIEW_ORIGIN`、`TLS_CERT_FILE`、`TLS_KEY_FILE` | `LAN_HOST` 设为宿主机的局域网 IPv4 地址。两个来源应使用设备可访问的地址，证书需覆盖它们并受设备信任。Web 服务直接监听 HTTPS 来源中的端口。 |

例如，反代配置可将 `PROXY_ORIGIN` 设为 `https://studio.example.test`，将 `PROXY_PREVIEW_ORIGIN` 设为 `https://studio-preview.example.test`。预览地址包含临时访问凭证；不要共享它，反代也不应记录预览请求的完整路径。不配置 HTTPS 时只开放本机，不会降级到远程 HTTP。

## 切换显示语言

需要简体中文界面时，在扩展中安装 **Chinese (Simplified) Language Pack**（`MS-CEINTL.vscode-language-pack-zh-hans`），执行 **Configure Display Language** 选择简体中文并重启。桌面与浏览器工作站分别管理扩展，需分别配置。

## 更新后重启

退出应用后重新运行启动命令。启动器会应用内核补丁并检查源码、依赖和环境指纹，有变化时重建；仅重载应用窗口不会执行这一步。

构建失败会停止启动。排除错误后重试，不应继续使用未更新的构建判断新功能。

## 可选语音依赖

默认跳过 Foundry Local / ONNX 的 NuGet 下载。这些库用于上游聊天的本地语音听写，编辑器和 Workflow 功能不依赖它们。

需要本地语音听写时，设置 `FOUNDRY_LOCAL_SKIP_INSTALL=0` 后重新执行 `npm run setup`，并确认对应 NuGet 下载源可访问。其他原生依赖仍按正常流程安装。

启动成功后，跟随[快速开始](/guides/quickstart)创建第一个项目。
