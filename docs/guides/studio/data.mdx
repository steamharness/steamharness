# 管理数据库与知识库

在 Studio 数据库工具中查看当前 Server 账号可用的关系库和知识库。项目使用资源前，需要声明别名、取得授权并完成绑定。

## 连接资源

1. 登录正确的 Server 账号，打开目标项目入口。
2. 在数据库工具中选择关系库或知识库。
3. 点击管理入口，在 Server Web 中创建资源或申请已有资源的访问权。
4. 为入口绑定对应别名；关系库按项目模型完成迁移后再运行。

关系库定义来自 `steamharness.database.ts` 和 schema；知识库独立使用 `knowledgeBases` 声明。相同类型和 UUID 的共享引用只展示一份。

## 权限与运行条件

| 条件 | 说明 |
| --- | --- |
| 项目访问权 | 允许打开项目源码或已发布版本 |
| 资源授权 | 允许当前账号读写某个关系库或知识库 |
| 入口绑定 | 把该项目入口的别名指向获授权资源 |
| 网络 | 关系库持久操作要求 Server 和 PostgreSQL 可达 |

项目成员身份和绑定本身都不会授予资源访问权。缺少绑定只影响需要该资源的数据操作，其他入口仍可打开。当前协议不提供旧版 KV 编辑器或本地／远程 KV 切换。

## 在 Server Web 中管理

从已登录的 Studio 打开管理链接，会使用当前账号和权限建立网页会话，无需重新输入密码。链接不携带长期 token；凭据撤销或账号停用后，网页访问同样失效。

Server Web 提供账号授权、入口绑定、模型、表数据、知识文档和附件管理。Studio 数据库侧栏的按钮和提示跟随当前主题。

关系模型与生成步骤见 [Database API](/core-api/database)；资源归属和历史区别见[数据存储](/concepts/data-storage)。
