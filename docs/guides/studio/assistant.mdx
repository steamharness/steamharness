# 小助手与持久任务

Studio 小助手在独立工作目录中处理代码和项目任务。它作为内置项目分发，共用固定身份；使用服务器模型仍需账号授权。

## 开始一个任务

1. 打开小助手，确认绑定的工作目录和模型。
2. 检查 **Permission**，输入具体任务。
3. 遇到需要批准的操作时，核对工具和参数后处理。
4. 在 Trace 中查看任务、计划、记录和用量。

会话历史保存在本机用户数据目录。内置项目身份不会授予其他服务器项目的数据访问权。加载失败可点击 **重试**；重试期间显示进度，再次失败会给出原因。

## 使用项目技能

在 **项目信息 → 技能** 查看技能名称、数量与来源，点击可只读预览 `SKILL.md` 和 Markdown 源码。

小助手通过 `skill` 工具按需读取指南，不把技能安装到用户全局目录：

```json
{"action":"list"}
```

```json
{"action":"read","skill":"steamharness-generator"}
```

读取技能中的引用文件时传入 `path`。指南要求的文件修改或命令仍使用对应工具和权限，接入示例见 [createSkillTools](/core-api/create-skill-tools)。

## 控制 Studio

小助手项目包含默认 `main` Bot 和 `studio-control` Workflow，统一安装并共用依赖。通过 `mcp --entry studio-control` 按需连接控制入口；也可打开小助手项目根目录并直接运行该入口。

| 工具范围 | 可以做什么 |
| --- | --- |
| 工作区和诊断 | 读取编辑器状态、入口列表、错误与警告 |
| 文件 | 打开文件并定位行列 |
| 视图 | 打开终端、文件、搜索、源代码管理或小助手视图 |
| 外观 | 切换已安装的主题 |

打开终端本身不执行命令。状态、诊断和入口查询默认自动批准，其他编辑器操作继续遵守工具权限及 Build/Plan 审批。

控制能力要求 Node 扩展宿主。会话关闭、工作区移除或撤销信任后，连接失效。`studio-control` 子目录不是独立项目；此入口不提供旧 Desktop 的 Dock、更新和开机自启控制。

## 排查 Kanban 页面

`get_kanban_diagnostics` 只读检查已经打开的本地入口。先在 JSON 字符串 `input` 中传入 `projectDir` 和 `entryId`，查看当前配置、页面实例及最近 50 条 Bridge 请求。

需要检查页面方法时，用返回的 `instanceId`、`configurationId` 和明确声明为 `readOnly: true` 的方法构造 `call`。例如查询地图是否 `imageReady`，不能靠上传或文件下载成功推断页面已经显示。

诊断不会打开、刷新页面或修改配置。没有预览、没有实例或实例过期时会返回不可用或失败。更新 CLI 后重新打开预览，才能使用新增诊断能力。

## 持久任务与子 Agent

意外退出后，持久会话会恢复原运行；关闭宿主保留检查点，显式停止才持久取消。输入队列、补充本轮、撤回和分叉都在对话中操作。

| Trace 页签或入口 | 用途 |
| --- | --- |
| 任务 | 查看任务树与历史，打开子对话或分叉来源，分范围停止 |
| 计划 | 查看和更新计划步骤 |
| 记录、用量 | 查看运行记录、上下文与用量，压缩或重置上下文 |
| 对话中的 **子 Agent** | 展开运行、排队、失败和完成数量，以及阶段、进度、结果或错误 |

子 Agent 入口在主回复结束后仍保留，后续回复也保留展开状态；断线时显示最近状态并暂停跳转。停止、重试和批次管理仍在 Tasks 中完成。项目最多委派 4 个只读子 Agent，结果单次回传。

Studio Control 在首次搜索授权工具时连接。Code Mode 默认关闭，由宿主显式启用。

## 权限何时生效

点击小助手的 **Permission** 打开 **设置 → 权限**。初始用户默认值为自动批准 `auto`，保存在用户级 `studio.agent.permissionPolicy`；工作区不能覆盖。

| 模式 | 文件与命令范围 |
| --- | --- |
| 只读 | 隐藏写入、编辑和命令工具 |
| 工作区 | 文件与检索限于工作区和挂载目录；shell 仍以宿主身份执行 |
| 自动批准 | 文件工具还可访问工作区外路径 |

项目可声明允许覆盖的默认值，也可重置为跟随用户设置。编码工具、提示词和 Studio Control 使用同一份有效权限。

设置变化不会中断当前、后台或子任务。所有工作结束、会话空闲后，后续输入采用新设置，并保留历史和请求标识。完整规则见[用户设置与权限继承](/core-api/user-settings)。
