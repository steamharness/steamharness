# 运行与文件存储

本机项目的数据保存在 `~/.steamharness/accounts/<账号键>/projects/<项目ID>/`。同一系统用户运行的 Studio、Studio Web、CLI 和 SDK 使用同一套目录。账号按 Server 地址和用户 ID 区分；未连接项目账号时使用 `local`，只连接系统 AI 不会切换账号。Studio Web 读取服务所在机器的数据，不会同步另一台电脑上的文件。

项目 ID 目录也是默认工作目录。在这里生成的脚本和计划不会因重建或换用正式版而丢失。指定工作目录或为 Bot 绑定文件夹，只改变执行位置，不搬动源码、历史或记忆。新版不导入旧目录中的记录。

源码项目没有有效 UUID 时，宿主按项目的规范目录生成稳定的本地存储键，不修改清单。不同目录分别保存记录，重新打开同一目录继续使用原记录。发行构建仍校验源码中的项目 UUID。

| 内容 | 保存位置 |
| --- | --- |
| 本地运行记录、对话、记忆、附件 | 项目 ID 目录的 `entries/<入口ID>/` |
| 文件夹 Bot 分身、绑定工作区的助手 | 分别在项目的 `instances/<分身ID>/`、`workspaces/<目录键>/` 下，按入口保存 |
| Studio 托管的内置程序 | 项目的 `builds/`；构建副本不存放工作文件 |
| 编辑器设置及扩展、独占的宿主数据 | 分别在 `~/.steamharness/studio/` 和 `~/.steamharness/hosts/` |
| Server 运行存储 | 显式选择后由 Server 按账号和项目权限保存 |
| 项目托管文件 | 上传到 Server，按项目成员权限读取 |
| 配置附件 | 按项目、入口及配置版本读取 |

本地历史与 Server 存储的接口、备份和故障处理见[运行存储](/core-api/runtime-storage)。项目托管文件与配置附件的区别见[文件](/concepts/files)。

## 产物与运行数据目录

可重建产物写入聚合项目根的 `dist/steamharness/`。子入口不得另建产物根。

| 内容 | 路径 |
| --- | --- |
| 根入口编译和静态页面 | `dist/steamharness/build/<entryId>/` |
| 子入口编译和静态页面 | `dist/steamharness/entries/<encodeURIComponent(entry.root)>/build/<entryId>/` |
| 缓存、测试报告和发行包 | `dist/steamharness/cache/`、`dist/steamharness/reports/`、`dist/steamharness/release/` |

构建器只清理自己的输出目录。删除 `dist/` 后重新构建，不会删除项目外的运行历史。

入口 ID 不得使用受管目录名 `steamharness`、`cache`、`reports`、`release`、`tmp`，也不得使用 Windows 设备名 `con`、`prn`、`aux`、`nul`、`com1`–`com9`、`lpt1`–`lpt9`。入口路径若位于 `dist/`，必须指向对应的 `build/<entryId>/`。
